# Зовнішні референси (опційно)

## Thomas More AI — legal-skills-open

Репозиторій: https://github.com/ThomasMoreAI/legal-skills-open

Корисний skill `draft-a-legal-document` для **NDA, MSA, privacy policy** (англ., загальна юрисдикція). Для клонування в особисті скіли Cursor:

```powershell
git clone --depth 1 https://github.com/ThomasMoreAI/legal-skills-open.git "$env:TEMP\legal-skills-open"
# приклад: скопіювати лише draft-a-legal-document у ~/.cursor/skills/ якщо потрібні US-договори
```

Для **crimeland-wiki/laws/** використовуй **crimeland-legal-drafting** (цей проєкт), не draft-a-legal-document.
