# Мисливство

Полювання на **диких тварин** у лісах та горах штату. Окрема активність від цивільних [вакансій](../basics/city-hall.md) — не потребує оформлення в центрі зайнятості.

## Коротко

| Параметр | Значення |
| --- | --- |
| Стаж | **Не потрібен** |
| Ліцензія | **Мисливська** — оформлення в [мерії](../basics/city-hall.md) / ЦНАП |
| Магазин мисливця | Зараз **не активний** на мапі — спорядження в [Ammunation](../basics/shops.md) |
| Улов | М’ясо, шкури, трофеї — залежно від тварини |

## Як полювати

1. Оформіть **мисливську ліцензію** та тримайте в [гаманці](../basics/documents.md).
2. Візьміть **зброю** з дозволом на полювання (не в місті, не біля натовпу).
3. Вирушайте в **ліс / гори** (Paleto, Chiliad, пустеля).
4. Знайдіть тварину (олень, кабан, койот тощо).
5. Полюйте згідно з [правилами](../basics/rules.md) (дистанція, без Powergaming).
6. Підійдіть до **туші** → **`E`** → міні-гра **знімання шкури** (5–18 сек).
7. Продайте здобич переробнику або іншим гравцям через RP / [маркетплейс](../basics/marketplace.md).

## Поради

- Полювання **поза містом** — у місті стрілянина викличе [поліцію](../police/getting-started.md).
- Шкурки та м’ясо мають **різну цінність** — великі тварини вигідніші.
- Не полюйте на тварин інших гравців без RP-дозволу.
