# Шахтар

Шахтарство — цивільна робота з видобутку руди в підземних шахтах. Потрібен **стаж у штаті від 2 років** (вимога [центру зайнятості](../basics/city-hall.md)). Оплата залежить від обсягу зданої руди.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж для вакансії | **2 роки** в штаті |
| Точка входу | **Mine Center** (шахтарський центр на мапі) |
| Публічні шахти | **№ 11** та **№ 13** — без оренди |
| Орендованих шахт на гравця | максимум **1** |
| Максимум днів оренди за продовження | **30 днів** |
| Мова меню | Українська |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **«Вакансії»** → **Шахтар**.
2. Переконайтесь, що ваш **стаж у штаті ≥ 2 років**.
3. Оформіть працевлаштування та прокладіть маршрут до **Mine Center**.
4. На місці увійдіть у шахтарський центр і оберіть шахту в меню.

{% hint style="info" %}
Працевлаштування в центрі зайнятості та **початок зміни в шахті** — різні кроки. Маршрут лише показує, куди їхати.
{% endhint %}

## Вхід у шахту

На сервері діє система **Mine Center**: ви не заходите в шахту «з вулиці», а спочатку обираєте шахту в центрі.

### Публічні шахти (№ 11, № 13)

- **Безкоштовний** вхід — оренда не потрібна.
- Підходять для старту та заробітку без великих вкладень.
- Може бути більше гравців одночасно.

### Орендовані шахти

- Оплачується **оренда** на обмежений термін (до 30 днів за одне продовження).
- Один гравець може орендувати **лише одну** шахту.
- Зручно для стабільної роботи з командою або власним ритмом.

## Покрокова зміна

### 1. Підготовка в Mine Center

1. Увійдіть у **Mine Center**.
2. Оберіть шахту (публічну або орендуйте).
3. За потреби переодягніться в **робочий одяг** у гардеробі.

### 2. Спорядження

На точках пікапу всередині шахти візьміть:

| Предмет | Навіщо |
| --- | --- |
| **Кирка** | Видобуток руди зі стін тунелю |
| **Шолом** | Захист (обов’язково для роботи в шахті) |

Покладіть кирку назад на точку пікапу, коли закінчите зміну.

### 3. Видобуток

1. Спустіться в тунелі до зон з рудою.
2. Підійдіть до стіни з маркером / підказкою.
3. Натисніть **`E`** — почнеться копання.
4. Зібрана руда потрапляє до вас — стежте за вагою інвентаря.

### 4. Здача руди

1. Підійдіть до **дробилки / сортувальної машини** (зона вивантаження в шахті).
2. Здайте руду — маєте стояти **не далі ~12 м** від точки здачі.
3. Отримайте оплату за зданий обсяг.

{% hint style="warning" %}
Якщо стоїте занадто далеко від дробилки, здача не спрацює. Підійдіть ближче до стрічки / машини.
{% endhint %}

### 5. Завершення

- Поверніть кирку та шолом на місця.
- Вийдіть через Mine Center.
- Перевірте баланс у [банку](../basics/bank.md) або [гаманці телефону](../basics/phone.md).

## Особливості шахти

| Особливість | Пояснення |
| --- | --- |
| Потяг | **Вимкнений** — вагонетки стоять біля зони вивантаження, користуйтесь пішки |
| Атмосфера | Увімкнений фоновий звук шахти |
| Шанс руди в клітинці | Залежить від налаштувань шахти; не кожна стіна дає однаковий обсяг |

## Поради новачку

1. Спочатку працюйте в **публічних шахтах 11 або 13** — без оренди.
2. Не забувайте **шолом** — без нього робота може бути недоступна.
3. Тримайте в [інвентарі](../character/inventory.md) воду та їжу — у шахті довго.
4. Поєднуйте з [батлпасом](../basics/battlepass.md) — цивільні завдання часто включають роботу.

## Якщо щось не працює

| Проблема | Що зробити |
| --- | --- |
| Немає вакансії в центрі | Перевірте **стаж 2 роки** |
| Меню іншою мовою | Повідомте адміністрацію через `F4` |
| Не здається руда | Підійдіть ближче до дробилки (~12 м) |
| Немає кирки | Знайдіть точку пікапу всередині шахти |
