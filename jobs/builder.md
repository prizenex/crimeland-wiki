# Будівельник

Робота на **будівельних майданчиках** промзони міста. Доступна **з першого дня** в штаті — зручний старт для новачків.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **Не потрібен** |
| База | Промзона **LS** (~926, -1560) — маршрут з ![](../.gitbook/assets/blips/419.png) центру зайнятості |
| Оплата | **~100$** за 1% прогресу зміни (повна зміна — кілька тисяч $) |
| Команда | Можна в **групі** (множник виплати) |
| Кулдаун між змінами | **30 хв** |
| Обов’язково | **Гаманець**, посвідчення **категорії C** |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **«Будівельник»**.
2. Прокладіть маршрут до майданчика в промзоні.
3. Підійдіть до маркера бригади → **`E`** → меню зміни.

## Покрокова зміна

1. За бажанням зберіть **групу** (лідер розподіляє відсотки виплат).
2. Сядьте в **службовий транспорт** бригади (можлива телепортація до авто).
3. Їдьте на **активний майданчик** за GPS.
4. Виконуйте завдання: заливка бетону, зварювання, монтаж, збірка конструкцій (міні-ігри).
5. Прогрес відображається на екрані — після **100%** поверніться на базу.
6. Завершите зміну → виплата на рахунок.

{% hint style="warning" %}
Штраф **~500$**, якщо закінчити без **службового авто** бригади.
{% endhint %}

## Поради

- Зручна перша робота для [батлпасу](../basics/battlepass.md).
- Оформіть **категорію C** в [автошколі](../transport/driving-school.md) до першого візиту.
- Працюйте в команді — виплата множиться на кількість учасників.
