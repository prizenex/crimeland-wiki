# Таксист

Перевозьте **NPC** і **гравців** містом за оплату. Потрібен **1 рік стажу** в штаті.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **1 рік** |
| База | Таксі-бюро (~896, -177) |
| Оплата NPC | **~300$–3 500$** за рейс (залежить від місії) |
| VIP-замовлення | **~3 550$–15 000$** (потрібен рівень у меню таксі) |
| Посвідчення | **Категорія B** |
| Робота в системі | Активна посада **`taxi`** |

## Як влаштуватись

1. [Центр зайнятості](../basics/city-hall.md) → **Водій таксі**.
2. Приїдьте на базу → **`E`** біля NPC → відкрийте **меню таксі**.
3. Переконайтесь, що **активна робота** — **`F1`** → **Про мене** → **Робота**.

## Покрокова зміна

### Замовлення NPC

1. У меню оберіть **місію** (місто, передмістя тощо).
2. Заберіть **службове авто** на точці видачі.
3. Під’їдьте до пасажира → **`E`** — посадити.
4. **`G`** — режим підбору клієнтів на вулиці (за бажанням).
5. Довезіть до точки → отримайте оплату та **досвід**.

### Гравці

1. Увімкніть **таксометр** біля авто → **`E`**.
2. Пасажир сідає в машину — тариф нараховується за пробігом.
3. **`N`** — виставити **рахунок** гравцю після поїздки.

{% hint style="info" %}
Є **щоденні завдання** в меню (наприклад, 25 NPC або 10 гравців від 2 км) — дають додатковий досвід.
{% endhint %}

## Поради

- VIP-місії відкриваються з **рівнем** у меню таксі — довгі, але вигідні.
- Для RP з гравцями рекламуйте послугу через **«Послуги»** в [телефоні](../basics/phone.md).
- Базова плата за посадку — **~10$** + податок **~10%** з тарифу.
