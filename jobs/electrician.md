# Електрик

Обслуговування міських **електромереж**: щитки, трансформатори, будинки. **2 роки стажу** в штаті.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **2 роки** |
| База | Район **Vinewood Hills** (~751, 223) — маршрут з ![](../.gitbook/assets/blips/419.png) центру зайнятості |
| Оплата | **~750$–1 000$** за виклик (легкий / середній / складний) |
| Депозит за авто | **500$** (повертається при здачі службової машини) |
| Команда | Можна в **групі** |
| Обов’язково | **Гаманець**, **рівень 2+** у системі досвіду |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **«Електрик»**.
2. Прокладіть маршрут до бази електриків.
3. Підійдіть до маркера → **`E`** → меню зміни.

## Покрокова зміна

1. Сплатіть **депозит** за службовий автомобіль (якщо пропонує меню).
2. Оберіть **рівень складності** виклику (спочатку доступні легкі).
3. Їдьте за GPS до **об’єкта** (червоний маркер на місці).
4. Виконайте **міні-ремонт** (не помиліться — інакше удар струмом).
5. Після серії викликів поверніть авто → депозит назад + виплата.

## Складність викликів

| Рівень | Орієнтовна оплата |
| --- | --- |
| Легкий | **~1 000$** |
| Середній | **~750$** |
| Складний | **~1 000$** |

Після **15** легких курсів відкривається середній рівень, після **30** — складний.

## Поради

- Деякі об’єкти на **висоті** — будьте обережні в RP.
- Тримайте **гаманець** і перевіряйте **рівень** перед стартом.
- Не плутайте з [механіком](mechanic.md) — там ремонт авто, не мережі.
