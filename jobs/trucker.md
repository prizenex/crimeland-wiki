# Далекобійник

Доставка вантажів **вантажівкою з [причепом](../transport/trailers.md)**. Потрібно **2 роки стажу** в штаті.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **2 роки** |
| База | **Доки** — бліп «Робота - далекобійник» (~1209, -3115) |
| Оплата | **~800$–1 000$** за км + бонуси за тип вантажу |
| Типи контрактів | Швидкі (орендована вантажівка) та вантажні (свій тягач) |
| Скасування рейсу | Утримуйте **`F6`** **2 сек** |
| Посвідчення | **Категорія C** рекомендована |

## Як влаштуватись

1. [Центр зайнятості](../basics/city-hall.md) → **«Вакансії»** → **Далекобійник**.
2. Прокладіть маршрут до логістичної бази в доках.
3. Активуйте роботу: **`F1`** → **Про мене** → **Робота** (або **`/multijob`**).

## Покрокова зміна

1. Підійдіть до маркера бази → **`E`** → відкрийте **меню логістики**.
2. Оберіть **контракт** (швидкий або вантажний).
3. Заберіть **вантажівку** (орендовану або свою) та **причеп** з точки видачі.
4. Зчепіть причеп (**`H`**, див. [Причіпи](../transport/trailers.md)) і їдьте за GPS.
5. У зоні розвантаження — відчепіть причеп і підтвердіть доставку.
6. Якщо брали **орендовану** вантажівку — поверніть її на базу для виплати.

## Типи вантажів

| Тип | Особливості |
| --- | --- |
| **Звичайний** | Стандартна оплата за відстань |
| **Терміновий** | Менше часу на доставку, штраф **~20%** за прострочку |
| **Крихкий** | Штраф **~20%**, якщо пошкодження вантажу > **30%** |
| **Нелегальний** | Вищий множник оплати, більший ризик |

Нові контракти з’являються кожні **~5 хв** (до **30** активних у списку).

## Поради

- Почніть з **швидких** контрактів — не потрібна власна вантажівка.
- Плануйте розвороти з довгим причепом заздалегідь.
- Для власного бізнесу [24/7](../business/twenty-four-seven.md) можна замовити доставку палива/товару через логістику.
