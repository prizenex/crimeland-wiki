# Кур'єр

**Доставка піци** — стартова вакансія в ![](../.gitbook/assets/blips/419.png) [центрі зайнятості](../basics/city-hall.md). **Стаж не потрібен**.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **Не потрібен** |
| База | Піцерія (~538, 101) — маршрут з центру зайнятості |
| Оплата | **500$–1 000$** за доставку (готівка) |
| Замовлень за зміну | **10** доставок |
| Транспорт | Службове авто (видається на базі) |
| Посвідчення | **Категорія B** |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **«Доставка піци»**.
2. Оформіть працевлаштування та прокладіть маршрут до піцерії.
3. Підійдіть до NPC → **`E`** / **`лівий Alt`** → почніть зміну.

Перемикання між кількома роботами — **`F1`** → **Про мене** → **Робота** (до **4** професій).

## Покрокова зміна

1. У піцерії натисніть **«Почати роботу»** — з’явиться **службове авто** і мітка **«Наступний клієнт»** на GPS.
2. Їдьте за маршрутом до **будинку клієнта**.
3. Біля будинку (у зоні доставки) підійдіть до **авто** → **`лівий Alt`** → **«Взяти піцу»** — коробка з’явиться в руках. Піцу **не** беруть у піцерії.
4. Підійдіть до дверей → **`лівий Alt`** → **«Доставити піцу»** (або взаємодія в зоні біля дверей).
5. Отримайте оплату — на GPS з’явиться **наступний** клієнт. Повторіть кроки 2–4.
6. Після **10** доставок поверніться на базу → **«Завершити роботу»** біля NPC.

{% hint style="info" %}
Порядок: **авто → їхати → біля будинку взяти піцу з машини → вручити**. Не виходьте з авто далеко від точки — гра напише, що ви занадто далеко від клієнта. Після останньої доставки **обов’язково завершите зміну** на базі.
{% endhint %}

## Поради

- Короткі рейси по LS — швидкий заробіток на старті.
- Поєднуйте з [батлпасом](../basics/battlepass.md) — є завдання на доставки.
- Для іншої роботи без стажу — [Сміттяр](cleaner.md) або [Мийник вікон](window-cleaner.md).

## Якщо щось не працює

| Проблема | Рішення |
| --- | --- |
| «Потрібна категорія B» | Здайте на B в [автошколі](../transport/driving-school.md) |
| Немає «Взяти піцу» на авто | Під’їдьте ближче до **будинку клієнта** (мітка GPS), вийдіть з машини |
| «Потрібна піца з машини» | Спочатку **`лівий Alt`** на **авто** → «Взяти піцу», потім ідіть до дверей |
| Не зарахували оплату | Доставте всі **10** замовлень і натисніть **«Завершити роботу»** на базі |
