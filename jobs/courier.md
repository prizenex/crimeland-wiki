# Кур'єр

**Доставка піци** — стартова вакансія в [центрі зайнятості](../basics/city-hall.md). **Стаж не потрібен**.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **Не потрібен** |
| База | Піцерія (~535, 96) — маршрут з центру зайнятості |
| Оплата | **~500$–1 000$** за доставку (готівка) |
| Замовлень за зміну | **10** доставок |
| Транспорт | Службове авто (видається на базі) |
| Посвідчення | **Категорія B** |

## Як влаштуватись

1. [Центр зайнятості](../basics/city-hall.md) → **«Доставка піци»**.
2. Приїдьте на піцерію за маршрутом.
3. Підійдіть до NPC → **`E`** / **`лівий Alt`** → почніть зміну.

## Покрокова зміна

1. Візьміть **піцу** в піцерії (з’явиться в руках).
2. Сядьте в **службове авто** і їдьте за GPS до клієнта.
3. Підійдіть до дверей → **`E`** → вручте піцу.
4. Отримайте оплату і беріть **наступне** замовлення.
5. Після **10** доставок поверніть транспорт на базу.

{% hint style="info" %}
Не сідайте в авто з піцею в руках неправильно — спочатку завантажте замовлення, потім їдьте. Після останньої доставки обов’язково **поверніть машину**.
{% endhint %}

## Поради

- Короткі рейси по LS — швидкий заробіток на старті.
- Поєднуйте з [батлпасом](../basics/battlepass.md) — є завдання на доставки.
- Для іншої роботи без стажу див. [Сміттяр](cleaner.md) або [Мийник вікон](window-cleaner.md).
