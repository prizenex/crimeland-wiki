# Садівництво

Догляд за парками та зеленими зонами міста. Вакансія **«Садівник»** у [центрі зайнятості](../basics/city-hall.md) — **стаж не потрібен**.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **Не потрібен** |
| База | Парк **Vinewood** (~-1481, -395) — маршрут з ![](../.gitbook/assets/blips/419.png) центру зайнятості |
| Оплата | **5 000$–15 000$** за місію (залежить від складності) |
| Команда | До **4** гравців |
| Кулдаун | **Немає** (0 год) |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **«Вакансії»** → **Садівник**.
2. Прокладіть маршрут до парку Vinewood.
3. Підійдіть до NPC на базі → **`E`** → меню зміни.

## Покрокова зміна

1. Оберіть **місію** (стрижка газону, кущі, прибирання листя, квітники).
2. За потреби запросіть друзів у **групу** (до 4 осіб).
3. Переодягніться в робочий одяг, якщо пропонує меню.
4. Їдьте за GPS між точками на карті.
5. Виконуйте завдання на кожній ділянці (міні-ігри / анімації).
6. Після завершення всіх етапів — **виплата** на рахунок.

## Поради

- Спокійна перша робота для новачків — поруч за тематикою [фермерство](farming.md), але без сільської техніки.
- Поєднуйте з [батлпасом](../basics/battlepass.md) та цивільним RP у парках.
- Тримайте **гаманець** в інвентарі, якщо вимагає меню зміни.
