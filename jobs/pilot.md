# Пілот

Пасажирські та вантажні **авіарейси** з аеропорту. **5 років стажу** — одна з найвимогливіших цивільних робіт.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **5 років** |
| База | **Аеропорт LS** (~-1243, -3392) — маршрут з ![](../.gitbook/assets/blips/419.png) центру зайнятості |
| Оплата | **~4 000$–10 500$** за рейс (пасажири / посилки) |
| Транспорт | **Власний літак** або вертоліт (службовий не завжди доступний) |
| Посвідчення | **Ліцензія пілота** (окремо від авто) |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **«Пілот»**.
2. Оформіть **ліцензію пілота** та придбайте/майте **літак**.
3. Приїдьте в **аеропорт** за маршрутом.
4. Підійдіть до точки пілотів → **`E`** → меню рейсів.

## Покрокова зміна

1. Оберіть тип рейсу: **пасажири** або **посилка**.
2. Сідайте в **свій літак** на стоянці.
3. Слідуйте GPS до точки ![](../.gitbook/assets/blips/569.png) **«Забрати пасажирів»** / **«Забрати посилку»**.
4. Виконайте посадку / завантаження.
5. Летіть до ![](../.gitbook/assets/blips/569.png) **«Висадити пасажирів»** / **«Віддати посилку»**.
6. Після завершення — виплата на рахунок.

## Типи рейсів

| Тип | Орієнтовна оплата |
| --- | --- |
| Посилка (короткий) | **~4 000$–5 500$** |
| Посилка (далекий) | **~5 000$–6 500$** |
| Пасажири (LS ↔ Sandy) | **~5 500$–8 000$** |
| Пасажири (LS ↔ Grapeseed) | **~8 000$–10 500$** |

{% hint style="warning" %}
Без **літака** та **ліцензії** вакансія в каталозі лише інформаційна — спочатку інвестуйте в навчання та техніку.
{% endhint %}

## Поради

- Перевірте паливо та стан літака перед зльотом.
- Дотримуйтесь RP-правил польотів над містом.
- Для наземного транспорту до аеропорту — [оренда](../transport/rental.md) або власне авто.
