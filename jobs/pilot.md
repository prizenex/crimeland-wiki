# Пілот

Пасажирські та вантажні авіарейси. **5 років стажу** в штаті — одна з найвимогливіших цивільних робіт.

### Вимоги

- Посада **пілот** через [центр зайнятості](../basics/city-hall.md).
- **Ліцензія пілота** (окрема від автомобільної).
- **Власний літак** або доступ до службового (RP).

### Як працювати

1. Приїдьте в **аеропорт** (маршрут з ЦЗ).
2. Почніть зміну, оберіть тип рейсу: посилка, пасажири.
3. Слідуйте маршруту GPS, сідайте та злітайте згідно з підказками.
4. Оплата після завершення рейсу.

Бліпи на карті: **«Забрати посилку»**, **«Висадити пасажирів»** — українською в конфігу.

{% hint style="warning" %}
Без літака та ліцензії вакансія лише інформаційна в каталозі — спочатку інвестуйте в навчання та техніку.
{% endhint %}
