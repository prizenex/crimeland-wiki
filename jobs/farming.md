# Фермерство

Вирощування та збір урожаю на **фермах штату**. Окрема гілка від [садівництва](gardening.md). Тут же доступне [самогоноваріння](moonshining.md) — бродильні бочки та дистилятор (нелегальна RP-гілка).

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **Не потрібен** |
| NPC на мапі | ![](../.gitbook/assets/blips/86.png) **«Фермер»** |
| Меню | **`F7`** або <img src="../.gitbook/assets/farming_tablet.png" alt="Фермерський планшет" width="24"> Фермерський планшет в інвентарі |
| Оплата | Продаж урожаю на ринку ферми; місії **~9 600$+** за цикл (залежить від культури) |
| Команда | До **4** гравців у спільній місії |

## Як почати

1. Знайдіть на мапі ![](../.gitbook/assets/blips/86.png) **«Фермер»** (сільська зона).
2. Підійдіть до NPC → **`E`** — підказки та старт.
3. Відкрийте меню: натисніть **`F7`** **або** `Tab` → **Фермерський планшет** → **ПКМ** ![](../.gitbook/assets/inputs/mouse-rmb.svg) → **Використати**.
4. Оберіть **місію**: збір зерна, фруктові дерева, рогата худоба, дрон-полив тощо.
5. Виконуйте етапи за GPS → здавайте урожай → продавайте на **ринку ферми** в меню.

## Типи місій

| Тип | Суть |
| --- | --- |
| **Поле / зерно** | Трактор, сівба, збір, тюки на причеп |
| **Фруктові дерева** | Збір ящиків у саду |
| **Тваринництво** | Годування, догляд за худобою |
| **Дрон-полив** | Полив ділянок з повітря |

## Поради

- Купуйте **насіння** та інструменти в меню ринку ферми.
- Урожай можна постачати [кафе](../business/cafe.md) та [магазини](../business/twenty-four-seven.md) через RP.
- Для легального заробітку не змішуйте з [нелегальним самогоном](moonshining.md) на одній сесії без RP-приводу.
