# Сміттяр

**Сміттяр** (у центрі зайнятості — вакансія «Сміттяр») — одна з найпростіших [робіт](../basics/city-hall.md) для старту. **Стаж у штаті не потрібен**. Ви збираєте сміття по місту службовою вантажівкою та отримуєте оплату за кожен мішок.

{% hint style="info" %}
Окрема вакансія — [Мийник вікон](window-cleaner.md). Це інша робота: висотні фасади, а не збір відходів.
{% endhint %}

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **Не потрібен** |
| База | Район **доків** (південь Лос-Сантоса) |
| Оплата | **~350$** за один мішок у кузові |
| Команда | Можна працювати **в групі** (виплата множиться на кількість учасників) |
| Кулдаун між змінами | **2 години** |
| Посвідчення | **Категорія C** (вантажівка) |
| Обов’язковий предмет | **Гаманець** в інвентарі |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **«Вакансії»** → **Сміттяр**.
2. Оформіть працевлаштування та прокладіть маршрут до бази.
3. Приїдьте на точку біля доків.
4. Підійдіть до NPC / маркера → **`лівий Alt`** або **`E`** → почніть зміну.

Перемикання між кількома роботами — **`F1`** → **Про мене** → **Робота** (до **4** професій).

### Перед стартом перевірте

| Вимога | Деталі |
| --- | --- |
| <p>Гаманець</p><p>![](../.gitbook/assets/wallet.png)</p> | Має бути в інвентарі (у всієї команди, якщо працюєте разом) |
| Посвідчення **категорії C** | Оформлюється в [автошколі](../transport/driving-school.md); без нього зміну не почати |
| Вільне місце на мапі | Точка появи службової вантажівки не повинна бути зайнята |

## Покрокова зміна

### 1. Початок роботи

1. На базі відкрийте **меню зміни**.
2. За бажанням запросіть друзів у **групу** (лідер розподіляє відсотки виплат).
3. Переодягніться в **робочий одяг** (якщо пропонує меню).
4. Сядьте в **службову вантажівку** — вас може автоматично телепортувати до неї.

### 2. Збір сміття

Є два джерела мішків:

| Джерело | Як зібрати |
| --- | --- |
| **Смітники на вулиці** | Підійдіть до контейнера → `E` → підніміть мішок |
| **Мішки на землі** | Підберіть об’єкт поблизу |

Після підбору несіть мішок до **задньої частини вантажівки** (зона з підказкою `E`) і **закиньте в кузов**.

### 3. Наповнення кузова

- Кожен мішок додає **~350$** до майбутньої виплати.
- На екрані відображається **лічильник прогресу** (зазвичай внизу справа).
- Можна збирати сміття, поки не вирішите завершити зміну.

### 4. Розвантаження (фінальний етап)

Після набору мішків потрібно **розвантажити** вантажівку на базі:

1. Поверніться до зони розвантаження біля доків.
2. Виконайте етап **розвантаження** (анімація з мішками на стрічці).
3. Після цього можна **завершити зміну**.

### 5. Завершення та виплата

1. Поверніться на базу в **службовій вантажівці**.
2. Завершите зміну в маркері **«Закінчити роботу»**.
3. Гроші нарахуються на рахунок.

{% hint style="warning" %}
Якщо закінчите зміну **без службової вантажівки**, можливий **штраф ~5 000$**. Повертайте машину на базу.
{% endhint %}

## Робота в команді

| Параметр | Значення |
| --- | --- |
| Мінімум гравців | **1** (команду не обов’язково збирати) |
| Множник виплати в групі | Базова сума × **кількість учасників** (якщо всі виконали зміну) |
| Розподіл | Лідер групи може налаштувати **відсотки** виплат у меню |

Приклад: 10 мішків × 350$ = 3 500$ для одного гравця. У команді з 4 осіб загальний пул може бути вищим — залежно від налаштувань лідера.

## Додаткові знахідки

Під час збору сміття з **невеликим шансом** може випасти предмет:

| Предмет | Шанс (орієнтовно) |
| --- | --- |
| <p>Крипто-накопичувач</p><p>![](../.gitbook/assets/cryptostick.png)</p> | ~0,5% за мішок |

Не розраховуйте на це як на основний заробіток — це приємний бонус.

## Обмеження та кулдауни

| Параметр | Значення |
| --- | --- |
| Кулдаун після зміни | **2 години** до наступного повного циклу |
| Оновлення смітників | Контейнер «відновлюється» приблизно через **10–15 хвилин** після спустошення |
| Штраф без машини | **~5 000$** |

## Поради

1. Працюйте **маршрутом по кварталах** — не чекайте одного смітника.
2. Тримайте **гаманець** і посвідчення **C** завжди в інвентарі.
3. Для першого заробітку поєднуйте з [батлпасом](../basics/battlepass.md).
4. Якщо хочете роботу **без вантажівки** — спробуйте [миття вікон](window-cleaner.md) (потрібна категорія **B**).

## Якщо щось не працює

| Проблема | Рішення |
| --- | --- |
| «Потрібне посвідчення C» | Здайте на категорію C в [автошколі](../transport/driving-school.md) |
| Немає гаманця | Купіть у [мерії](../basics/city-hall.md) (~2 000$) |
| Машина не з’явилась | Звільніть місце на стоянці біля бази |
| Не зарахували оплату | Переконайтесь, що пройшли **розвантаження** і повернули вантажівку |
