# Водій автобусу

Регулярні **міські маршрути** з зупинками та пасажирами-NPC. Потрібен **1 рік стажу** в штаті.

## Коротко про роботу

| Параметр | Значення |
| --- | --- |
| Стаж | **1 рік** |
| Депо | Автобусне депо (~462, -641) — маршрут з ![](../.gitbook/assets/blips/419.png) центру зайнятості |
| Оплата | **~670$+** за маршрут (залежить від лінії та рівня) |
| Досвід | Накопичується за рейси — відкриваються нові маршрути |
| Посвідчення | **Категорія C** для великого автобуса |

## Як влаштуватись

1. ![](../.gitbook/assets/blips/419.png) [Центр зайнятості](../basics/city-hall.md) → **Водій автобуса**.
2. Приїдьте в депо за маршрутом.
3. Відкрийте **меню автобусника** → оберіть **маршрут** (доступні залежать від рівня).

## Покрокова зміна

1. Заберіть **автобус** на точці видачі.
2. Їдьте за GPS до **зупинок** по колу.
3. На кожній зупинці — чекайте, поки **пасажири сядуть** (NPC).
4. Завершите коло → отримайте **гроші та досвід**.
5. Поверніть автобус або беріть наступний маршрут.

{% hint style="warning" %}
Якщо вийти з автобуса надовго — через **~2 хв** він може **зникнути**. Завершуйте маршрут без довгих пауз.
{% endhint %}

## Приклади маршрутів

| Маршрут | Рівень | Орієнтовна оплата |
| --- | --- | --- |
| La Mesa | 1 | **~670$** |
| Інші лінії | 2+ | Вище — див. меню в депо |

## Поради

- Починайте з **коротких** маршрутів рівня 1.
- Дотримуйтесь зупинок — пасажири не сідають, якщо проїхати повз.
- Перемикайте роботу через **`F1`** → **Про мене** → **Робота**, якщо працюєте на кількох вакансіях.
