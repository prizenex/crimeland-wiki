# Гольф

Поле для гольфу — вбудована локація GTA / додаткові скрипти в `[games]`.

### Як грати

1. Приїдьте на **Golf Club** (північна частина карти).
2. Орендуйте ключки в клубі (якщо потрібно).
3. Проходьте лунки по маршруту, бийте по м'ячу за підказками.
4. Найменша кількість ударів — перемога.

Спокійна RP-активність для бізнес-зустрічей і відпочинку.
