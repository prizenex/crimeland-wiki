# Гольф

**Golf Club** — спокійна RP-активність на півночі карти (район Vinewood Hills). Підходить для бізнес-зустрічей і відпочинку.

## Де грати

| Орієнтир | Деталі |
| --- | --- |
| Клуб | Північ LS, **Golf Club** — лобі біля входу на поле |
| Старт | Підійдіть до точки лобі → **`E`** |

## Як грати

1. Приїдьте на **Golf Club**.
2. Відкрийте меню лобі → **`E`**.
3. Орендуйте **карт** (~**300$**) — він довезе по полю.
4. Для ударів потрібен **ключка для гольфу** в інвентарі (купівля або своя).
5. Проходьте **лунки** за маршрутом — на мапі підказки до наступної.
6. Перемагає той, хто зробив **менше ударів** (ліміт ~10 на лунку).

## Поради

- Увімкнено **ставки** між гравцями — домовтесь IC перед матчем.
- Вночі на полі працює підсвітка м’яча та лунки.
- Після гри — [спортзал](../character/sport.md) ![](../.gitbook/assets/blips/311.png) для відновлення [статусів](../character/statuses.md).
