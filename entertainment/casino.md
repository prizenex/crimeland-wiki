# Казино

**Diamond Casino** — легальні азартні ігри в центрі місту. Вхід біля головного входу казино на мапі (район Vinewood).

### Фішки

- Купуйте **фішки казино** у касі (1 фішка = **100$**).
- Грайте в слоти, рулетку, **Inside Track**, колесо фортуни.
- При виході — обміняйте фішки назад (курс викупу ~**90%** від номіналу).

### Ігри

| Гра | Де |
| --- | --- |
| Слоти | Зал автоматів |
| Рулетка | Ігрові столи |
| Inside Track | Скачки |
| Колесо фортуни | Щоденний бонус (якщо доступно) |
| Бар | Напої та RP |

### Правила

- Грайте відповідально — це розвага, не основний заробіток.
- [Пограбування казино](../crime/casino-robbery.md) — окрема кримінальна активність, не частина легального візиту.

Підійдіть до столу або автомата — меню відкриється автоматично.
