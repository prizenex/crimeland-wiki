# Бойові мистецтва

Тренування та дуелі **один на один** у трьох зонах міста. Це **RP-розвага**, не заміна зброї в кримінальних сценах.

## Де тренуватись

| Стиль | Орієнтир |
| --- | --- |
| Додзьо | Південь LS (~-828, -696) |
| Бокс | **Vespucci Beach** (~-1211, -1576) |
| MMA | **Rockford Hills** (~982, -93) |

Підійдіть до **тренера-NPC** → **`E`** / підказка → навчіться стилю бою.

## Як битися

| Дія | Клавіша (орієнтир) |
| --- | --- |
| Удар | **R** |
| Ухилення вліво | **Q** |
| Ухилення вправо | **D** |
| Ухилення назад | **Пробіл** |

Перемога — за здоров’ям / рахунком раундів. Домовтесь про правила **до** бою IC.

## Поради

- У зонах бою **урон гравцям увімкнений** — майте бандаж або викличте [EMS](../ems/getting-started.md).
- Не використовуйте бій як Powergaming у затриманнях.
- Після тренування — [спортзал](../character/sport.md) ![](../.gitbook/assets/blips/311.png).
