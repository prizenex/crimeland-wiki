# BMX

BMX — екстремальний транспорт для трюків. Купується в **спортивних магазинах** (наприклад, біля Venice Beach).

### Як почати

1. Купіть **BMX** у спортивному магазині на мапі.
2. Використайте предмет в інвентарі — з'явиться велосипед.
3. Сідайте та катайтесь; трюки — миша та клавіші з підказок на екрані.

### Швидке меню спорту

Утримуйте **`V`** — радіальне меню для перемикання між BMX, скейтом, роликами тощо.

### Поради

- Зберігайте BMX через меню магазину, щоб не втратити при виході з гри.
- Не використовуйте BMX для втечі від поліції без RP-наслідків.
