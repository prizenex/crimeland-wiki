# BMX

BMX — екстремальний транспорт для трюків. Купується в **спортивних магазинах** (Venice Beach, Xtreme Store).

## Де купити

| Магазин | Орієнтир |
| --- | --- |
| Venice Beach | Набережна **Venice** (захід LS) |
| Xtreme Store | Центр міста, біля **Legion Square** (~274, 136) |

## Як кататись

1. Купіть **BMX** → використайте предмет в [інвентарі](../character/inventory.md).
2. Сідайте на велосипед і їдьте.
3. Трюки — комбінації клавіш з підказок на екрані.

### Основні трюки

| Трюк | Клавіша (орієнтир) |
| --- | --- |
| Barspin | **ЛКМ** |
| Tailwhip | **C** |
| Superman | **ПКМ** |
| Bike flip | **G** |
| Wheelie | **L Ctrl** |

### Пасажир

Поруч із другом на BMX: **`F`** — сісти на «пеги» (якщо велосипедист уже їде).

## Швидке меню спорту

Утримуйте **`V`** — перемикання між BMX, скейтом, роликами.

## Поради

- Зберігайте BMX через меню магазину або **`E`** біля велосипеда.
- Мінімальна швидкість для трюків — ~1 км/год.
- Не використовуйте BMX для втечі без RP-наслідків.
