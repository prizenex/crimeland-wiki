# Більярд

Більярдні столи — у **барах та клубах** по місту.

### Як грати

1. Знайдіть більярдний стіл (бар, клуб).
2. Підійдіть до столу, `E` / `лівий Alt` → **«Грати»**.
3. Керуйте кием за підказками на екрані.
4. Можна грати з другом — по черзі.

Ставки та правила (8-ball, 9-ball) домовляйте IC перед партією.
