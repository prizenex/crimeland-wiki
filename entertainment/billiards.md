# Більярд

Більярдні столи стоять у **барах, клубах і казино** по місту. Це публічна розвага — вакансія в центрі зайнятості не потрібна.

## Як грати

1. Знайдіть **більярдний стіл** (бар, клуб, Diamond Casino).
2. Підійдіть до столу → **`E`** / **`лівий Alt`** → **«Грати»**.
3. Керуйте кием за підказками на екрані.
4. Грайте з другом **по черзі** — один стіл, одна партія.

## Правила IC

| Тема | Рекомендація |
| --- | --- |
| Формат | 8-ball або 9-ball — домовтесь **до** партії |
| Ставки | Опціонально, лише за згодою обох гравців |
| Черга | Не займайте стіл, якщо вже грають |

## Поради

- Не блокуйте прохід у барі — інші гості теж хочуть грати.
- Після гри можна продовжити вечір у [казино](casino.md) або на [баскетбольному майданчику](basketball.md).
