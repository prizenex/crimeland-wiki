# Паркур

Паркур — пересування зі стрибками, карабканьем і трюками. Режим увімкнено **на всьому сервері** — NPC і окрема «реєстрація» не потрібні.

## Як увімкнути

**`Caps Lock` + `Alt`** (утримувати **обидві** клавіші) — увімкнути або вимкнути режим паркуру.

Працює **будь-де** в місті. Не спрацює, якщо персонаж у наручниках, без свідомості або в стані смерті/нокауту.

## Де зручно тренуватись

| Зона | Орієнтир |
| --- | --- |
| Пляж | **Vespucci Beach** (захід LS) |
| Будівля | Центр LS, біля **Legion** (~165, -68) |
| Доки | **Порт** (південь LS) |

## Основні рухи

| Рух | Клавіші (орієнтир) |
| --- | --- |
| Стрибок / сальто | **Пробіл** + **W/A/S/D** |
| Паркур по стіні | **ЛКМ** біля стіни |
| Wallflip | **E** на стіні вперед |
| Ковзання | **C** під час бігу |
| Приземлення з перекату | **R** під час падіння |

Підказки з’являються на екрані після активації режиму.

## Поради

- Падіння з висоти **>30 м** можуть вбити — стежте за [статусами](../character/statuses.md).
- Не заважайте проходу — зони публічні.
- Для RP-змагань домовтесь про маршрут і суддівство IC.
