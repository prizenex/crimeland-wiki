# Керування

Більшість щоденних дій доступна через інвентар, радіальне меню та взаємодію з об'єктами. Нижче наведені стандартні клавіші; якщо ви їх змінювали, перевірте власні налаштування FiveM.

### Основні клавіші

| Клавіша | Дія |
| --- | --- |
| `Esc` | Меню паузи та налаштування |
| `P` | Мапа |
| `Tab` | [Інвентар](../character/inventory.md) |
| `M` | [Телефон](phone.md) |
| `F1` | [Радіальне меню](../controls/radial.md) — одяг, робота, [житло](../housing/house-management.md), улюбленці |
| `F4` | [Меню сервера](server-menu.md) |
| `F10` | [Батлпас](battlepass.md) |
| `U` | [Емоції / анімації](../character/animations.md) |
| `~` | Цикл режиму [голосу](radio.md) (шепіт / нормально / крик) |
| `E` / `лівий Alt` | Взаємодія з NPC та об'єктами — [два режими таргета](#два-режими-таргета-звичайний-та-імерсивний) |
| `E` | Окремі **маркери** та скриптові точки, де на екрані явно показано підказку `E` (не таргет) |

## Взаємодія з NPC та об'єктами

Більшість дій у місті (банк, магазин, робота, EMS на пацієнта тощо) відкривається через **систему таргета**. У гайдах це позначають як **`E`** / **`лівий Alt`** — залежно від того, який режим у **вас** обрано.

### Два режими таргета: звичайний та імерсивний

| Режим | **Звичайний** | **Імерсивний** |
| --- | --- | --- |
| **Як виглядає** | Біля NPC / об'єкта з'являється **кружечок** | При утриманні Alt — **око** на цілі, список дій біля прицілу |
| **Що натискати** | **`E`** на кружечку | Утримувати **`лівий Alt`** → навести приціл → **ЛКМ** ![](../.gitbook/assets/inputs/mouse-lmb.svg) по дії |
| **Коли зручніше** | Швидкі побутові дії, магазини, банк | RP-сцени, коли не хочете «кружечків» на екрані |
| **У налаштуваннях** | Режим **«Звичайний»** | Режим **«Імерсивний»** |

**Як перемкнути режим:** відкрийте **налаштування таргета** (глобальне меню взаємодії) → **«Режим таргета»** → оберіть **Звичайний** або **Імерсивний**.

{% hint style="info" %}
Якщо в іншому гайді написано **`E`** / **`лівий Alt`** — це **одна й та сама** взаємодія, просто в різних режимах. Не шукайте обидві клавіші одночасно: дивіться **підказку на екрані** або свій обраний режим у таблиці вище.
{% endhint %}

Так працюють [банк](bank.md), [центр зайнятості](city-hall.md), [магазини](shops.md), робочі NPC, дії поліції/EMS на гравця тощо.

Окремо від таргета частина точок (маркетплейс, деякі роботи, старі маркери) показує лише **`E`** без кружечка — орієнтуйтесь на текст підказки.

### Дії в інвентарі

Правою кнопкою відкрийте меню предмета та оберіть потрібну дію. Для використання також доступні подвійний клік або `Alt` + ліва кнопка миші.

`Shift` + ліва кнопка ділить стек навпіл. `Ctrl` + ліва кнопка викидає предмет на землю, а `Ctrl` + `Shift` + ліва кнопка — половину стека. Уважно користуйтесь цими комбінаціями біля цінних речей.

### Голос і рація

Увімкніть голосовий чат у налаштуваннях гри та оберіть мікрофон.

| Клавіша | Дія |
| --- | --- |
| `~` | Перемкнути **дальність голосу поруч** (шепіт / нормально / крик) |
| **`9`** | **Говорити в [рацію](radio.md)** — утримувати під час мовлення |

**`9`** працює **лише після підключення до хвилі** в рації. Хвилі **1–10** — службові (поліція, EMS тощо на зміні); цивільним доступні **11–500**. Деталі — у статті [Рація](radio.md).

## Авто: ключі, двигун, бардачок, багажник

Більшість дій з **вашим** або **орендованим** авто — окремі клавіші FiveM плюс таргет на кузові. Без **ключів** до машини двигун зазвичай **не заводиться** (окрім hotwire або якщо мотор уже працював).

### Клавіші (FiveM)

Перевірте: **Esc → Налаштування → Призначення клавіш → FiveM** — рядки **«Перемкнути замки автомобіля»**, **«Перемкнути двигун»**, **«Спроба взлому»** (hotwire), **«Відкрити інвентар»** / **«Відкрити додатковий інвентар»**.

| Клавіша | Дія | Коли працює |
| --- | --- | --- |
| **`L`** | **Замок / розблокування** дверей | Поруч із авто або всередині; потрібні **ключі** від цієї машини |
| **`G`** | **Увімкнути / вимкнути двигун** | Ви на **місці водія** |
| **`H`** | **Завести без ключів** (hotwire, міні-гра) | Водій, двигун **заглушений**, ключів **немає**; не на службових/чорному списку авто |
| **`Tab`** | [Інвентар](../character/inventory.md); у салоні — **бардачок** | Сидите в авто → відкривається **бардачок** (якщо є); інакше — ваш інвентар |
| **`F2`** | **Додатковий інвентар** | Ззаду **відкритого** багажника — вміст багажника; біля сховищ — інші другі панелі (див. [інвентар](../character/inventory.md)) |

{% hint style="info" %}
Якщо **`Tab`** / **`F2`** не відкривають багажник — спочатку **відчиніть кришку** через таргет (нижче). **`F2`** дивиться на те, куди ви **націлились** — станьте ззаду авто.
{% endhint %}

### Через таргет на авто (`E` / `лівий Alt`)

Наведіть таргет на **двері, капот або зад** машини:

| Пункт у меню | Що робить |
| --- | --- |
| **Багажник** | Відкрити / закрити **кришку** багажника |
| **Вміст багажнику** | Склад речей — лише якщо кришка **відчинена** |
| **Капот** | Відкрити / закрити капот (де є) |
| **Двері** | Окремі двері авто |
| **Залізти в багажник** | Якщо багажник **відкритий** — також **`F1`** → [Активні дії](../controls/radial.md) |

Типовий порядок для речей у багажнику: **`L`** (розблокувати) → таргет **«Багажник»** → **«Вміст багажнику»** або **`F2`** ззаду.

### Як це пов’язано

| Ситуація | Що відчуєте |
| --- | --- |
| **Немає ключів**, двигун заглушений | Не поїдете, поки не **`H`** (hotwire) або не отримаєте ключі |
| **Замок увімкнено** (`L`) | Двері закриті; спочатку розблокуйте |
| **Бардачок** | Тільки **в салоні**, клавіша **`Tab`** (не плутати з багажником ззаду) |
| **Багажник** | Кришка через таргет; **речі** — коли кришка відкрита |
| **Чуже / NPC авто** | Зазвichай **заблоковане**; потрібна відмичка, hotwire (**`H`**) або RP-отримання ключів |

Детальніше про слоти та перенесення речей — [Інвентар → Сховища та багажники](../character/inventory.md). Вуличний [збут з багажника](../crime/illegal-sales.md) вимагає **відкритої** кришки.

### Якщо клавіша не працює

Закрийте інше відкрите меню, перевірте призначення клавіш у розділі FiveM та спробуйте підійти ближче до точки. Деякі дії потребують предмета, роботи, ліцензії або перебування за кермом.

Для звернення до адміністрації відкрийте `F4` → **«Скарги / питання»**. Якщо потрібен ID іншого гравця, скористайтесь `F1` → **«Опції»** → **«Показати ID»**.
