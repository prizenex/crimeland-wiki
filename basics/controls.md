# Керування

Більшість щоденних дій доступна через інвентар, радіальне меню та взаємодію з об'єктами. Нижче наведені стандартні клавіші; якщо ви їх змінювали, перевірте власні налаштування FiveM.

### Основні клавіші

- **`Esc`** — меню паузи та налаштування
- **`P`** — мапа
- **`Tab`** — [інвентар](../character/inventory.md)
- **`M`** — [телефон](phone.md)
- **`F1`** — [радіальне меню](../controls/radial.md): одяг, робота, [житло](../housing/house-management.md), улюбленці
- **`F4`** — [меню сервера](server-menu.md)
- **`F10`** — [батлпас](battlepass.md)
- **`U`** — [емоції / анімації](../character/animations.md)
- **`~`** — дальність [голосу](radio.md) поруч (шепіт / нормально / крик)
- **`E`** / **`лівий Alt`** — взаємодія з NPC та об'єктами ([два режими таргета](#два-режими-таргета-звичайний-та-імерсивний))

## Взаємодія з NPC та об'єктами

Більшість дій у місті (банк, магазин, робота, EMS на пацієнта тощо) відкривається через **систему таргета**. У гайдах це позначають як **`E`** / **`лівий Alt`** — залежно від того, який режим у **вас** обрано.

## Два режими таргета: звичайний та імерсивний

- **Звичайний** — Біля NPC / об'єкта — **кружечок** → **`E`**. Зручно для магазинів, банку, швидких дій
- **Імерсивний** — Утримати **`лівий Alt`** → **око** на цілі → **ЛКМ** ![](../.gitbook/assets/inputs/mouse-lmb.svg) по дії. Зручно для RP без «кружечків»

**Перемкнути режим:** **`F1`** → [Радіальне меню](../controls/radial.md) → **ОПЦІЇ** → **Таргет** → **«Режим таргета»** → **Звичайний** або **Імерсивний**.

{% hint style="info" %}
Якщо в іншому гайді написано **`E`** / **`лівий Alt`** — це **одна й та сама** взаємодія в різних режимах. Дивіться **підказку на екрані**, а не шукайте обидві клавіші одночасно.
{% endhint %}

Так працюють [банк](bank.md), [центр зайнятості](city-hall.md), [магазини](shops.md), робочі NPC, дії поліції/EMS на гравця тощо.

Окремо від таргета частина точок (маркетплейс, деякі роботи, старі маркери) показує лише **`E`** без кружечка — орієнтуйтесь на текст підказки.

### Дії в інвентарі

Правою кнопкою відкрийте меню предмета та оберіть потрібну дію. Для використання також доступні подвійний клік або `Alt` + ліва кнопка миші.

`Shift` + ліва кнопка ділить стек навпіл. `Ctrl` + ліва кнопка викидає предмет на землю, а `Ctrl` + `Shift` + ліва кнопка — половину стека. Уважно користуйтесь цими комбінаціями біля цінних речей.

### Голос і рація

Увімкніть голосовий чат у налаштуваннях гри та оберіть мікрофон.

- **`~`** — перемкнути **дальність голосу поруч** (шепіт / нормально / крик)
- **`9`** — **говорити в [рацію](radio.md)** (утримувати під час мовлення)

**`9`** працює **лише після підключення до хвилі** в рації. Хвилі **1–10** — службові (поліція, EMS тощо на зміні); цивільним доступні **11–500**. Деталі — у статті [Рація](radio.md).

## Авто

Потрібні **ключі** від машини — без них **`G`** (двигун) зазвичай не спрацює. Ключі дають при покупці, оренді або в RP. Якщо ключів немає — **`H`** (hotwire, міні-гра), крім службових авто.

### Посадити і поїхати

1. **`L`** — розблокувати двері (поруч із авто або в салоні).
2. Сісти за кермо.
3. **`G`** — завести / заглушити двигун.

Немає ключів і мотор не працює — **`H`** на місці водія (hotwire).

### Бардачок (в салоні)

Сидите в машині → **`Tab`** → відкриється **бардачок** (якщо він є в цій моделі). Це **не** багажник ззаду.

### Багажник (ззаду авто)

Спочатку **кришка**, потім **речі** — це два різні кроки:

1. **`L`** — машина розблокована.
2. Таргет **`E`** / **`лівий Alt`** на зад машини → **«Багажник»** — відкрити кришку.
3. **`F2`** ззаду **або** таргет → **«Вміст багажнику»** — покласти / забрати речі.

Кришка закрита — вміст не відкриється. Станьте **ззаду** і дивіться на багажник, якщо **`F2`** «нічого не бачить».

Через таргет на кузові також доступні **капот**, **двері**, **залізти в багажник** (коли відкритий; також **`F1`** → [Активні дії](../controls/radial.md)).

Слоти та перенесення речей — [Інвентар → Сховища та багажники](../character/inventory.md).

### Якщо щось не працює

- **Двері не відкриваються** — **`L`** (можливо, авто на замку).
- **Не заводиться** — перевірте ключі; без них лише **`H`** або RP-отримання ключів.
- **Чужа машина** — зазвичай заблокована; hotwire або відмичка в RP.
- Закрийте інші меню та підійдіть ближче до авто.

Для звернення до адміністрації відкрийте `F4` → **«Скарги / питання»**. Якщо потрібен ID іншого гравця, скористайтесь `F1` → **«Опції»** → **«Показати ID»**.
