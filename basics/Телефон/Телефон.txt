Загальна інформація

Телефон — це один з основних засобів комунікації та взаємодії з різними системами штату. За його допомогою гравець може спілкуватися з іншими мешканцями, користуватися соціальними мережами, переглядати інформацію про роботу, керувати фінансами, транспортом та використовувати інші доступні сервіси.
Для того щоб відкрити або закрити телефон, необхідно натиснути клавішу M.
Розблокування телефону:
Після відкриття телефону спочатку відображається екран блокування.
Для розблокування необхідно:
1. Натиснути на білу смужку, розташовану в нижній частині екрана.
2. Якщо на телефоні встановлений пароль, після цього відкриється вікно для його введення.
3. Введіть встановлений 4-значний пароль.
4. Після правильного введення пароля відкриється головний екран телефону.
Якщо захист паролем не встановлений, додаткове введення коду не знадобиться.
Програми телефону:
Телефон містить велику кількість застосунків, кожен із яких відповідає за певну функцію. Для перегляду всіх програм використовуйте дві сторінки головного екрана.
Пташка:
Соціальна мережа для публікації дописів та перегляду публікацій інших мешканців штату.
Інста-пік:
Соціальна мережа, орієнтована на публікацію та перегляд фотографій. Також проведення та перегляду прямої трансляції.
TikTут:
Застосунок для публікації та перегляду коротких відеороликів.
Торгова площадка:
Додаток для публікацій продажу або покупки траспорту, предметів тощо.
Криптовалюта: Застосунок для взаємодії з доступною на сервері системою криптовалют.

Дарк-нет:

Окремий сервіс, пов’язаний із нелегальною та кримінальною діяльністю. Використовується для зв’язку між різними фракціями 
Browser:
Внутрішньоігровий браузер, через який можна користуватися доступними вебресурсами.
Праця:
Розділ, пов’язаний із працевлаштуванням та доступними роботами. Корисний насамперед для новачків, які шукають спосіб заробітку.
Налаштування:
Дозволяють налаштувати телефон та змінити доступні параметри пристрою.
Застосунки:
Розділ для роботи з додатковими застосунками телефону.
Годинник:
Дозволяє користуватися функціями, пов’язаними з часом.
Пошта:
Застосунок для роботи з електронною поштою та повідомленнями, які надходять на неї. Також в цьому застосунку надають додаткову інформацію про взлом особистої машини, знищення тощо.
Погода:
Дозволяє переглядати інформацію про поточні погодні умови.
Гаманець
Використовується для роботи з фінансами та платіжними функціями телефону. Через цей застосунок ви можете відправляти кошти людині, але перед цим переконайтесь що дана людина є в ваших контактах
Гараж:
Дозволяє переглядати інформацію про власні транспортні засоби. При виборі автівки в цьому додатку ви зможете переглянути стан, геолокацію (якщо ви залишили її десь на вулиці) або в якому гаражі вона знаходиться.
Мій будинок:
Розділ, пов’язаний із нерухомістю гравця та інформацією про неї (геолокація, керування ключами).
Карти:
Використовуються для навігації та пошуку необхідних місць.
Нотатки:
Дозволяють створювати та зберігати особисті текстові записи.
Калькулятор:
Стандартний застосунок для виконання математичних розрахунків.
Диктофон:
Призначений для використання функцій запису аудіо.
Музика:
Застосунок для використання доступних функцій, пов’язаних із прослуховуванням музики (наразі не працює).
Послуги:
Розділ для перегляду та використання доступних внутрішньоігрових послуг. В цьому застосунку ви зможете подивитись служби наявні в штаті, якщо поруч з цією службою є кнопка дзвінка - гравець може звернутись до цієї служби та викликати її ( поліція, механіки, медики і т.д.)  Контакти: Використовується для відправки повідомлень і для дзвінків. Для того що з кимось обмінятись своїм контактом треба зайди в додаток, з самого вверху буде надпис: Телефон ( Ваше ім’я ), натиснувши на нього вам відкриється ваш контакт, справа ви знайдете кнопку “Поділитись”, після чого ви вибираєте свого друга з яким хочете поділитись контактом.
