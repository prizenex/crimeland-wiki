# Банк

Банківський рахунок потрібен для зберігання грошей, переказів і покупок карткою. **Готівка** і **баланс рахунку** — різні кошти: перед покупкою перевіряйте обраний спосіб оплати.

## Де знайти банк

На мапі (`P`) — бліп ![](../.gitbook/assets/blips/108.png) **«Банк»**. У відділенні:

1. Підійдіть до працівника.
2. `лівий Alt` → **«Банк»**.

Банкомати стоять біля відділень і в місті — взаємодія через `лівий Alt` на корпусі апарата.

## Особистий рахунок

### Покласти або зняти

1. Відкрийте особистий рахунок у меню банку або банкомата.
2. Оберіть **внесення** або **зняття**.
3. Введіть суму → підтвердіть.
4. Перевірте баланс і **історію операцій**.

| Операція | Умова |
| --- | --- |
| Внесення | Готівка при собі |
| Зняття | Достатній залишок на рахунку |

### Банківська картка та PIN

У відділенні банку:

1. **«Налаштування рахунку»**.
2. Задайте **PIN-код**.
3. **«Замовити»** картку — залиште слот в інвентарі.

Біля банкомата: майте картку при собі, введіть PIN, коли система запитає.

{% hint style="info" %}
Якщо біля банкомата немає дії — підійдіть ближче до корпусу. У відділенні меню відкривається через працівника.
{% endhint %}

## Перекази

### Іншому гравцю (через банк)

У меню банку — **зовнішній переказ**:

| Поле | Що вказати |
| --- | --- |
| Рахунок списання | Ваш особистий |
| Сума | Сума переказу |
| Одержувач | **Citizen ID / Passport ID** (не ID над головою) |

Одержувач має бути **в грі**. Перед підтвердженням звірте ID з людиною. Свій Passport ID — у [меню сервера](server-menu.md).

### Через телефон

У [телефоні](phone.md) → **«Гаманець»** можна переказати кошти контакту. Зручно для швидких угод без поїздки до банку.

## Спільні рахунки

Для спільних витрат (організація, друзі, бізнес-партнери):

| Параметр | Значення |
| --- | --- |
| Ліміт створення | До **2** спільних рахунків на персонажа |
| Доступ | Додайте користувачів за Citizen ID |
| Видалення | Спочатку зніміть залишок |

Додавайте лише тих, кому довіряєте доступ до коштів.

### Службові рахунки

Рахунки **роботи**, **банди** або **сім’ї** з’являються в меню залежно від посади та повноважень. Якщо рахунок недоступний — уточніть у керівника.

## Готівка vs картка

| Де | Що приймають |
| --- | --- |
| Більшість магазинів | Готівка і картка |
| [Маркетплейс](marketplace.md) | На вибір при покупці |
| ЦНАП (документи) | Лише **готівка** |
| Оренда транспорту | Готівка або банк (у меню оренди) |

Операції з рахунком також відображаються в **«Гаманці»** телефону (якщо увімкнено історію).

## Якщо щось пішло не так

1. Перевірте, з якого балансу списались кошти (готівка / банк).
2. Перегляньте історію в банкоматі або телефоні.
3. Для спірних переказів — `F4` з часом операції та Passport ID одержувача.
