# Банк

Тут ви зберігаєте гроші, переказуєте кошти іншим гравцям і оплачуєте покупки карткою замість готівки. Пам'ятайте: готівка в кишені та баланс на рахунку — це різні гроші, тож перед оплатою перевірте, яким способом платите.

## Де знайти банк

На мапі (`P`) — бліп ![](../.gitbook/assets/blips/108.png) **«Банк»**. У відділенні підійдіть до працівника і відкрийте меню через **`E`** / **`лівий Alt`** ([Керування](controls.md)) → **«Банк»**. Банкомати стоять біля відділень і в місті — та сама взаємодія через таргет на корпусі апарата.

## Особистий рахунок

Відкрийте особистий рахунок у меню банку чи банкомата, оберіть **внесення** або **зняття**, введіть суму і підтвердьте — баланс і **історія операцій** оновляться відразу. Внесення потребує готівки при собі, зняття — достатнього залишку на рахунку.

### Картка та PIN

У відділенні банку відкрийте **«Налаштування рахунку»**, задайте **PIN-код** і замовте картку — залиште для неї вільний слот в інвентарі. Біля банкомата достатньо мати картку при собі й ввести PIN, коли система запитає.

{% hint style="info" %}
Якщо біля банкомата немає дії — підійдіть ближче до корпусу. У відділенні меню відкривається лише через працівника.
{% endhint %}

## Перекази

### Іншому гравцю (через банк)

У меню банку — **зовнішній переказ**. Вкажіть ваш особистий рахунок списання, суму та **Citizen ID / Passport ID** одержувача (не ID над головою). Одержувач має бути **в грі**; перед підтвердженням звірте ID з людиною.

**Де взяти Citizen ID:** на **ID-картці** в [гаманці](documents.md) — поле **Citizen ID**; номер можна **виділити й скопіювати** з картки. Той самий номер у [меню сервера](server-menu.md) підписаний як **Passport ID**.

### Через телефон

У [телефоні](phone.md) → **«Гаманець»** можна переказати кошти контакту. Зручно для швидких угод без поїздки до банку.

## Спільні рахунки

Для спільних витрат — з організацією, друзями чи бізнес-партнерами:

- **Ліміт створення** — до **2** спільних рахунків на персонажа
- **Доступ** — додайте користувачів за **Citizen ID** (Passport ID)
- **Видалення** — спочатку зніміть залишок

**Citizen ID партнера** — на його **ID-картці** в [гаманці](documents.md), поле **Citizen ID**. Попросіть **показати** картку — номер можна **скопіювати** й вставити в банку при додаванні до спільного рахунку. Додавайте лише тих, кому довіряєте доступ до коштів.

### Службові рахунки

Рахунки **роботи**, **банди** або **сім'ї** з'являються в меню залежно від посади та повноважень. Якщо рахунок недоступний — уточніть у керівника.

## Готівка vs картка

- **Більшість магазинів** — готівка і картка
- **[Маркетплейс](marketplace.md)** — оберіть спосіб оплати при покупці
- **ЦНАП (документи)** — лише готівка
- **Оренда транспорту** — готівка або банк (у меню оренди)

Операції з рахунком також відображаються в **«Гаманці»** телефону (якщо увімкнено історію).

## Якщо щось пішло не так

Перевірте, з якого балансу списались кошти — готівка чи банк, і перегляньте історію в банкоматі або телефоні. Для спірних переказів звертайтесь через `F4` з часом операції та Passport ID одержувача.
