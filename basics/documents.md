# Документи

Документи підтверджують особу та дозволи персонажа. На сервері вони зберігаються в <img src="../.gitbook/assets/wallet.png" alt="Гаманець" data-size="line"> **гаманці** — предметі в [інвентарі](inventory.md), який ви тримаєте при собі.

## Гаманець

| Предмет | Деталі |
| --- | --- |
| <img src="../.gitbook/assets/wallet.png" alt="Гаманець" data-size="line"> **Гаманець** | Єдиний предмет у [інвентарі](../character/inventory.md); усі картки **всередині** |
| На старті | Видається разом із телефоном і базовим набором |
| Де тримати | Особистий інвентар — без гаманця не відкриється меню документів |

Окремих ID-карток, прав чи ліцензій у слотах інвентаря **немає** — лише меню гаманця. Втратили <img src="../.gitbook/assets/wallet.png" alt="Гаманець" data-size="line"> **гаманець** — купіть новий на прилавку в [мерії](city-hall.md) (там же, де продаються підручники з законами).

## Як переглянути документи

1. `Tab` → інвентар.
2. **ПКМ** ![](../.gitbook/assets/inputs/mouse-rmb.svg) на <img src="../.gitbook/assets/wallet.png" alt="Гаманець" data-size="line"> **«Гаманець»** → **«Використати»**.
3. Оберіть потрібну картку в меню гаманця.

На **ID-картці** вказано **Citizen ID** — це ваш постійний ідентифікатор (у [меню сервера](server-menu.md) той самий номер як **Passport ID**). Його можна **виділити й скопіювати** з картки (для [банківських переказів](bank.md) або спільного рахунку).

## Показати іншій людині

1. Станьте поруч із гравцем.
2. Відкрийте <img src="../.gitbook/assets/wallet.png" alt="Гаманець" data-size="line"> **гаманець** → оберіть картку.
3. Натисніть **«Показати»** (не «Передати»).

{% hint style="warning" %}
**«Показати»** і **«Передати»** — різні дії. Передача може забрати картку з вашого гаманця. Для перевірки особи завжди використовуйте показ.
{% endhint %}

## Які документи бувають

| Документ | Для чого |
| --- | --- |
| ID-картка | Підтвердження особи; **Citizen ID** на картці — для [переказів і спільних рахунків](bank.md) |
| Водійське посвідчення | Керування ТЗ, перевірка категорій на роботах |
| Ліцензія на зброю | Дозвіл на зброю |
| Службове / бізнес-посвідчення | Робота та повноваження організації |
| Інші ліцензії | Мисливство, медична тощо — за наявності в меню |

### Де оформити або відновити картку

| Документ | Де |
| --- | --- |
| ID, водійське A/B/C | ![](../.gitbook/assets/blips/419.png) [Мерія](city-hall.md) → ЦНАП (**2 500$** готівкою) |
| Бізнес-карта | ![](../.gitbook/assets/blips/419.png) [Мерія](city-hall.md) → ЦНАП (**10 000$**, потрібна робота) |
| Категорія водіння (перший раз) | [Автошкола](../transport/driving-school.md) → потім картка в ЦНАП |
| Ліцензія на зброю | Поліцейський департамент (**50 000$**) |

Після видачі в ЦНАП картка з’являється **всередині гаманця** — окремий предмет у інвентарі не потрібен.

## Якщо документ втрачено

1. Перевірте інвентар — чи є <img src="../.gitbook/assets/wallet.png" alt="Гаманець" data-size="line"> **гаманець**.
2. Відновіть картку в [мерії](city-hall.md) (готівка).
3. Службові посвідчення — через керівника організації.
4. Немає потрібної дії — `F4` в тікет з описом проблеми.

## Закони під рукою

У мерії на прилавку продаються **підручники** з текстами законів (окремі предмети в інвентарі). Повний набір також у вікі: [Конституція](../laws/constitution.md).
