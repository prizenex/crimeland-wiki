# Мерія

Мерія (ЦНАП) — головна точка для **працевлаштування**, **оформлення документів** і пошуку адрес бізнесів. На мапі шукайте **«Центр зайнятості»** біля адміністративної будівлі в центрі міста.

## Центр зайнятості

### Як знайти першу роботу

1. Підійдіть до працівниці центру зайнятості.
2. `лівий Alt` → **«Відкрити центр зайнятості»**.
3. Вкладка **«Вакансії»** → оберіть професію.
4. Прочитайте опис, оформіть працевлаштування, прокладіть маршрут.
5. На місці зверніться до роботодавця, щоб **почати зміну**.

{% hint style="info" %}
Працевлаштування і початок зміни — **різні** кроки. Маршрут лише показує, куди їхати; спорядження та умови перевіряються на робочій точці.
{% endhint %}

### Зручні стартові вакансії

| Робота | Гайд |
| --- | --- |
| Прибиральник | [Прибирання](../jobs/cleaner.md) |
| Мийник вікон | [Миття вікон](../jobs/window-cleaner.md) |
| Кур'єр | [Доставка](../jobs/courier.md) |
| Садівник | [Садівництво](../jobs/gardening.md) |

Перед орендою робочого транспорту перевірте вимоги у гайді конкретної роботи (посвідчення, гаманець, інструменти).

### Зміна роботи

| Що потрібно | Як зробити |
| --- | --- |
| **Оформити нову вакансію** | Центр зайнятості → **«Вакансії»** → оберіть професію |
| **Перемкнути активну роботу** | **`F1`** → **Про мене** → **Робота** (або **`/multijob`**) |

У меню робіт видно всі оформлені професії (до **4**). Оберіть потрібну — вона стане **активною** без повторного візиту в центр зайнятості.

{% hint style="info" %}
**Працевлаштування** (нова вакансія) і **перемикання активної** — різні дії. Спочатку оформлюєте роботу в центрі зайнятості, потім перемикаєтесь через [радіальне меню](../controls/radial.md).
{% endhint %}

## Бізнеси в місті

Вкладка **«Бізнеси в місті»** — довідник адрес:

- Ammunation, Benny's, спортзал;
- тату- та nail-салони;
- Premium Deluxe Motorsport, Weed Shop тощо.

Оберіть заклад → **маршрут на мапі**. Це не вакансії: щодо роботи в закладі звертайтесь до працівників або через **«Послуги»** в [телефоні](phone.md).

## Документи та гаманець

### Фізичний гаманець

Предмет **«Гаманець»** видається **на старті** разом із телефоном і базовим набором речей. Тримайте його в [інвентарі](../character/inventory.md) — без предмета не відкриється меню з картками документів.

Якщо гаманець втрачено — зверніться через `F4` → **«Скарги / питання»**.

### Оформлення карток у ЦНАП

У мерії через меню ЦНАП можна **видати або відновити** картки в **гаманці** (предмет у інвентарі):

| Документ | Вартість | Оплата |
| --- | --- | --- |
| ID-картка | **2 500$** | Готівка |
| Водійське A / B / C (картка в гаманці) | **2 500$** за оновлення / видачу | Готівка |
| Інші ліцензії з меню гаманця | **2 500$** (якщо передбачено в меню) | Готівка |
| Бізнес-карта | **10 000$** | Готівка (потрібна робота) |

{% hint style="warning" %}
Оплата в ЦНАП — **готівкою**. Мати готівку при собі перед візитом.
{% endhint %}

Після видачі відкрийте гаманець у інвентарі → **«Використати»** → оберіть потрібну картку. Детальніше — у розділі [«Документи»](documents.md).

### Ліцензія на зброю

Окремо від ЦНАП — у **поліцейському департаменті** (NPC біля відділку). Вартість **50 000$**, можлива перевірка судимості. Деталі — у розділі [поліції](../police/getting-started.md).

### Тексти законів

Конституція, кодекси та інші правові тексти можна придбати як предмети й читати з інвентаря. Повний набір також зібрано у вікі: [Конституція](../laws/constitution.md).

## Автошкола (посилання)

Підтвердження водійських категорій — в [автошколі](../transport/driving-school.md) (окрема точка біля аеропорту, бліп **«Автошкола»**). ЦНАП видає **картку** після складання, але не замінює навчання.
