# Адміністративний кодекс

Адміністративний кодекс — **дрібні правопорушення**: штрафи, попередження, короткі арештні санкції без важкої кримінальної статті.

## Де прочитати

Документ у [мерії](../basics/city-hall.md) → [гаманець](../basics/documents.md).

## Типові порушення

| Категорія | Приклади | Наслідки (орієнтир) |
| --- | --- | --- |
| ПДР | Перевищення, дрифт у місті | Штраф, евакуація авто |
| Публічний порядок | П'янство, шум, хуліганство | Штраф, короткий арешт |
| Невиконання вимог | Ігнор зупинки поліції | Штраф + ескалація до криміналу |

Додаткові штрафи з практики LSPD — у [таблиці вироків](../police/standard-sentences.md) (розділ «Додаткові штрафи»).

## Відмінність від криміналу

| Аспект | Адмінкодекс | [Кримінальний кодекс](criminal-code.md) |
| --- | --- | --- |
| Тяжкість | Легші санкції | Тюрма, великі штрафи |
| Приклад | Перевищення 3 000$ | Пограбування — місяці ув'язнення |
| Докази | Часто достатньо радара / свідків | Потрібні докази, MDT, суд |

{% hint style="info" %}
Офіцер може **понизити** кваліфікацію до адмінки за перше дрібне порушення — це RP-рішення, не обов'язок.
{% endhint %}
