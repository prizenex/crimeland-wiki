# Адміністративний кодекс

Адміністративний кодекс — дрібні правопорушення: штрафи, попередження, короткі арештні санкції без важкої кримінальної статті.

### Де прочитати

Документ у [мерії](../basics/city-hall.md) → гаманець.

### Типові порушення

- Порушення ПДР (перевищення, дрифт у місті).
- Публічне п'янство, шум.
- Невиконання законних вимог офіцера (в межах RP).

Відрізняйте від [кримінального кодексу](criminal-code.md) — адмінка зазвичай легша за наслідки.
