# Адміністративний кодекс

Адміністративний кодекс — **дрібні правопорушення**: штрафи, попередження, короткі арештні санкції без важкої кримінальної статті.

## Де прочитати

Документ у [мерії](../basics/city-hall.md) → [гаманець](../basics/documents.md).

## Типові порушення

- **ПДР**; Приклади: Перевищення, дрифт у місті; Наслідки (орієнтир): Штраф, евакуація авто
- **Публічний порядок**; Приклади: П'янство, шум, хуліганство; Наслідки (орієнтир): Штраф, короткий арешт
- **Невиконання вимог**; Приклади: Ігнор зупинки поліції; Наслідки (орієнтир): Штраф + ескалація до криміналу

Додаткові штрафи з практики LSPD — у [таблиці вироків](../police/standard-sentences.md) (розділ «Додаткові штрафи»).

## Відмінність від криміналу

- **Тяжкість**; Адмінкодекс: Легші санкції; [Кримінальний кодекс](criminal-code.md): Тюрма, великі штрафи
- **Приклад**; Адмінкодекс: Перевищення 3 000$; [Кримінальний кодекс](criminal-code.md): Пограбування — місяці ув'язнення
- **Докази**; Адмінкодекс: Часто достатньо радара / свідків; [Кримінальний кодекс](criminal-code.md): Потрібні докази, MDT, суд

{% hint style="info" %}
Офіцер може **понизити** кваліфікацію до адмінки за перше дрібне порушення — це RP-рішення, не обов'язок.
{% endhint %}
