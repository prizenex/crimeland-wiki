# Судовий кодекс

Судовий кодекс описує роботу судів, ролі суддів та адвокатів, призначення покарань і оскарження вироків.

### Де прочитати

Предмет у [мерії](../basics/city-hall.md) або документ у департаменті юстиції (DOJ).

### Процес (загалом)

1. Поліція передає справу з доказами.
2. Сторони (обвинувачення / захист) виступають у суді RP.
3. Суддя виносить вирок за [кримінальним](criminal-code.md) та [процесуальним](procedural-code.md) кодексами.
4. Відбування покарання — у державній в'язниці.

Цивільні спори (бізнес, контракти) також можуть вирішуватись у суді за домовленістю фракцій.
