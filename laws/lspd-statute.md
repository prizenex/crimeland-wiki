# Статут поліцейського департаменту Los Santos

Внутрішній регламент **LSPD**: дисцибліна, звання, процедури патруля, використання зброї та спецзасобів. Доповнює [закон про правоохоронні органи](law-enforcement-law.md) і [процесуальний кодекс](procedural-code.md).

## Ієрархія (типова)

| Ранг | Роль |
| --- | --- |
| Офіцер | Патруль, зупинки, первинне затримання |
| Сержант | Керівник зміни, нагляд за молодшими |
| Лейтенант / Капітан | Операції, ордери, дрон / K9 (за SOP) |
| Шеф | Політика департаменту, кадри |

Точні звання та доступ до спецзасобів визначає керівництво IC.

## Щоденні стандарти

| Тема | Вимога |
| --- | --- |
| Форма | Службова на зміні; бронежилет за SOP |
| Рація | Завжди на службовій частоті під час патруля |
| MDT | Звіти після кожного затримання — **`K`** |
| Зброя | Ескалація сили: голос → нелетальні → lethal за загрозою життю |
| Докази | [Криміналістика](../police/forensics.md) до очищення місця |

## Спецпідрозділи

| Підрозділ | Гайд |
| --- | --- |
| K9 | [Службові собаки](../police/k9.md) |
| Дрон | [Повітряне спостереження](../police/drone.md) |

## Для кандидатів

Після вступу в [поліцію](../police/getting-started.md) обов'язкове вивчення статуту на **співбесіді IC**. Повний текст — у службовому пакеті документів або Google Doc від керівництва.

{% hint style="info" %}
Порушення статуту IC може каратися дисциплінаркою (зниження, відсторонення) — це RP, не адмін-покарання, якщо не порушені правила сервера.
{% endhint %}
