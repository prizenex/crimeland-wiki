# Процесуальний кодекс

Процесуальний кодекс регулює **затримання**, **обшук**, **допит**, **адвоката** та передачу справи в суд.

## Для громадян

| Право | Що це означає |
| --- | --- |
| **Адвокат** | Можете вимагати після затримання |
| **Мовчання** | Не зобов'язані свідчити проти себе |
| **Обшук** | Лише за **ордером** або **законною підставою** (візуальний контакт, погоня, згода) |
| **Протокол** | Офіцер має пояснити причину затримання IC |

## Для поліції

1. [Посібник офіцера](../police/officer-guide.md) + цей кодекс.
2. Протокол затримання в [MDT](../police/database-terminal.md) — **`K`**.
3. Збір доказів — [криміналістика](../police/forensics.md) **до** евакуації з місця.
4. [Таблиця вироків](../police/standard-sentences.md) — орієнтир для статей і термінів.

## Типова послідовність затримання

| Етап | Дія |
| --- | --- |
| 1 | Зупинка з RP-підставою, ідентифікація |
| 2 | Наручники, короткий огляд (якщо законно) |
| 3 | Доставка у ![](../.gitbook/assets/blips/60.png) відділок |
| 4 | Допит, адвокат за запитом |
| 5 | Вирок / передача в суд |
| 6 | Звіт у MDT, конфіскація за номером інциденту |

## Обшук: коли можна без ордера

- **Візуальний контакт** — зброя / наркотики на виду.
- **Погоня** — підозрілий тікає після злочину.
- **Згода** громадянина IC.
- **Авто** — за правилами штату (зазвичай ордер або арешт власника).

{% hint style="info" %}
Спірні ситуації вирішуйте в **RP-суді** або через DOJ — не OOC-скандал у загальному чаті.
{% endhint %}
