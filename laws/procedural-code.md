# Процесуальний кодекс

Процесуальний кодекс регулює затримання, обшук, допит, адвоката та передачу справи в суд.

### Для громадян

- Право на **адвоката** після затримання.
- Право **мовчати** — не свідчити проти себе.
- Обшук лише за **ордером** або **законними підставами** (візуальний контакт, погоня).

### Для поліції

- [Посібник офіцера](../police/officer-guide.md) + цей кодекс.
- Протокол затримання в MDT.
- Збір доказів — [криміналістика](../police/forensics.md).

Повний текст — предмет у [документах](../basics/documents.md).
