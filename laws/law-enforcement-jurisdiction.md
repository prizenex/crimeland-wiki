# Юрисдикція та взаємодія правоохоронних органів

Документ розмежовує зони відповідальності **LSPD** (місто), **BCSO** (округ Blaine, Paleto), федеральних агентів та спецпідрозділів.

### Типові правила

| Зона | Первинна юрисдикція |
| --- | --- |
| Los Santos | LSPD |
| Paleto Bay, Sandy Shores | BCSO |
| Highway | LSPD + BCSO за домовленістю |
| Федеральні злочини | FIB / DOJ (RP) |

### Спільні операції

- Переслідування через кордони юрисдикції — радіо-координація.
- Спільні рейди — наказ старшого за званням / місією.
- Докази передаються з протоколом MDT.

У конфлікті юрисдикцій — RP-наказ керівництва, не OOC-спори в чаті.
