# Юрисдикція та взаємодія правоохоронних органів

Документ розмежовує зони відповідальності **LSPD** (місто), **BCSO** (округ Blaine, Paleto), федеральних агентів та спецпідрозділів.

## Карта юрисдикції

| Зона | Первинна юрисдикція | Відділок |
| --- | --- | --- |
| Los Santos (місто) | **LSPD** | ![](../.gitbook/assets/blips/60.png) Mission Row |
| Paleto Bay, Sandy Shores | **BCSO** | ![](../.gitbook/assets/blips/60.png) Paleto |
| Шосе / траса | LSPD + BCSO | За домовленістю по рації |
| Федеральні злочини | FIB / DOJ | RP-події |

## Спільні операції

| Ситуація | Правило |
| --- | --- |
| Погоня через кордон | Радіо-координація: «передаю в BCSO» / «беру на себе» |
| Спільний рейд | Наказ **старшого за званням** або за місією |
| Докази | Передача з протоколом у [MDT](../police/database-terminal.md) |
| Медики на місці | EMS не під юрисдикцією поліції — лише співпраця |

## Конфлікти

У конфлікті юрисдикцій — **RP-наказ керівництва** (шериф / шеф / DOJ), не OOC-спори в чаті.

{% hint style="warning" %}
Патруль BCSO в центрі LS без виклику — погана RP-практика. Аналогічно LSPD у Paleto без координації.
{% endhint %}
