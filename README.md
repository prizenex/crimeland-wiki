# Ласкаво просимо

Це гайдбук для тих, хто щойно прибув до штату, і для тих, кому потрібно швидко розібратися з конкретною механікою. Тут немає «правильного» шляху: почніть із перших завдань, знайдіть роботу, побудуйте власну історію — або одразу відкрийте потрібний розділ у меню.

## Ви тут уперше?

1. [Зайдіть на сервер](getting-started/connect.md) та [створіть персонажа](getting-started/character.md).
2. Відкрийте [Початок гри](getting-started/first-steps.md) — він проведе від аеропорту до перших грошей і житла.
3. Перед пригодами прочитайте [Правила гри](basics/rules.md) і збережіть [Керування](basics/controls.md), щоб не шукати потрібну клавішу в розпал гри.

## Уже освоїлися?

- Потрібні гроші — оберіть [роботу](jobs/cleaner.md) або подивіться [бізнеси](business/overview.md).
- Плануєте купити авто — почніть з [автошколи](transport/driving-school.md), [оренди](transport/rental.md) чи [салонів](transport/dealerships.md).
- Хочете змінити образ — завітайте до розділу [Ваш персонаж](character/appearance.md).
- Шукаєте конкретну систему — скористайтеся навігацією ліворуч або пошуком GitBook.
