# Дріфт

На сервері є **виділена дріфт-зона** з лічильником очок і винагородою за результат. Для тренувань і змагань використовуйте її — не вулиці центру міста.

## Де знайти

| Об’єкт | Розташування |
| --- | --- |
| **Дріфт-зона** | Доки / південний промрайон — бліп ![](../.gitbook/assets/blips/326.png) на мапі (`P`) |
| **Радіус зони** | ~**300 м** навколо майданчика |
| **Магазин поруч** | Їжа, напої, ремкомплект, мотузки для довгих сесій |

Поза зоною лічильник очок **не** нараховує винагороду (хоча технічно заносити можна на будь-якій дорозі).

## Як працює лічильник

1. Заїдьте в зону на авто.
2. Починайте **занос** — на екрані з’являться **очки** та **кут** заносу.
3. Тримайте ланцюжок заносів: між фігурами є **2 секунди** на продовження, інакше серія обнуляється.
4. Завершення серії — фіксація результату.

### Винагорода за очки

| Параметр | Значення |
| --- | --- |
| Множник | **0,01$** за 1 очко |
| Приклад | 10 000 очок ≈ **100$** |
| Мінімум для виплати | **1 000** очок |
| Максимум за серію | **100 000** очок (≈ **1 000$**) |

Топові результати можуть потрапляти в **таблицю лідерів** зони.

## Як готуватись

| Крок | Деталі |
| --- | --- |
| Авто | **Дрифт-пакет** у [тюнінгу](tuning.md) — цього достатньо; окремий привід не потрібен |
| Інший тюнінг | Stage, привід, swap, шини **не впливають**, поки стоїть дрифт-пакет — не переплачуйте |
| Ремкомплект | Дріфт швидко б’є кузов |
| Паливо | Заправтесь заздалегідь — зона велика |

## RP та поліція

Дріфт у місті поза зоною може закінчитись зупинкою **LSPD**. Для публічних заходів домовляйтесь із гравцями на майданчику або організуйте івент.

## Відмінність від гонок

[Гонки](racing.md) — окрема система з GPS-трассами та часом кола. Дріфт — очки за стиль і кут заносу в виділеній зоні.
