# Причіпи

Причепи та евакуатори — для **перевезення авто** і **човнів**. Якщо застрягли в болоті — див. [Бездоріжжя](off-road.md). Окремо причепи використовуються в роботі [далекобійника](../jobs/trucker.md).

## Де купити

Північ від міста, біля **Paleto Bay**, два [салони](dealerships.md):

| Салон | Що продає | Орієнтовні ціни |
| --- | --- | --- |
| **Магазин причіпів** | Причепи для авто та човнів (маленькі, середні, великі, човнові) | **~240 000$–700 000$** |
| **Магазин тягачів** | Пікапи, евакуатори, вантажівки з фаркопом | **~700 000$–5 200 000$** |

1. Знайдіть бліп на мапі → **`E`** → **«Відкрити шоурум»**.
2. Оберіть модель → тест-драйв за бажанням → купівля.
3. Заберіть транспорт на точці видачі — за замовчуванням він на паркінгу **«Куби»** (Legion Square); далі — [паркінг](parking.md).

{% hint style="info" %}
Не всі машини тягнуть будь-який причеп — потрібен **фаркоп** (tow hitch). Перевіряйте сумісність у шоурумі або на тест-драйві.
{% endhint %}

## Зчеплення причепа

1. Під’їдьте **заднім ходом** до причепа — фаркоп має бути близько до зчепа.
2. **Затисніть `H`** — причеп **зчепиться** або **відчепиться** (одна клавіша для обох дій).
3. Переконайтесь, що з’єднання тримається перед виїздом.

| Дія | Клавіша |
| --- | --- |
| Зчепити / відчепити причеп | **`H`** (утримувати) |
| Пандус на причепі (якщо є) | **`J`** — відкрити / закрити |
| Закріпити авто на платформі | **`E`** біля кузова евакуатора / причепа |

## Завантаження авто на причеп

На **евакуаторах** і **платформах**:

1. Відкрийте **пандус** (`J`), якщо він є на моделі.
2. Заїдьте або підженіть авто на платформу.
3. Натисніть **`E`** → **закріпити** (attach).
4. Після розвантаження — **`E`** → **відкріпити** (detach).

Для **човнів** — під’їдьте до човнового причепа; з’явиться підказка закріпити на відстані.

## Для далекобійників

Окремо від особистих причепів — [далекобійник](../jobs/trucker.md) зчеплює **вантажні причепи** на робочій зміні (потрібна категорія **C**). Деталі — у гайді роботи.

## Поради

| Порада | Чому |
| --- | --- |
| Плануйте розвороти | Довгий причеп не розвернеться на вузькій вулиці |
| Гальмуйте раніше | Вага збільшує гальмівний шлях |
| Не залишайте на проїжджій частині | Евакуація та RP-штрафи |
