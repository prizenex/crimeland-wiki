# Паркінг

Власний транспорт зберігається в **гаражах**. Орендовані та службові авто мають окремі правила повернення.

## Гараж

1. Знайдіть бліп **гаражу** на мапі (іконка паркінгу).
2. Під’їдьте до зони → `лівий Alt` або `E` (залежно від підказки).
3. У меню:
   - **Достати** авто зі списку;
   - **Поставити** поточне на зберігання.

| Параметр | Деталі |
| --- | --- |
| Слоти | Залежать від прогресу, житла та налаштувань персонажа |
| Стан авто | Зберігається (пошкодження, тюнінг, бензин) |
| Публічні гаражі | Можлива **погодинна плата** за зберігання (приватні, робочі та сімейні — без неї) |

Якщо слотів не вистачає — продайте зайве авто на [ринку](market.md) або розширте можливості через житло / RP.

## Штрафмайданчик (імпаунд)

Якщо авто **евакуювали** (поліція, знищення, адміністративне рішення):

1. Знайдіть бліп **штрафмайданчика** на мапі.
2. Під’їдьте → `E` → **«Штрафмайданчик»**.
3. Оберіть своє авто → сплатіть **штраф** і заберiть.

Вартість залежить від типу евакуації та часу зберігання. Для сильно пошкодженого або «знищеного» авто може стягуватись підвищений збір (до **10 000$** і вище).

## Поради

| Ситуація | Рекомендація |
| --- | --- |
| Вихід з гри | Поставте авто в **гараж**, якщо можете |
| Небезпечний район | Не залишайте дороге авто без нагляду |
| Чужі ключі | Відкривають лише **конкретну** машину, не весь гараж |
| Оренда | Поверніть на [точку оренди](rental.md), не в особистий гараж |

## Відмінність від авторинку

[Авторинок](market.md) — для **продажу** авто іншому гравцю. Гараж — для **зберігання** вашого транспорту між сесіями.
