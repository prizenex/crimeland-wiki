# Паркінг

Власний транспорт зберігається на **публічних паркінгах** (гаражах на мапі). Орендовані та службові авто мають окремі правила повернення.

## Публічний паркінг

1. Відкрийте мапу (`P`) → знайдіть бліп ![](../.gitbook/assets/blips/524.png) **«Паркінг»** (публічний гараж).
2. Під’їдьте до зони → `лівий Alt` або `E` (залежно від підказки).
3. У меню:
   - **Достати** авто зі списку;
   - **Поставити** поточне на зберігання.

| Параметр | Деталі |
| --- | --- |
| Скільки авто можна мати | **Без ліміту** — кожна машина прив’язана до паркінгу, де ви її залишили |
| Стан авто | Зберігається (пошкодження, тюнінг, бензин) |
| Погодинна плата | На **публічних** паркінгах — так; робочі, сімейні та гараж житла — без неї |
| Після покупки в [салоні](dealerships.md) | За замовчуванням — ![](../.gitbook/assets/blips/524.png) **Legion Square** (центр міста) |

{% hint style="info" %}
**Ліміт слотів не блокує покупку авто.** Слоти обмежують лише **гараж у вашому житлі** — скільки машин одночасно може стояти в домашньому гаражі. На звичайних паркінгах міста обмеження кількості авто **немає**.
{% endhint %}

## Гараж житла

Якщо у вас є [будинок або апартаменти](../housing/first-home.md) з гаражем:

- Кількість місць залежить від **типу житла** та покращень.
- Якщо гараж **повний** — цю конкретну машину туди не поставите, але вона лишається на **публічному паркінгу**.
- Розширення слотів — через покращення житла (якщо доступно в меню будинку).

## Штрафмайданчик (імпаунд)

Якщо авто **евакуювали** (поліція, знищення, адміністративне рішення):

1. Відкрийте мапу (`P`) → знайдіть бліп ![](../.gitbook/assets/blips/68.png) **«Штрафмайданчик»** (район доків, південь LS).
2. Під’їдьте → `E` → **«Штрафмайданчик»**.
3. Оберіть своє авто → сплатіть **штраф** і заберiть.

Вартість залежить від типу евакуації та часу зберігання. Для сильно пошкодженого або «знищеного» авто може стягуватись підвищений збір (до **10 000$** і вище).

## Поради

| Ситуація | Рекомендація |
| --- | --- |
| Вихід з гри | Поставте авто на **паркінг**, якщо можете — менше ризик евакуації |
| Небезпечний район | Не залишайте дороге авто без нагляду |
| Чужі ключі | Відкривають лише **конкретну** машину, не весь список |
| Оренда | Поверніть на [точку оренди](rental.md), не в особистий паркінг |
| Багато авто | Тримайте на різних паркінгах міста — шукайте через [телефон](../basics/phone.md) → **Гараж** |

## Відмінність від авторинку

[Авторинок](market.md) — для **продажу** авто іншому гравцю. Паркінг — для **зберігання** вашого транспорту між сесіями.
