# Оренда

Оренда транспорту доступна **по всьому штату** — точки позначені бліпом ![](../.gitbook/assets/blips/466.png) **«Оренда транспорту»** на мапі. Зручно в перші дні після прильоту в [аеропорт](../getting-started/first-steps.md).

## Як орендувати

1. Знайдіть точку оренди (`P` → ![](../.gitbook/assets/blips/466.png) бліп оренди).
2. Підійдіть до маркера → `E` → меню оренди.
3. Оберіть **категорію** та **модель**.
4. Оберіть **термін** (30 хв / 1 / 2 / 3 / 6 год).
5. Сплатіть **оренду** + **депозит** (готівка або банк).
6. Заберіть авто на точці видачі (на мапі з’явиться жовтий бліп до посадки в салон).

## Терміни та орієнтовні ціни

Ціни залежать від класу авто. Нижче — базовий економ-клас (наприклад, Asea, Premier):

| Термін | Оренда (орієнтир) |
| --- | --- |
| 30 хв | ~1 500$ |
| 1 год | ~2 500$ |
| 2 год | ~4 200$ |
| 3 год | ~6 000$ |
| 6 год | ~10 000$ |

Комфортні та спортивні моделі дорожчі. **Депозит** утримується окремо (від **2 500$** для бюджетних авто до **15 000$+** для преміум-класу) і повертається після здачі авто.

### Безкоштовний транспорт для новачків

Гравці **0–1 рівня** (поки не досягли **2-го рівня**) орендують **мопеди та електроскутер** **безкоштовно** на **будь-якій** точці оренди — оренда й депозит **0$**. Зручно для першої поїздки в ![](../.gitbook/assets/blips/419.png) [мерію](../basics/city-hall.md) після прильоту в [аеропорт](../getting-started/first-steps.md).

## Повернення

1. Поверніть авто в **зону повернення** тієї ж точки (червоний маркер на землі).
2. Зупиніть транспорт у зоні → підтвердіть здачу.
3. Депозит повернеться на той самий баланс, з якого платили.

{% hint style="warning" %}
Прострочення оренди коштує дорожче. Слідкуйте за таймером на екрані або бліпом орендованого авто.
{% endhint %}

## Де є точки

Оренда в ключових районах: **Legion / центр** (старт у місті), **аеропорт** (після прильоту), **південь / доки** (роботи та бізнеси), **Paleto** та інші — для регіональних маршрутів.

На аеропорті в каталозі лише **електроскутер** — для швидкого виїзду в місто (для новачків — безкоштовно до 2-го рівня).

## Важливо

- **Не ваше авто** — Орендоване ТЗ **не** продається на [ринку](market.md)
- **Пошкодження** — Сильні пошкодження можуть зменшити повернення депозиту
- **Вихід з гри** — Депозит повертається на банк при відключенні (якщо оренда ще активна)
- **P2P-оренда** — Гравці можуть здавати **власні** авто іншим — окремий режим у меню оренди

Після купівлі власного авто в [салоні](dealerships.md) оренда зазвичай не потрібна.
