# Тюнінг

Тюнінг і ремонт доступні в **зонах Customs** (самообслуговування) та в **майстернях** з гравцями-механіками.

## Самообслуговування (LS Customs / Benny's)

1. Заїдьте в зону тюнінгу (бліп **Customs** на мапі).
2. Зупиніть авто в маркері.
3. **`E`** → **«Налаштувати транспортний засіб»**.
4. Оберіть категорію → сплатіть → дочекайтесь встановлення.

| Категорія | Що змінює |
| --- | --- |
| Продуктивність | Двигун, гальма, трансмісія, підвіска, турбо |
| Зовнішній вигляд | Колір, диски, спойлери, неон, тонування |
| Додатково | Ксенон, клаксон, номерні рамки |

Точки: LS Customs по всьому штату, Benny's, марина, Sandy Shores та інші (див. бліпи на мапі).

## Майстерня з механіком

У [автомайстерні](../business/auto-repair-shop.md) працюють гравці:

| Послуга | Як |
| --- | --- |
| Складний тюнінг | Через планшет механіка |
| Ремонт після ДТП / погоні | Замовлення в майстерні |
| **Нітро** | Встановлення механіком → використання клавішею **`RMENU`** |

Механік бачить реальний стан деталей і може запропонувати повний ремонт дешевше, ніж серія дрібних полагоджень у Customs.

## Сервісне зношування

На сервері увімкнено **знос деталей** (двигун, гальма, підвіска тощо).

| Показник | Що робити |
| --- | --- |
| Нижче **20%** | Потрібне ТО в майстерні |
| Ігнорування | Гірша керованість, ризик поломок у погоні |

Слідкуйте за станом після тривалих [гонок](racing.md), [дріфту](drift.md) або робочих змін.

## Benny's як магазин

Запчастини для тюнінгу також продаються в **Benny's** як [магазин гравця](../business/twenty-four-seven.md) — ціни залежать від власника.

{% hint style="info" %}
Поліцейський транспорт ремонтується на **спеціальних точках** біля відділку — не на цивільних Customs.
{% endhint %}

## Поради

- Спочатку **ремонт**, потім **косметика** — інакше переплатите за вигляд побитого авто.
- Для [дріфту](drift.md) налаштуйте підвіску й задній привід у Customs або з механіком.
- Зберігайте **ремкомплект** в інвентарі для екстреного ремонту в полі.
