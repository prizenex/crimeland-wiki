# Дрон

Поліцейський дрон — **повітряне спостереження**: пошук підозрілого, контроль натовпу, підтримка погоні. Керування з планшета оператора; напарник може бачити трансляцію.

## Хто має доступ

| Параметр | Значення |
| --- | --- |
| Робота | **Поліція** або **шериф** |
| Мінімальний ранг | **2** і вище |
| Предмет | **Поліцейський дрон** — видається зі службового спорядження |

## Як запустити

1. Переконайтесь, що ви **на зміні** та маєте дрон в інвентарі.
2. `Tab` → знайдіть предмет → ![](../.gitbook/assets/inputs/mouse-rmb.svg) → **Використати**.
3. Дрон з’явиться поруч — з’явиться інтерфейс керування.
4. Після місії **посадіть** дрон або дочекайтесь автоповернення — інакше можна втратити апарат.

## Можливості поліцейського дрона

| Функція | Опис |
| --- | --- |
| Камера | Огляд з висоти, зум |
| **Нічне бачення** | Спостереження в темряві |
| **Тепловізор** | Пошук людей за тепловим слідом |
| Режим переслідування | Утримує ціль у кадрі (за SOP) |
| Динамік | Оголошення з повітря (налаштовує керівництво) |
| Розряд | Обмежений радіус і час польоту від оператора |

## Керування (орієнтир)

| Дія | Клавіші |
| --- | --- |
| Рух | **W A S D** |
| Висота | **Q** / **E** (або аналог у меню дрона) |
| Камера | **Миша** |
| Вихід | За підказкою на екрані |

Точні клавіші можна змінити в налаштуваннях FiveM → **Key Bindings**.

## Обмеження RP

- Для спостереження за **приватною територією** потрібен **ордер** або **екстрені обставини** (захоплення заручників, стрілянина).
- Не використовуйте дрон для **метагейму** без IC-підстави.
- Після польоту — **звіт** у [MDT](database-terminal.md): де, коли, що зафіксовано.

{% hint style="warning" %}
Дрон можна збити пострілами. Не зависайте над озброєним підозрілим без прикриття наземного патруля.
{% endhint %}
