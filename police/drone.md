# Дрон

Дрон LSPD — спостереження з повітря, пошук підозрілого, контроль натовпу.

### Використання

1. Доступ за рангом / сертифікацією (SOP відділку).
2. Запуск з відділку або патрульного авто.
3. Керування — WASD + миша; камера транслює на планшет напарника.
4. Після місії — посадка та звіт.

### Обмеження RP

- Потрібен **ордер** або **екстрені обставини** для спостереження за приватною територією.
- Не використовуйте дрон для метагейму без IC-підстави.
