# K9

Підрозділ **K9** — собаки для пошуку наркотиків, бігунів та захисту офіцера.

### Для офіцера-кінолога

1. Отримайте сертифікацію K9 у відділку.
2. Візьміть собаку з вольєра на зміну.
3. Команди: пошук, утримання, захист (за SOP).

### Для патрульних

- Викликайте K9 при підозрі на наркотики в авто / будинку (з ордером).
- Не заважайте роботі собаки — RP-дистанція.

Деталі команд залежать від ресурсу K9 на сервері — навчання проводить керівництво LSPD.
