# Термінал бази даних

**MDT** (Mobile Data Terminal) — службовий планшет для пошуку громадян, авто, ордерів і оформлення справ. Використовують поліція, шериф і EMS на зміні.

## Як відкрити

- **Ви на активній зміні (поліція / шериф / EMS)** — Натисніть **`K`**
- **Ви без зміни або у наручниках** — Планшет **не відкриється**

Планшет працює на вулиці, у патрульному авто та в відділку — головне бути на службі.

{% hint style="info" %}
Після оформлення затримання справу заносьте в MDT — це основа для [таблиці вироків](standard-sentences.md) і подальшого суду.
{% endhint %}

## Що можна зробити

- **Пошук** — За ім'ям, номером авто, Citizen ID
- **Профіль** — Попередні статті, нотатки, ордери на арешт
- **Інциденти** — Створення справи, прив'язка доказів, штрафи
- **BOLO / розшук** — Оголошення розшуку авто або особи
- **Бюлетень** — Службові оголошення для відділку

## Типовий сценарій після затримання

1. Створіть **інцидент** і збережіть — запам'ятайте його номер.
2. Зафіксуйте **конфіскацію** речей у шафу за цим номером.
3. Вкажіть **особу затриманого** та статті.
4. Озвучте вирок IC, видайте тюремну форму, призначте термін.
5. Допишіть звіт і спишіть штраф у MDT.

Детальні кроки — у [таблиці стандартних вироків](standard-sentences.md).

## RP-правила

- Дані в MDT — **лише IC-інструмент**. Не використовуйте їх для метагейму в OOC.
- Перевірка в базі без RP-підстави (просто «пробив у MDT») — порушення правил сервера.
- Докази з [криміналістики](forensics.md) мають збігатися з тим, що ви вносите в звіт.
