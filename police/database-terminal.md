# Термінал бази даних

**MDT** (Mobile Data Terminal) — планшет поліції для пошуку громадян, авто та справ.

### Як відкрити

- У службовому авто або на посту — команда або планшет (за SOP відділку).
- Потрібна активна зміна поліції / шерифа.

### Що можна

- Пошук за **ім'ям**, **номером авто**, **Citizen ID**.
- Перегляд **розшуку**, **попередніх статей**, **нотаток**.
- Оформлення **звітів** та **ордерів** (за рангом).

Дані в MDT — IC-інструмент; не використовуйте OOC для метагейму.
