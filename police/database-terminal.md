# Термінал бази даних

MDT (Mobile Data Terminal) — ваш робочий інструмент на зміні: пробити людину чи авто, перевірити ордери, завести справу на затриманого. Доступний поліції, шерифу та EMS.

## Як відкрити

Якщо ви на активній зміні (поліція, шериф або EMS), просто натисніть **`K`** — планшет працює на вулиці, у патрульному авто й у відділку, головне бути на службі. Без зміни або в наручниках MDT не відкриється.

## Що можна зробити

- **Пошук** — за ім'ям, номером авто, Citizen ID
- **Профіль** — попередні статті, нотатки, ордери на арешт
- **Інциденти** — створення справи, прив'язка доказів, штрафи
- **BOLO / розшук** — оголошення розшуку авто або особи
- **Бюлетень** — службові оголошення для відділку

## Типовий сценарій після затримання

Створіть інцидент і запам'ятайте його номер, зафіксуйте конфісковані речі в шафу за цим номером, вкажіть особу затриманого та статті. Далі озвучте вирок IC, видайте тюремну форму, призначте термін і допишіть звіт зі штрафом у MDT — детальні кроки в [таблиці стандартних вироків](standard-sentences.md).

{% hint style="info" %}
Заносьте справу в MDT одразу після затримання — це основа для [таблиці вироків](standard-sentences.md) і подальшого суду.
{% endhint %}

## RP-правила

- Дані в MDT — лише IC-інструмент. Не використовуйте їх для метагейму в OOC.
- Перевірка в базі без RP-підстави (просто «пробив у MDT») — порушення правил сервера.
- Докази з [криміналістики](forensics.md) мають збігатися з тим, що ви вносите в звіт.
