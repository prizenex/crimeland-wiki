# Вступ і початок роботи (Поліція)

**LSPD** та **BCSO** (шериф Палето) — державні силові структури. Набір через RP, не через ![](../.gitbook/assets/blips/419.png) [центр зайнятості](../basics/city-hall.md).

### Як подати заявку

1. **«Послуги»** → Поліція / Шериф у [телефоні](../basics/phone.md).
2. Або прийдіть у відділок Mission Row / Paleto IC.
3. Співбесіда, перевірка [документів](../basics/documents.md), навчання.

### Перша зміна

- Форма та спорядження в роздягальні.
- [Рація](../basics/radio.md) на службовій частоті.
- Планшет / MDT — [термінал бази даних](database-terminal.md).
- Патруль з напарником або самостійно за наказом керівництва.

Детальний посібник — [Посібник офіцера](officer-guide.md).
