# Криміналістика

На місці злочину офіцер збирає **докази** для справи в MDT та суду.

### Типові дії

| Доказ | Як зібрати |
| --- | --- |
| Гільза | Підбір біля точки пострілу |
| Відбиток | Набір з поверхні (двері, авто) |
| ДНК | Зразок крові / слідів |
| Фото | Камера / телефон для протоколу |

### Ланцюжок зберігання

1. Зберіть доказ у пакет.
2. Опишіть в MDT-звіті.
3. Передайте детективу / лабораторії IC.

Без зібраних доказів складніше обґрунтувати обвинувачення в [суді](../laws/judicial-code.md).
