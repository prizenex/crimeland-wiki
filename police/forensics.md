# Криміналістика

На місці злочину офіцер збирає **докази** для справи в [MDT](database-terminal.md) та суду. Без зібраних доказів складніше обґрунтувати обвинувачення в [суді](../laws/judicial-code.md).

## Що знадобиться

| Що | Навіщо |
| --- | --- |
| Активна **зміна** поліції / шерифа | Докази збирають лише правоохоронці на службі |
| **Порожній пакет для доказів** | Видається зі службового авто або спорядження |
| **Ліхтарик** (як зброя в руках) | Підсвічує гільзи та сліди на місці |

## Типи доказів

| Доказ | Де шукати | Як зібрати |
| --- | --- | --- |
| **Гільза** | Біля точки пострілу | Увімкніть ліхтарик → підійдіть → **`G`** |
| **Кров / ДНК** | Сліди після поранення | Підійдіть до плями → **`G`** |
| **Відбиток** | Двері, авто, предмети | Підійдіть до сліду → **`G`** |
| **Відбиток особи** | У відділку | Сканер у ![](../.gitbook/assets/blips/60.png) **Mission Row** або **Paleto** → `лівий Alt` |

Після збору доказ потрапляє в **інвентар** як заповнений пакет із міткою (тип, вулиця, серійний номер тощо).

## Сканер відбитків у відділку

1. Приведіть затриманого в ![](../.gitbook/assets/blips/60.png) **відділок** (LS або Paleto).
2. Підведіть до **сканера** (зона біля допитних кімнат).
3. `лівий Alt` → **«Відкрити сканер відбитків»**.
4. Зафіксуйте ID відбитка — внесіть у звіт MDT.

## Ланцюжок зберігання

1. Зберіть доказ на місці події.
2. Опишіть у **звіті інциденту** в [MDT](database-terminal.md).
3. Передайте матеріали детективу / старшому зміни IC.
4. При потребі — зберігайте пакети до суду, не викидайте без RP-підстави.

{% hint style="warning" %}
Без **порожнього пакета** в інвентарі збір доказів не спрацює. Перевіряйте спорядження перед виїздом на виклик.
{% endhint %}

## Поради патрульному

- На ДТП і перестрілках спочатку **огородіть зону**, потім збирайте докази.
- Фотографуйте місце на **телефон** для RP-протоколу — це доповнює, але не замінює пакети.
- Якщо підозрілий **мив руки** після пострілу — GSR-тест (перевірка на порох) проводять старші за SOP відділку.
