# Посібник офіцера поліції

Короткий довідник для патрульного офіцера LSPD / BCSO.

### Щоденні обов'язки

1. **Патруль** — реагування на виклики 911 / рація.
2. **Зупинки** — перевірка документів, обшук за підозрою (з RP-підставою).
3. **Затримання** — наручники, доставка у відділок, [вироки](standard-sentences.md).
4. **Допомога EMS** — огородження місця ДТП / пограбування.

Дійте згідно [Конституції](../laws/constitution.md) та [кодексів](../laws/criminal-code.md). Без підстави — не обшук, без наказу — не lethal force.
