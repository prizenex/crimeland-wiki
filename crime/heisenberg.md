# Гайзенберг (метамфетамін)

У пустелі, подалі від очей, стоять **кемпери з лабораторією**. Звідти вночі йде **синій дим** — його бачать мешканці й патруль. Хто тримає **температуру** і не палиться, отримує кристали **трьох якостей**; хто поспішив — починає збори знову. Далі — [збут](illegal-sales.md) на вулиці або IC.

{% hint style="success" %}
**З чого почати:** **Джессі** у **таборі хіппі** ![](../.gitbook/assets/blips/280.png) (пустеля). Діалог **«Метамфетамін»** — маршрути на карту, точки збору, рецепт. Загубились — вона поставить waypoint.
{% endhint %}

{% hint style="warning" %}
**Пам’ятайте:** без **протигаза** — отруєння парами · варіння **під землею / у тунелях заборонене** · **синій дим** може привести копів · затримання = конфіскація всього
{% endhint %}

## Рецепт варки

{% hint style="info" %}
**Ціль — 50°C.** Тримайте суміш у коридорі **50–70°C** (не вище **+20°C** від цілі — падає чистота). Легкий пар — норма; орієнтир — **густий дим** з казана.
{% endhint %}

### Закладка в казан

Порядок не важливий — усі чотири позиції одразу, **літій лише 1 шт.** на цьому кроці:

| | Інгредієнт |
| --- | --- |
| <img src="../.gitbook/assets/kq_acetone.png" alt="Ацетон" width="36"> | Ацетон — **1** |
| <img src="../.gitbook/assets/kq_ammonia.png" alt="Амоніак" width="36"> | Амоніак — **1** |
| <img src="../.gitbook/assets/kq_meth_pills.png" alt="Псевдоефедрин" width="36"> | Псевдоефедрин — **1** |
| <img src="../.gitbook/assets/kq_lithium.png" alt="Літій" width="36"> | Літієвий пакет — **1** (ще **2** додасте пізніше) |

### Покроково

| Крок | Що робите | Сигнал / температура |
| --- | --- | --- |
| **1** | Казан на плиту, нагрів **~50°C** | Суміш готова до реакції |
| **2** | Літій **реагує** — t° **різко вгору** | **Негайно** зніміть казан або вимкніть плиту |
| **3** | Дочекайтесь кінця реакції | t° **трохи вище 50°C** (не нижче!) |
| **4** | Додайте **2-й** літієвий пакет → знову гасите перегрів | Як крок 2–3 |
| **5** | Додайте **3-й** літієвий пакет → те саме | Усього **3** літієвих пакети в суміші |
| **6** | Тримайте **50–70°C** | Поки йде **густий дим**; коли зник — далі |
| **7** | Охолодіть суміш | **Нижче 40°C** перед етанолом |
| **8** | Додайте <img src="../.gitbook/assets/kq_ethanol.png" alt="Етанол" data-size="line"> **етанол** | Низька t°, поки дим **не припиниться** |
| **9** | Охолодіть до мінімуму → **перелийте в лоток** | Чекайте **затвердіння** кристалів |
| **10** | Заберіть результат | Повідомлення з **% чистоти** партії |

{% hint style="warning" %}
**Перегрів + літій** може **вибухнути** кемпер (процес зірветься). Не кидайте літій, коли t° уже зависока.
{% endhint %}

## Поради

1. **Зберіть усе з блоків вище** — не заходьте у фургон «наполовину».
2. Запасіть **кілька цистерн** амоніаку — поповнення лише після повного спустошення.
3. На **3 літієвих пакети** — одразу кілька штук з акумуляторної купи.
4. Варіть **вночі**, подалі від магістралей — менше педів і викликів копів.
5. Перші партії — **тренування температури**; high на збуті вигідніший у рази.
6. Не залишайте фургон із **димом** на очах у NPC.
