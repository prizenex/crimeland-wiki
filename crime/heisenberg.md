# Гайзенберг (метамфетамін)

«Гайзенберг» — це **варіння метамфетаміну** у спеціально обладнаному **фургоні / кемпері**. Потрібні хімікати, набір лабораторії та контроль температури. Якість продукту залежить від **чистоти реакції** — від низької до високої.

> Ігрова механіка. Дим з фургона може привернути поліцію. Варіння **під землею / у тунелях заборонене**.

## Підказка: NPC Джессі (табор хіппі)

У **таборі хіппі** (пустеля, схід штату) сидить **Джессі** — барига, яка знає весь ланцюг від прекурсорів до готового продукту.

{% hint style="success" %}
Поговоріть із **Джессі** → оберіть **«Метамфетамін»**. Вона **покроково пояснить рецепт варки**, підкаже **де взяти кожен прекурсор** (амоніак, літій, етанол, ацетон, псевдоефедрин), де знайти **інструменти** та **де варити** (трейлери поруч). Можна одразу поставити **мітку на карті** — не треба шукати наосліп.
{% endhint %}

| Тема в діалозі | Що дізнаєтесь |
| --- | --- |
| Амоніак | Танкери біля Humane Labs |
| Літій | Старі акумулятори на сміттєзвалищі |
| Інші прекурсори | Склад, магазин на виїзді з Sandy Shores |
| Інструменти | Стара хата на заході (обережно — можуть бути зайві гості) |
| Де варити | Трейлери / кемпери в пустелі |
| **Рецепт варки** | Повний покроковий гайд: температура 50°C, 3 літієві пластини, етанол, охолодження |

Якщо загубились — **завжди повертайтесь до Джессі**, вона оновить маршрут.

## Підходящий транспорт

Варіння працює лише в **спеціальних фургонах**:

- Journey / Journey2
- Camper
- Інші кемпери зі списку сервера (донатні моделі)

Зайдіть у фургон з **набором лабораторії** в інвентарі та встановіть обладнання через меню взаємодії.

---

## Покрокове варіння

### 1. Підготовка

1. Припаркуйте фургон **подалі від людей** (не в тунелі — система блокує).
2. Одягніть **протигаз**.
3. Завантажте хімікати в лабораторію згідно підказок у фургоні.
4. Цільова **температура ~50°C** (діапазон 40–200°C).

### 2. Процес

1. Змішуйте інгредієнти за етапами (амоніак → ацетон → етанол → літій тощо).
2. Слідкуйте за **термометром** на колбі — відхилення псує якість.
3. Після реакції — **охолодження** на протязі (швидкість охолодження налаштована на сервері).
4. Зберіть кристали з **лотка**.

### 3. Результат за чистотою

Максимум **10 одиниць** за ідеальну партію без втрат.

| Чистота | Продукт | Ефект (орієнтовно) |
| --- | --- | --- |
| 40%+ | <p>Низька якість</p><p>![](../.gitbook/assets/kq_meth_low.png)</p> | +броня, −здоров’я, витривалість |
| 75%+ | <p>Середня якість</p><p>![](../.gitbook/assets/kq_meth_mid.png)</p> | Стабільніший ефект, менше шкоди |
| 95%+ | <p>Висока якість</p><p>![](../.gitbook/assets/kq_meth_high.png)</p> | Максимальний ефект, мінімум побічних |

{% hint style="warning" %}
**Неправильна температура + літій** може **вибухнути** фургон (якщо увімкнено на сервері). Не додавайте літій при перегріві.
{% endhint %}

## Ризики

| Ризик | Деталі |
| --- | --- |
| **Синій дим** | З фургона йде дим — NPC і гравці можуть викликати **поліцію** (шанс ~100% на педа в радіусі 120 м) |
| **Отруєння** | Без протигаза — сильний дебафф |
| **Вибух** | Критичний перегрів + літій |
| **Конфіскація** | При затриманні — втрата хімікатів і готового продукту |

Після успішної партії на екрані може з’явитись **повідомлення про завершення** (стиль «місія виконана»).

## Поради «Гайзенберга»

1. Варіть **вночі** подалі від магістралей — менше педів = менше викликів копів.
2. Запасіть **2–3 цистерни амоніаку** заздалегідь — поповнення 20 хвилин.
3. Тренуйте **температуру** на малих партіях — висока якість коштує дорожче на збуті.
4. Не залишайте фургон з димом на місці пограбування — це найочевидніший слід.
