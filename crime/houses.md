# Пограбування будинків

Контракт через [планшет](contract-tablet.md): отримуєте адресу, проникаєте у житло, обшукуєте меблі й виносите цінне. Один із найпопулярніших способів крайм-заробітку.

⚠️ Якщо організатор надовго покине район контракту — завдання **скасують** автоматично.

## Рівні будинків

### 🟢 Звичайний

Для новачків. Мінімальна складність, можливі мешканці всередині.

- **Нагорода:** ~$5 000 – $20 000
- **Репутація:** +10 XP

### 🟡 Середній

Більше точок обшуку, вищий шанс на цінний лут, мешканці можуть чинити опір.

- **Нагорода:** ~$15 000 – $50 000
- **Репутація:** +15 XP

### 🔴 Елітний

Лазерна сигналізація, дороге майно, високий ризик провалу.

- **Нагорода:** ~$40 000 – $100 000
- **Репутація:** +20 XP

### 🔴 Елітний (посилена охорона)

Ще жорсткіший варіант — посилені заходи безпеки, інколи потрібні копи онлайн.

- **Нагорода:** ~$50 000 – $120 000
- **Репутація:** +20 XP

### ⚫ Мафіозний особняк

Краще групою. Озброєна охорона — один із найнебезпечніших контрактів.

- **Нагорода:** ~$80 000 – $200 000+
- **Репутація:** +25 XP

### ⭐ Будинок знаменитості

Максимальна складність: цінне майно, рідкісний лут, посилена охорона.

- **Нагорода:** ~$100 000 – $250 000+
- **Репутація:** +25 XP

{% hint style="info" %}
Починайте зі звичайних і середніх будинків, щоб набрати репутацію, а на елітні та особняк ідіть з напарниками — самі можете не впоратись з охороною.
{% endhint %}

## Що можна знайти

- Готівка, ювелірка, телефони, електроніка
- Побутова техніка (частина — великогабаритна, носиться в руках)
- Зброя, боєприпаси, інструменти для інших крайм-активностей
- Колекційні та рідкісні предмети

Найцінніше зазвичай — техніка, електроніка та рідкісні колекційні предмети. Зголодніли під час обшуку — не соромтесь заглянути в холодильник.

## Системи безпеки

Сигналізація, лазери, озброєні власники, охоронці, виклик LSPD. Чим дорожчий будинок — тим складніше залишитись непоміченим.

{% hint style="warning" %}
Власник може помітити вас ще до кінця обшуку — залиште вільне місце в інвентарі, щоб швидко забрати цінне й піти.
{% endhint %}

Для дверей потрібен **набір для відмикання** — див. [Відмичка](lockpick.md).
