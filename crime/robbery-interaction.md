# Грабіж та взаємодія

Грабіж **гравця** на CrimeLand — це **RP-обшук кишень** через меню інвентаря. Є **два режими** залежно від стану жертви.

> Грабіж без RP-причини, на спавні або в заборонених зонах — порушення [правил сервера](../basics/rules.md).

## Два режими грабежу

| Стан жертви | Чи можна грабити? | Скільки можна забрати |
| --- | --- | --- |
| **Підняті руки** (`X`) | ✅ Так | **Усі дозволені** предмети з **кишен** (по черзі, меню відкривається знову) |
| **Нокдаун** (без свідомості на землі) | ✅ Так | **Лише один** предмет на вибір — після цього обшук закривається |
| У **стяжках** | ✅ Так | Як при піднятих руках — **кілька** предметів |
| Стоїть / бігає без здачі | ❌ Ні | — |
| У наручниках (поліція) | ❌ Ні | Окремі RP-механіки [поліції](../police/officer-guide.md) |

{% hint style="info" %}
**Підняті руки** — це **свідоме RP-здавання** під загрозою. **Нокдаун** — обшук без свідомості; система **обмежує** його **одним** предметом, щоб не «вичищати» пораненого повністю.
{% endhint %}

## Як грабити (покроково)

### RP-пограбування (руки вгору)

1. **RP-контекст** — погоня, пограбування, війна банд, самооборона.
2. Наведіть **зброю** на жертву (не кулак / ліхтарик).
3. Попросіть підняти руки — жертва натискає **`X`**.
4. У [радіальному меню](../controls/radial.md) оберіть **«Грабувати»** (або через aim-меню).
5. Забирайте предмети з **кишен** — після кожного меню відкриється знову, поки не закриєте або не відійдете.

### Обшук у нокдауні

1. Жертва **без свідомості** на землі (бій, ДТП, нокаут).
2. Підійдіть **близько** (до **8 м**), тримайте **зброю**.
3. **«Грабувати»** → оберіть **один** предмет.
4. Обшук **автоматично завершується** — для другого предмета потрібен новий цикл (новий нокдаун / нова ситуація).

**Кулдаун:** після початку грабежу на грабіжника — **2 хв** до наступної спроби.

## Що можна забрати

Система дозволяє забирати **конкретний список** речей з **кишен** (крайм-лут, зброя, наркотики, інструменти пограбувань тощо).

### Приклади дозволеного луту

| Категорія | Приклади |
| --- | --- |
| Наркотики | Косяки, пакети коксу, мет, трава |
| Крайм-інструменти | <img src="../.gitbook/assets/hack_usb.png" alt="USB" data-size="line"> USB, <img src="../.gitbook/assets/hack_card.png" alt="картка" data-size="line"> картка, дрилі, терміт |
| Цінності | <img src="../.gitbook/assets/markedbills.png" alt="Мічені купюри" data-size="line"> Мічені купюри, золото, коштовності |
| Зброя | Пістолети, гвинтівки (з списку сервера) |
| Розхідники | <img src="../.gitbook/assets/lockpick.png" alt="Відмичка" data-size="line"> Відмичка, рація, телефон |

### Що забрати НЕ можна

| Категорія | Приклади |
| --- | --- |
| Документи | ID, права, ліцензії (у [гаманці](../basics/documents.md)) |
| Одяг / рюкзаки | Самі сумки, косметичні предмети |
| Вміст сумки (грабіж) | Злочинець бачить лише **кишені** — не слоти сумки / рюкзака |
| Їжа зі старту | Базовий фастфуд новачка |
| Банківський рахунок | Тільки **готівка** з інвентаря |
| Адмін / донат-речі | Спецпредмети з чорного списку |

{% hint style="info" %}
**Готівка** зазвичай **дозволена**. Гроші на **банківському рахунку** через обшук не знімаються.
{% endhint %}

## Обшук поліцією (виняток)

Правило «лише **кишені**» стосується **грабіжників**. **Поліція** при законному обшуку (наручники, візуальний контакт, погоня — [посібник офіцера](../police/officer-guide.md)) може переглянути **сумку / рюкзак** і **вилучити нелегальні** предмети: наркотики, незареєстровану зброю, крадене, інструменти для злочинів. Легальні речі та [документи](../basics/documents.md) — за RP і [процесуальним кодексом](../laws/procedural-code.md).

## Заборонені зони

Грабіж **вимкнено** в радіусі **20 м** від точок:

| Зона | Навіщо захист |
| --- | --- |
| Лікарня (Pillbox) | RP медицини |
| Sandy Shores (спавн-подібні зони) | Захист новачків |

Повідомлення в грі: *«У цій зоні грабувати заборонено»*.

На **арені** обшук **нокнутих** гравців **заборонений**.

## Особливі правила (поліція / військові)

Якщо жертва — **коп або військовий** високого рангу:

- Частина **службової зброї** **прихована** від меню обшуку.
- Грабіж копа без вагомого RP — **жорстке порушення** правил.

---

## Базові правила сервера (RP)

1. **Має бути причина** — борг, війна банд, погоня, домовленість IC.
2. **Не чистіть новачків** без сюжету.
3. **Не використовуйте** VDM / RDM — спочатку RP, потім здача або нокдаун.
4. Після обшуку — вирішіть IC (відпустити, передати EMS, везти до банди).

---

## Типові сценарії

**RP під дулом**

1. Зупинили суперника в [війні зони](territory-war.md).
2. Навели зброю → жертва підняла **руки** (`X`).
3. **«Грабувати»** → зняли мічені купюри та наркотику з кишень.
4. Відпустили або передали EMS.

**Після перестрілки**

1. Суперник у **нокдауні**.
2. **«Грабувати»** → обрали **один** найцінніший предмет.
3. Викликали EMS або залишили на місці.
