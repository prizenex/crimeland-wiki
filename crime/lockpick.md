# Відмичка

**Відмичка** — базовий інструмент крайму: авто, чужі склади [відмивки](money-laundering.md), двері в RP. Два основні предмети: **звичайна відмичка** і **набір для відмикання** (для [будинків](houses.md) за контрактом).

> Відмичка — не «магічна кнопка». Описуй дії в чаті, чекай реакції власника / поліції.

## Види відмичок

| Іконка | Предмет | Для чого |
| --- | --- | --- |
| <img src="../.gitbook/assets/lockpick.png" alt="Звичайна відмичка" width="36"> | **Звичайна відмичка** | Авто, чужі склади відмивки, прості замки |
| <img src="../.gitbook/assets/lockpick_house.png" alt="Набір для відмикання" width="36"> | **Набір для відмикання** | [Пограбування будинків](houses.md) за контрактом — **усі рівні** житла |

{% hint style="info" %}
**Просунута відмичка** майже не використовується — інколи випадає в луті, але для основних механік **не потрібна**. Для елітних будинків із сигналізацією беруть **картку для злому** ([чорний ринок](contract-tablet.md) планшета).
{% endhint %}

{% hint style="warning" %}
При **невдалому** зламі відмичка може **зламатися** (витратиться). Тримай запас.
{% endhint %}

## Де використовується

### Автомобілі

#### Звичайні / орендовані / без власника

1. Підійди до **закритого авто** (не свого)
2. Використай **звичайну відмичку** з інвентаря
3. Пройди **міні-гру** (чим складніше авто — тим важче)
4. Успіх — двері відкриті; провал — відмичка може зламатись, можливий **виклик поліції**

#### Персональні авто (електронний замок)

На **особистих авто гравців** (і деяких преміум-моделях) звичайна відмичка **не підійде** — гра покаже: *«В цьому авто електронний замок»*.

- <img src="../.gitbook/assets/hack_usb.png" alt="Фантомний USB" width="36"> **Фантомний USB** — замість відмички, складніша міні-гра
- Мінімум **1 000 XP** репутації на [планшеті](contract-tablet.md) — без неї злам заблоковано
- Власнику може прийти **сповіщення** про спробу
- При провалі USB може **пошкодитись**

{% hint style="warning" %}
Не витрачай звичайні відмички на **чужі гаражні авто**, поки не перевірив — персональне чи ні. Для таких — лише USB і досвід з контрактів.
{% endhint %}

Пов’язано з [викраденням авто](car-theft.md) та контрактами boosting у планшеті.

### Будинки

Для [пограбування будинків](houses.md) за контрактом потрібен **набір для відмикання** — окремий предмет.

1. Візьми контракт на [планшеті](contract-tablet.md)
2. Приїдь на адресу
3. Використай **набір для відмикання** на дверях
4. На елітних — додатково **картка для злому** для обходу сигналізації

### Склади та відмивка

- **Чужий склад** відмивки — **звичайна відмичка** на дверях ([Відмивка](money-laundering.md))
- Після зламу — ризик сигналізації, якщо власник купив захист

### Інше RP

- Двері бізнесів у подієвих сценаріях (за згодою адміністрації / поліції)
- Багажники (якщо механіка увімкнена на авто)

## Правила та ризики

- **Відмичка при обшуку LSPD** — конфіскація + RP-затримання
- **Злам без RP-причини** — порушення правил
- **Провал міні-гри** — втрата відмички, шум → свідки
- **Злам свого авто** — не потрібна; використовуй ключі / [телефон](../basics/phone.md)

### Що писати в RP

Приклад: *«Бачу, замок старий… спробую підігнати штифт»* — потім міні-гра. Не метагеймте («зараз зламаю скриптом»).

## Легальні альтернативи

- Викликати [механіка](../jobs/mechanic.md) для авто
- Домовитись з орендодавцем житла
