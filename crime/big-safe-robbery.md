# Пограбування великого сейфу (Union)

**Об’єднане сховище Union** — окрема велика операція (не через [планшет контрактів](contract-tablet.md)). Це підземне сховище з **золотими злитками**, грошовими візками та стінами, які треба **просвердлити** та **підірвати**. Один з найприбутковіших standalone-heist на сервері.

> Ігрова механіка. Потрібна команда, C4, сумки та оренда спецтехніки.

## Параметри

| Параметр | Значення |
| --- | --- |
| Мін. поліції | **4** |
| Кулдаун між спробами | **60 хв** (1 год) |
| Оренда різака | **$5 000** |
| Виклик поліції | Автоматично при старті |

## Покроковий сценарій

### 1. Старт (пустеля, Sandy Shores)

1. Приїдьте до **точки старту** в пустелі (схід штату, біля аеропорту Sandy).
2. Переконайтесь, що в місті **4+ поліцейських**.
3. Майте при собі **C4** і **сумки**.
4. Поговоріть із **координатором** на місці → почніть пограбування.
5. На GPS з’явиться маршрут до **будівельника** (оренда різака).

### 2. Оренда різака

1. Приїдьте до **NPC-будівельника** у місті (район доків).
2. Заплатіть **$5 000** — на GPS з’явиться **різак** (важка техніка).
3. Сідайте в різак і їдьте до **сховища Union** (підземний комплекс у місті).

### 3. Проникнення

1. Під’їдьте різаком до **стіни сховища**.
2. **Просвердліть** стіну (взаємодія біля маркера).
3. **Встановіть C4** на двері / перешкоди всередині.
4. **Підірвіть** — відкриється доступ до зали з лутом.

{% hint style="info" %}
Поруч не повинно бути **іншого гравця** на етапі зламу — система блокує дублювання.
{% endhint %}

### 4. Збір здобичі

У сховищі — **столи зі злитками** та **грошові візки**:

| Тип | Нагорода |
| --- | --- |
| <img src="../.gitbook/assets/goldingot.png" alt="Золотий злиток (стіл)" width="24"> Золотий злиток (стіл) | **50 злитків** за стіл; продаж ~**$1 000** / шт. |
| Грошовий візок | **$5 000–10 000** за один «захват»; на візку **~45 захватів** |
| Золотий візок | Злитки замість готівки |

Забирайте все в **сумки** — інвентар швидко заповнюється.

### 5. Відхід і здача

1. Після збору — **втеча** від поліції (блокпости, погоня).
2. На GPS з’явиться **покупець** (район доків, південь міста).
3. Здайте здобич — отримаєте підсумкове повідомлення з сумою.

**Орієнтовний профіт команди:** сотні тисяч — понад **$1M** при повному зачисті візків і столів (залежить від швидкості та поліції).

## Типові помилки

| Помилка | Що станеться |
| --- | --- |
| Забули C4 | Не відкриєте внутрішні перешкоди |
| Немає сумок | Не зберете лут |
| Приїхали без $5 000 | Не орендуєте різак |
| Мало поліції онлайн | Старт заблоковано |
| Кулдаун 60 хв | «Зачекайте перед наступною спробою» |

---

## Поради

1. **Водій різака** + **2 лутера** + **1 відволікання** — мінімальний склад.
2. Плануйте **маршрут втечі** до покупця заздалегідь — не їдьте через LSPD.
3. Золоті злитки можна **продати** легальним скупникам IC або тримати як актив.
4. Готівка з візків — звичайна; мічені з інших місць — [відмийте](money-laundering.md).
