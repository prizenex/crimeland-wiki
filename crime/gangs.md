# Банди

**Кримінальна організація** (банда) — це об’єднання гравців зі спільною картою територій, складами, доходом від зон і внутрішньою ієрархією. Це основа для [війн за території](territory-war.md), зонального виробництва та командних злочинів.

Офіційні **RP-банди** сервера (Ballas, Families, Vagos, Lost MC тощо) мають **штаб-квартири** зі сховищами. Окремі **гравецькі організації** створюються адміністрацією — самостійно з меню створити організацію **не можна**.

## Як потрапити в організацію

1. Пройдіть стартову крайм-лінію (квест з **Петром**) або знайдіть контакт IC.
2. Доведіть корисність банді: завдання, вірність, активність.
3. **Лідер** або **офіцер** запрошує вас через кримінальне меню.
4. Після прийому ви бачите зони організації на карті та можете брати участь у [війнах](territory-war.md).

{% hint style="info" %}
Працівники **поліції, шерифа, уряду та EMS** не можуть відкрити кримінальне меню, поки на службі.
{% endhint %}

## Кримінальне меню

| Дія | Клавіша |
| --- | --- |
| Відкрити меню організації / карту | `F9` |

У меню доступно:

- **Карта територій** — хто контролює які зони;
- **Склади зон** — збір, переробка, продаж (якщо зона ваша);
- **Учасники** — запрошення, ролі, статистика;
- **Винагороди за голову** — оголошення bounty на ворогів;
- **Статистика** — вбивства, захоплення, досвід.

При першому відкритті створюється **кримінальний профіль** — без нього немає доступу до війн і контрактів високого рівня.

## Штаб-квартири фракцій

Прив’язані до класичних банд — дають **сховище** (~50 слотів):

| Організація | Орієнтир на карті |
| --- | --- |
| **The Ballas Gang** | Південь LS (Grove-сусідство) |
| **Grove Street Families** | Дейв / Families |
| **Los Santos Vagos** | Район Vagos |
| **The Lost MC** | Клуб Lost MC |

Захопити штаб через звичайну війну на карті **не можна** — це домашня зона фракції.

## Що дає контроль території

Детально — у гайді [Війна за території](territory-war.md). Коротко:

| Тип зони | Приклад | Дохід |
| --- | --- | --- |
| **Збір** | Збір ганжі | Пакунок трави кожні 10 хв |
| **Переробка** | Кокос, відмивання, крафт зброї | Конвертація предметів у складі зони |
| **Збут** | Пляж, Vanilla Unicorn | Продаж наркотиків за готівку |

Нейтральна зона **нічого не виробляє** — потрібен власник.

## Криптовалюта організації

За перемоги у [війнах](territory-war.md) учасники отримують **біткоіни**:

![](../.gitbook/assets/bitcoin.png)

Біткоіни витрачаються в **Континенталь** (безпечна зона) на набори для крафту зброї, броню, зіп-тай тощо.

## Винагорода за голову (bounty)

| Параметр | Значення |
| --- | --- |
| Мінімальна сума | **$200** |
| Оплата | Криптовалюта / гроші (залежно від оголошення) |
| Наслідок для цілі | При виконанні — **скидання кримінальної статистики** (звання повертається до «кишенькового злодія») |

**Континенталь** — нейтральна територія. **Вбивство там** автоматично дає bounty на вбивцю.

## Кримінальні звання

| Звання | Орієнтовні вимоги |
| --- | --- |
| Кишеньковий злодій | Старт |
| Вбивця | 20 вбивств, 2 хедшоти |
| Дон | 50 вбивств, 10 захоплень, 10 bounty |
| Баба Яга | 100 вбивств, 20 захоплень, 20 bounty |

Звання видно в профілі та впливає на репутацію в краймі.

## Правила для гравців

- Війни узгоджуйте з **лідерами** — не починайте стрільбу без RP-приводу.
- **Масові перестрілки** без сюжету заборонені правилами сервера.
- Поліція може втрутитись при ескалації або рейді складу.
- Новачкам: спочатку [контракти](contract-tablet.md) та дрібний крайм, потім — території.

{% hint style="warning" %}
Якщо **всі учасники** покинуть організацію — вона зникає, а зони стають **нейтральними**. Перед переродженням персонажа передайте лідерство.
{% endhint %}
