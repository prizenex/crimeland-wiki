# Пограбування підземного сховища

**Підземне сховище** — командна операція, яку починають у **пустелі біля Lester**. Потрібно зібрати команду на дошці, приїхати спецтранспортом, **витягнути тросом** важку конструкцію, **підірвати** двері, **зламати** систему та забрати до **$1 200 000** готівки.

> Ігрова механіка. Окремий heist, не плутати з [банками](bank-robbery.md) чи [Union](big-safe-robbery.md).

## Параметри

| Параметр | Значення |
| --- | --- |
| Мін. поліції | **3** |
| Кулдаун | **5 хв** між спробами (глобальний) |
| Загальна сума в сховищі | **$1 200 000** |
| Час збору однієї пачки | **10 сек** |
| Точка старту | Пустеля (Lester) |
| Сховище | Підземний комплекс у **місті** (захід LS) |

## Покроковий сценарій

### Етап 1. Збір команди (Lester)

1. Приїдьте до **Lester** у пустелі (північно-схід карти).
2. Біля нього — **дошка пограбування** з планом.
3. **Почати пограбування** — стати лідером.
4. Інші гравці — **приєднатися до команди** (до 3 учасників на транспорт).
5. Переконайтесь: **3+ копів** онлайн, у всіх є **C4, мотузка, USB, сумка**.

{% hint style="info" %}
На дошці показано **схему** та фото локації — перегляньте перед стартом.
{% endhint %}

### Етап 2. Транспорт до кар’єру

1. Після старту на GPS з’являються **3 авто** (кар’єр, схід штату).
2. Команда сідає в **підготовлений транспорт** (броньовані пікапи / інший набір).
3. Їдьте до **точки біля сховища** у місті.

### Етап 3. Проникнення до сховища

1. **Візьміть гак / трос** на місці (маркер взаємодії).
2. **Прикріпіть трос** до цільової конструкції сховища.
3. **Прикріпіть інший кінець** до авто.
4. **Тягніть** — міні-гра / фізика витягування дверей або панелі.
5. **Встановіть C4** на двері → підрив.
6. **Зламайте** панель безпеки (**фантомний USB**).

### Етап 4. Збір грошей

1. Усередині — **пачки готівки** (загалом **$1.2M** на всю команду).
2. Кожна пачка — **10 секунд** анімації збору.
3. Потрібна **сумка** в інвентарі.
4. Діліть ролі: один збирає, інші прикривають вхід.

### Етап 5. Відхід

1. Поліція отримає **виклик** на старті — готуйте втечу.
2. Точки **завершення** — знову в **пустелі** (два варіанти на карті).
3. Розподіліть готівку **IC** між учасниками.

## Поради

1. **USB і мотузку** — по 2 на команду (на випадок фейлу міні-гри).
2. Один гравець **на сторожі** біля виходу — LSPD любить піджати в кінці.
3. Готівка вже **чиста** — відмивка не потрібна, якщо не змішуєте з міченими.
4. Після кулдауну 5 хв можна **повторити** — але поліція запам’ятає район.
