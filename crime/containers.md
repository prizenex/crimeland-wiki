# Контейнери

Контракт через [планшет](contract-tablet.md): проникніть на охоронювану базу, розкрийте вантажні контейнери болгаркою. Охорона щільна — **самотужки майже не вийде**.

## Старт

- Достатня **репутація** на планшеті
- Команда **2–5** гравців
- <img src="../.gitbook/assets/angle_grinder.png" alt="Болгарка" data-size="line"> **Болгарка** (кутова шліфмашина)
- Важка зброя, броня, патрони й медикаменти — бажано

Прийміть контракт → приїдьте на мітку → знайдіть контейнери → розкрийте їх на місці.

{% hint style="warning" %}
Охорона щільна, тому якщо команда ще не готова до затяжного бою — спочатку наберіть досвід на [будинках](houses.md) або [банкоматах](atms.md).
{% endhint %}

## Охорона

Професійні найманці з автоматами, висока точність, агресивна поведінка. Частина сидить на висоті — зачищайте периметр поступово, не забігайте у центр одразу.

## Можлива здобич

Вміст **випадковий** — кожен контракт може відрізнятись:

- Зброя, боєприпаси, вибухівка
- Наркотики, хакерське обладнання, крипто-стіки
- Компоненти та набори для крафту зброї

## Нагорода за контракт

- **+25 XP** репутації
- **+50 Gcoin**
- Лут із контейнерів
