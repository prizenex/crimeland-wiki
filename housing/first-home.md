# Перше житло

Кожен новий мешканець штату може отримати **безкоштовне стартове житло** — апартаменти в комплексі на **Alta Street**. Це зручна база на перші дні гри.

### Стартові апартаменти

1. Відкрийте мапу (`P`) і знайдіть квартирний комплекс на **Alta Street**.
2. Ваш номер позначений **👑** на мапі.
3. Підійдіть до входу, скористайтесь підказкою на екрані.
4. Усередині доступні **гардероб** і **сховище** (20 слотів).

Стартове житло **безкоштовне**, але його **не можна продати чи передати** іншому гравцю. Це тимчасова база, поки ви не купите власне житло.

### Що дає житло

| Можливість | Опис |
| --- | --- |
| Сховище | Зберігайте речі, які не хочете носити з собою |
| Гардероб | Перевдягайтесь без поїздки в салон |
| Ключі | Запросіть друзів — видайте ключ-предмет |
| Меблі | Розставте інтер'єр (див. [Декорування](decorating.md)) |

### Наступний крок

Коли накопичите кошти, можна купити **будинок або квартиру** у інших гравців або через оголошення. Керування — **`F1`** → **Про мене** → **Мій будинок** (див. [Управління будинком](house-management.md)).

{% hint style="info" %}
Якщо на сервері немає окремого ринку нерухомості на мапі — купівля зазвичай через домовленість з власником або **«Послуги»** в [телефоні](../basics/phone.md).
{% endhint %}
