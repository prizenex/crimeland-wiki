# Хвороби та травми

На CrimeLand здоров’я — не лише смужка HP. Є **кровотеча**, **пошкодження зон тіла**, **без свідомості** з таймером і необхідність **лікарні** для повного одужання.

## Типові стани

| Стан | Симптоми (RP) | Лікування |
| --- | --- | --- |
| **Кровотеча** | Втрата HP, сліди крові | <img src="../.gitbook/assets/bandage.png" data-size="line"> бандаж, EMS |
| **Пошкодження зони** | Біль у нозі, руці, голові — видно в меню травм | <img src="../.gitbook/assets/firstaid.png" data-size="line"> аптечка, лікарня |
| **Без свідомості** | Лежите на землі, таймер «кровотечі» | EMS-реанімація або лікарня |
| **Перелом / важка травма** | Повільна ходьба, дебафи | Лише ![](../.gitbook/assets/blips/61.png) **лікарня** (check-in) |
| **Стрес після бою** | Дрож, важке дихання | Відпочинок, ліки в лікарні |

## Таймери (орієнтир)

| Фаза | Час |
| --- | --- |
| Кровотеча до втрати свідомості | ~**10 хвилин** |
| До «мозкової смерті» після падіння | ще ~**20 хвилин** |
| Примусове respawn (без EMS) | Залежить від зони та наявності медиків онлайн |

Якщо на сервері **достатньо EMS** — примусове воскресіння може бути **заблоковане**. Чекайте швидку.

## Для цивільних

1. Виклик **швидкої** — [телефон](../basics/phone.md) → EMS.
2. **Бандаж** з [аптеки](../basics/shops.md) — лише якщо немає медиків поруч.
3. При важких ранах їдьте / їдуть з вами до ![](../.gitbook/assets/blips/61.png) **лікарні** → реєстрація на стійці.
4. Після лікування можуть видати **милиці** на кілька хвилин — не бігайте одразу в погоню.

## Для медиків

- Діагностуйте через **`лівий Alt`** → огляд / меню травм — не «знаєте» діагноз з OOC.
- Синхронізуйте лікування з [обладнанням](equipment.md): бандаж → аптечка → доставка в лікарню.
- Після check-in пацієнта в лікарні — **скелет** скидається, дебафи зникають.

{% hint style="info" %}
Не описуйте симптоми в OOC-чаті («у мене перелом») без RP. Краще `/me` або дайте медику оглянути.
{% endhint %}
