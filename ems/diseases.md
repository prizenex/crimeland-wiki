# Хвороби та травми

На CrimeLand отримати кулю чи впасти з висоти — це не просто мінус HP: тіло реагує **кровотечею**, травмою конкретної зони або станом **без свідомості** з таймером, а повністю одужати можна лише в **лікарні**.

## Типові стани

| Стан | Симптоми (RP) | Лікування |
| --- | --- | --- |
| **Кровотеча** | Втрата HP, сліди крові | <img src="../.gitbook/assets/bandage.png" data-size="line"> бандаж, EMS |
| **Пошкодження зони** | Біль у нозі, руці, голові — видно в меню травм | <img src="../.gitbook/assets/firstaid.png" data-size="line"> аптечка, лікарня |
| **Без свідомості** | Лежите на землі, таймер «кровотечі» | EMS-реанімація або лікарня |
| **Перелом / важка травма** | Повільна ходьба, дебафи | Лише ![](../.gitbook/assets/blips/61.png) **лікарня** (check-in) |
| **Стрес після бою** | Дрож, важке дихання | Відпочинок, ліки в лікарні |

## Таймери (орієнтир)

- **Кровотеча до втрати свідомості** — ~**10 хвилин**.
- **До «мозкової смерті» після падіння** — ще ~**20 хвилин**.
- **Примусове воскресіння (без EMS)** — залежить від зони та наявності медиків онлайн.

Якщо на сервері достатньо EMS — примусове воскресіння може бути **заблоковане**. Чекайте швидку.

## Для цивільних

Якщо поруч є медики — викликайте швидку через [телефон](../basics/phone.md) → EMS. Якщо нікого немає, тимчасово зупиніть кровотечу **бандажем** з [аптеки](../basics/shops.md). При важких ранах їдьте (або вас відвезуть) до лікарні ![](../.gitbook/assets/blips/61.png) і зареєструйтесь на стійці.

{% hint style="info" %}
Після лікування можуть видати милиці на кілька хвилин — не поспішайте одразу бігти в погоню.
{% endhint %}

## Для медиків

Синхронізуйте лікування з [обладнанням](equipment.md): спочатку бандаж на місці, потім аптечка за потреби, і доставка в лікарню для повного лікування. Після check-in пацієнта в лікарні **скелет** скидається, а дебафи зникають.

{% hint style="info" %}
Діагностуйте через **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)) → огляд або меню травм, а не з OOC-чату. Пацієнту теж краще описувати симптоми через `/me`, а не писати прямо в OOC («у мене перелом»).
{% endhint %}
