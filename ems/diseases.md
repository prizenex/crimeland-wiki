# Хвороби

На сервері діють **травми**, **інфекції** та **отруєння** — не завжди достатньо просто «піднятись з нуля HP».

### Типові стани

| Стан | Симптоми | Лікування |
| --- | --- | --- |
| Кровотеча | Втрата HP, сліди крові | Бандаж, EMS |
| Перелом | Повільна ходьба | Лікарня, гіпс |
| Отруєння | Нудота, дебафи | Антидот, лікар |
| Інфекція | Температура, слабкість | Медикаменти в лікарні |

### Для цивільних

- Виклик **швидкої** через [телефон](../basics/phone.md) → EMS.
- Самолікування бандажем — тимчасове; серйозні травми лише в лікарні.

Медики діагностують через службове меню — не метагеймте симптоми в OOC-чаті без RP.
