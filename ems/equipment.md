# Обладнання (ЕМС)

Медики використовують спеціальні предмети зі службового спорядження та інвентаря.

### Базовий набір

| Предмет | Призначення |
| --- | --- |
| Бандаж | Зупинка кровотечі |
| Аптечка | Відновлення здоров'я |
| Дефібрилятор | Реанімація при зупинці серця |
| Морфін / медикаменти | Лікування [хвороб](diseases.md) |

### Як застосувати

1. Підійдіть до пацієнта.
2. `лівий Alt` → медичні дії (якщо ви на зміні EMS).
3. Або використайте предмет в інвентарі на цільовому гравці.

Цивільні можуть купити **базовий бандаж** в [аптеках](../basics/shops.md) — не замінює повноцінне лікування EMS.
