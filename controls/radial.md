# Радіальне меню

**Радіальне меню** — кругове меню швидких дій. Відкривається клавішею **`F1`** (режим **перемикання**: натиснули — відкрилось, натиснули ще раз — закрилось). Працює **на ходу**, якщо не відкрите інше вікно.

> Якщо `F1` не спрацьовує — перевірте **Налаштування → Призначення клавіш → FiveM → radialmenu**.

## Структура меню

- **Улюбленці** — меню домашніх тварин
- **Подружжя** — кільця, місії вірності, рейтинг (лише для одружених)
- **Про мене** — одяг, робота, будинок, фізуха, сімʼя, зброя на ремені
- **Активні дії** — грабіж, заручник, багажник, торгівля, привітання
- **ОПЦІЇ** — ID гравців, HUD, компас, 3D GPS, підказки клавіш

Наводьте курсор на сектор і клікайте — у багатьох пунктів є **підменю** (другий рівень).

---

## Улюбленці

Пункт **«Улюбленці»** на першому рівні радіалки відкриває **сумку улюбленців** — список ваших тварин, виклик на вулицю, інвентар та одяг.

- **Сумка улюбленців** — **`F1`** → **Улюбленці** або клавіша **`I`**
- **Купівля тварини** — зоомагазин у центрі міста (біля [кафе](../business/cafe.md)) — NPC біля точки продажу
- **Команди біля улюбленця** — **`G`** — слідувати, **`F`** — меню, **`H`** — обійняти, **`X`** — скасувати

Повний гайд — [Домашні улюбленці](../character/pets.md).

## Про мене

### Одяг

Швидке зняття / одягання без заходу в гардероб:

- **Варіація / верхній одяг** — куртка, верх
- **Майка, жилет, штани** — базовий шар
- **Капелюх, маска, окуляри** — голова / обличчя
- **Взуття, рукавички, сумка** — низ і аксесуари
- **Годинник, браслет, сережки, намисто** — дрібні пропи

{% hint style="info" %}
Зміни **миттєві** — зручно для RP (зняти маску біля копів) або фото. Повний гардероб — у [салонах одягу](../character/clothing.md).
{% endhint %}

### Робота та будинок

- **Робота** — меню мультироботи: **перемкнути активну** з уже оформлених (до **4**)
- **Мій будинок** — меню [житла](../housing/house-management.md) — працює, коли ви **біля своєї нерухомості**
- **Пошкодження** — стан здоровʼя / травми персонажа
- **Фізуха** — стати, відтискання, прес, йога
- **Сімʼя** — меню сімʼї (якщо ви в сімʼї)
- **Ремінь / анімація зброї** — як носити зброю на тілі

## Активні дії

- **Грабувати** — якщо гравець **підняв руки**, у **стяжках** або в **нокдауні** (див. [Грабіж](../crime/robbery-interaction.md))
- **Заручник** — утримання гравця під загрозою (RP)
- **Залізти в багажник** — потрібен **відкритий** багажник авто
- **Торгувати** — відкрити вуличну торгівлю (сидячий режим)
- **Привітатися** — RP-жест привітання
- **Вести за руку** — супровід гравця (часто EMS / поліція)

{% hint style="info" %}
**«Грабувати»** на свідомого гравця працює, якщо він **підняв руки** (`X`) або **скручений стяжками**. У **нокдауні** — лише **один** предмет; з піднятими руками — **усі дозволені** з кишень.
{% endhint %}

## ОПЦІЇ (корисне)

- **Показати ID** — побачити **серверні ID** гравців над головою (скарги, перекази)
- **Підказки** — увімкнути / вимкнути підказки клавіш на екрані
- **Кінорежим** — приховати HUD для скріншотів
- **Мінімапа завжди** — карта на екрані не лише в авто
- **Компас** — напрямок півночі на HUD
- **3D GPS** — маршрут у світі гри
- **Очистити обʼєкти** — прибрати «залиплі» пропи на персонажі
- **Таргет** — налаштування таргета — **«Режим таргета»**: **Звичайний** або **Імерсивний** (див. [Керування → Два режими](../basics/controls.md#два-режими-таргета-звичайний-та-імерсивний))
- **Зброя 3D** — відображення зброї на моделі

## Подружжя (якщо одружені)

Розділ зʼявляється лише після [шлюбу](../character/marriage.md):

- Доставити кільця
- Місії вірності та рейтинг
- Емодзі партнера
- Одягнути / зняти обручку

---

## Поради

1. **`F1` + Одяг** — швидше, ніж їхати в гардероб, якщо треба зняти лише маску.
2. **Показати ID** — перед скаргою в `F4` завжди знімайте ID порушника.
3. Якщо меню «зависло» — `Esc` або повторне `F1`.
