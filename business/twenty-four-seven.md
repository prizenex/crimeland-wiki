# Магазин 24/7

![](../.gitbook/assets/blips/52.png) Крамниця під гравцем: ви возите товар, ставите ціни, знімаєте прибуток з **рахунку бізнесу**. Можна мати **до 3** точок, **до 10** працівників, свою назву на бліпі.

> [Огляд усіх бізнесів](overview.md)

---

## Коротко про бізнес

| | |
| --- | --- |
| **Своє (макс.)** | **3** магазини |
| **Працівники** | **10** |
| **Категорій товару** | **3** (їжа, напої, алкоголь, побутове) |
| **Завдань для [далекобійника](../jobs/trucker.md)** | **20** у черзі |
| **Покращення** | Склад · Фургон · Відносини (кожне до **5** рівня) |

---

## Заробіток — три канали

| Канал | Як працює | Коли використовувати |
| --- | --- | --- |
| **Роздріб** | Клієнт купує на полиці — різниця «ціна − закупівля» | Завжди, поки є хід біля каси |
| **Експорт** | **Склад** → **Експорт** → рейс фургоном → оптовик | Тихий район, склад забитий |
| **Команда** | Працівники + [далекобійники](../jobs/trucker.md) крутять імпорт/експорт | Масштаб без вашої участі 24/7 |

## Маржа — приклади (max прокачка)

**Відносини ~25%** · фургон **~300 од./рейс**

### Роздріб (1 продаж)

| Товар | ~Закупівля | ~Ціна на полиці | **~Маржа / шт** |
| --- | --- | --- | --- |
| Вода | **~25$** | **~85$** | **~60$** |
| Кола | **~20$** | **~68$** | **~48$** |
| Бургер | **~37$** | **~55$** | **~18$** |
| Енергетик | **~40$** | **~119$** | **~79$** |

### Експорт (1 повний рейс фургона)

| Товар | **~Прибуток / рейс** |
| --- | --- |
| Вода (300 шт.) | **~18 000$** |
| Кола (300 шт.) | **~14 500$** |
| Бургер (300 шт.) | **~5 500$** |

Точні **«Ціна експорту»** і закупівля — на вкладці **Склад** у грі.

### Команда (5 рейсів експорту / вечір)

| Товар | **~5 рейсів** |
| --- | --- |

## Функціонал — вкладки меню

| Вкладка | Що робите |
| --- | --- |
| **Ваш магазин** | Статистика, відвідування, зароблено / витрачено |
| **Склад** | Залишки · **ціна продажу** · **ціна експорту** · кнопка **Експорт** |
| **Купити товари** | **Імпорт** — рейс **самостійно** на фургоні |
| **Найняти кур'єра** | **Створити роботу** — імпорт виконає [далекобійник](../jobs/trucker.md) |
| **Категорії** | Купити / продати лінійку товарів (до **3**) |
| **Покращення** | Склад, фургон, знижка постачальника |
| **Працівники** | Найм, ролі, доступ до імпорту/експорту |
| **Каса** | Покласти / **зняти** гроші |

---

## Імпорт

| Спосіб | Де в меню | Хто везе |
| --- | --- | --- |
| **Самостійно** | **Купити товари** → галочки → **Імпорт** | Ви на фургоні з гаражу |
| **Далекобійник** | **Найняти кур'єра** → **Створити роботу** (винагорода, товар, к-ть) | [Далекобійник](../jobs/trucker.md) або кур'єр біля магазину |

Після рейсу товар на **Складі**, гроші за закупівлю + винагорода (якщо наймали) — з рахунку бізнесу.

---

## Експорт

| Крок | Дія |
| --- | --- |
| 1 | **Склад** → галочки на товарах → **Експорт** |
| 2 | Кількість (макс. = **місткість фургона**) |
| 3 | Фургон → точка на мапі → **`E`** → гараж |
| 4 | Гроші на **Касі** бізнесу |

Експорт — **ваш рейс** або **працівник** з доступом. Завдань для далекобійника на експорт **немає**.

| | Роздріб | Експорт |
| --- | --- | --- |
| Маржа | **вища** | **нижча**, але без клієнтів |
| Хто запускає | Автоматично (склад + ціна) | Ви / працівник |

## Покращення

| | Старт | 5 рівень | Що змінюється |
| --- | --- | --- | --- |
| **Склад** | 1000 од. | **5000** | Рідше возите |
| **Фургон** | мала машина | **~300** од./рейс | Більший **прибуток за рейс** |
| **Відносини** | 0% | **~25%** | **Вища маржа** з тієї ж ціни |

---

## Запуск після покупки

1. **`E`** → **«Панель власника»** → **купити**
2. **Каса** — гроші на рахунок
3. **Категорії** — обрати до **3** лінійок
4. **Купити товари** → **Імпорт** (або **Найняти кур'єра**)
5. **Склад** — виставити ціни

{% hint style="warning" %}
Без імпорту полиці **пусті**. Гроші на **Касі** — **до** замовлення рейсу.
{% endhint %}
