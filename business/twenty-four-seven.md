# Магазин 24/7

Кожен ![](../.gitbook/assets/blips/52.png) **«Магазин»** на мапі може належати **гравцю**. Це класичний **retail**: ви закуповуєте товар оптом, виставляєте **роздрібні ціни**, тримуєте склад і заробляєте на різниці — поки сусіди бігають за водою та сендвічами.

> Загальна логіка бізнесів, апгрейди та ролі — у [Огляді бізнесів](overview.md).

## Для покупця

1. Знайдіть бліп **«Магазин»** або зайдіть у звичну точку 24/7.
2. Підійдіть до **каси** → **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)).
3. Оберіть товар → оплата **готівкою** або **карткою**.

Якщо на полицях **порожньо** — власник не поповнив склад. Детальніше про всі типи точок — [Магазини](../basics/shops.md).

---

## Для власника: з чого почати

| Крок | Дія |
| --- | --- |
| 1 | Знайдіть **вільний** магазин (без власника в панелі або через IC-оголошення) |
| 2 | Службова зона → **`E`** → **«Відкрити панель власника»** |
| 3 | **Купіть** бізнес (ціна показана в меню, залежить від локації) |
| 4 | **Поповніть** рахунок бізнесу |
| 5 | **Закупіть категорії** товару та перше наповнення складу |
| 6 | Встановіть **роздрібні ціни** в допустимих межах |
| 7 | Замовте **доставку** або найміть [далекобійника](../jobs/trucker.md) |

**Ліміти:** до **3** магазинів у власності · до **2** — як працівник у чужих · до **10** співробітників · до **20** контрактів доставки в черзі.

Назву магазину можна **перейменувати** в панелі (відображається на бліпі).

---

## Асортимент: категорії

На старті без власника зазвичай працюють **базові** категорії (їжа + напої). Власник може **докупити** додаткові лінійки — максимум **3 категорії** на один магазин:

| Категорія | Що продаєте |
| --- | --- |
| **Їжа** | Снеки, фастфуд, продукти |
| **Напої** | Вода, газованка, енергетики |
| **Алкоголь** | Пиво, міцні напої (де дозволено локацією) |
| **Побутове** | Різне для повсякденного RP |

**Стратегія:** точка біля **клубу** — алкоголь + напої; біля **спавну / лікарні** — їжа + вода; **універсал** дорожчий у закупівлі, зате стабільний трафік.

## Панель власника (головне)

| Розділ | Навіщо |
| --- | --- |
| **Головна** | Баланс, статистика, швидкі дії |
| **Товари** | Ціни, залишки, додати зі свого інвентаря на склад |
| **Банк** | Поповнення / зняття коштів бізнесу |
| **Покращення** | Три гілки апгрейдів (див. нижче) |
| **Найм** | Запросити гравців, ролі доступу |
| **Доставки** | Створити рейс для себе або [далекобійника](../jobs/trucker.md) |

**Імпорт** — оптова закупівля з «оптового ринку» системи (рейс фургоном). **Експорт** — зайве зі складу можна вивезти назад з частковим поверненням.

## Апгрейди 24/7

П’ять рівнів у **кожній** гілці. Ціни рівнів — **сотні тисяч – мільйони $** з рахунку бізнесу.

| Гілка | Рівень 0 → 5 (орієнтовно) | Навіщо качати |
| --- | --- | --- |
| **Склад** | ~1000 → **~5000** одиниць | Рідше замовляєте доставку, витримуєте наплив після івенту |
| **Фургон** | малий → **~300** од./рейс | Швидше завозите великі партії |
| **Відносини** | 0% → **~25%** знижки на опт | Вища **маржа** при тій самій роздрібній ціні |

**Транспорт рейсу** росте з рівнем фургона: **Speedo** → **Burrito** → **Mule** → **Pounder** — видно одразу, «хто тут головний по логістиці».

## Як заробляти, а не «тримати бізнес»

| Помилка | Як правильно |
| --- | --- |
| Купили й забули поповнити склад | Мінімум **2–3 дні** запасу ходових позицій |
| Ціни «як у всіх», маржа 0 | Підкрутіть **відносини** і тоді трохи знизьте ціну — обійдете конкурента |
| Самі возите все вручну | Один **далекобійник** на постійку дешевше за ваш час |
| Найняли всіх друзів без ролей | Розділіть **базовий / повний** доступ — менше шахрайства з касою |

{% hint style="info" %}
Гроші з продажів лягають на **рахунок бізнесу**, не одразу в кишеню. Регулярно **знімайте прибуток** або реінвестуйте в апгрейди — інакше «заробили», а на рахунку порожньо через закупівлю.
{% endhint %}
