# Магазин 24/7

![](../.gitbook/assets/blips/52.png) Крамниця під гравцем: возите товар, ставите ціни, знімаєте прибуток з **Каси**. До **3** точок · **10** працівників · **20** завдань [далекобійнику](../jobs/trucker.md).

> [Огляд усіх бізнесів](overview.md)

---

## Найвигідніше (max прокачка)

**Відносини ~25%** · фургон **~300** од./рейс

| Що | **~Прибуток** |
| --- | --- |
| Вода — **1 продаж** (роздріб) | **~60$** |
| Енергетик — **1 продаж** | **~79$** |
| Вода — **1 рейс** експорту | **~18 000$** |
| Кола — **1 рейс** експорту | **~14 500$** |
| Вода — **5 рейсів** / вечір (команда) | **~90 000$** |

Роздріб — поки ходять біля каси. Експорт — коли склад забитий, а клієнтів мало.

---

## Структура

| | |
| --- | --- |
| **Заробіток** | Роздріб на полиці · **Експорт** залишків · команда на рейсах |
| **Склад** | Без товару каса мертва — спочатку **імпорт** |
| **Ціни** | **Склад** → **ціна продажу** і **ціна експорту** |
| **Прокачка** | **Склад** · **Фургон** · **Відносини** (до **5** рівня) |

---

## Меню

| Вкладка | Що робите |
| --- | --- |
| **Ваш магазин** | Статистика, відвідування |
| **Склад** | Залишки · ціни · **Експорт** |
| **Купити товари** | **Імпорт** — рейс **самостійно** |
| **Найняти кур'єра** | **Створити роботу** — [далекобійник](../jobs/trucker.md) |
| **Категорії** | Купити / продати лінійку (до **3**) |
| **Покращення** | Склад, фургон, знижка постачальника |
| **Працівники** | Найм, доступ до рейсів |
| **Каса** | Покласти / **зняти** гроші |

---

## Імпорт

| Спосіб | Де | Хто везе |
| --- | --- | --- |
| **Самостійно** | **Купити товари** → галочки → **Імпорт** | Ви на фургоні з гаражу |
| **Далекобійник** | **Найняти кур'єра** → **Створити роботу** | [Далекобійник](../jobs/trucker.md) |

Після рейсу товар на **Складі**. Гроші за закупівлю (+ винагорода кур'єру) — з **Каси**. На **Касі** має бути запас **до** старту рейсу.

---

## Експорт

| Крок | Дія |
| --- | --- |
| 1 | **Склад** → галочки → **Експорт** |
| 2 | Кількість (макс. = місткість фургона) |
| 3 | Фургон → точка на мапі → **`E`** → гараж |
| 4 | Гроші на **Касі** |

Експорт — **ваш рейс** або **працівник** з доступом. Завдань для далекобійника на експорт **немає**.

| | Роздріб | Експорт |
| --- | --- | --- |
| Маржа | **вища** | **нижча**, але без клієнтів |
| Хто запускає | Автоматично (склад + ціна) | Ви / працівник |

## Покращення

| | Старт | 5 рівень |
| --- | --- | --- |
| **Склад** | 1000 од. | **5000** |
| **Фургон** | мала машина | **~300** од./рейс |
| **Відносини** | 0% | **~25%** знижки на закупівлю |

---

## Старт

1. **`E`** → **Панель власника** → **купити**
2. **Каса** → гроші на рахунок
3. **Категорії** → до **3** лінійок
4. **Купити товари** → **Імпорт**
5. **Склад** → ціни
