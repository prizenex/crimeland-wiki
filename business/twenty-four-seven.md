# Магазин 24/7

![](../.gitbook/assets/blips/52.png) На мапі багато крамниць з бліпом **«Магазин»**. Частина — звичайні точки сервера з фіксованими цінами ([як у звичайному магазині](../basics/shops.md)). Частина — **під гравцем**: ви возите товар, ставите ціни, можете дати свою назву на мапі. Люди заходять за водою, їжею, сигаретами — оплата лягає на **рахунок бізнесу**, а не на зарплату з NPC-зміни.

Це найпростіший вхід у власний бізнес: меню зрозуміле, попит передбачуваний, можна тримати точку навіть без постійного RP біля каси.

> Спільна логіка всіх таких бізнесів — [Огляд](overview.md).

---

## Як тут заробляють

Схема проста: **замовили доставку** → товар на складі → **ціна на полиці вища за закупівлю** → клієнт купив → гроші на рахунку бізнесу. Далі — зняли прибуток або вклали в покращення.

Якщо прокачати **Відносини**, постачальник продає дешевше. Ціну для клієнта можна не чіпати — просто **більше лишиться вам** з кожної продажі.

Можна тримати **до 3** магазинів, найняти **до 10** людей і повісити на бліп **свою** назву.

---

## Купівля і перший запуск

1. Знайдіть вільну точку (у панелі власника немає чужого імені).
2. **`E`** → **«Відкрити панель власника»** → **купити**.
3. **Банк** — покладіть гроші на рахунок бізнесу (з нього спишуть доставки).
4. **Товари** — оберіть **до 3 категорій**: їжа, напої, алкоголь, побутове.
5. **Доставки** — перша поставка.
6. **Товари** — виставте ціни. Полиці відкриті.

У черзі доставок — до **20** контрактів одночасно.

{% hint style="warning" %}
Без доставки полиці **пусті** — ніхто нічого не купить. Гроші на **Банку** мають бути **до** замовлення рейсу.
{% endhint %}

---

## Що продавати

| Категорія | Зазвичай де заходить |
| --- | --- |
| Їжа + напої | Спавн, лікарня, центр міста |
| Алкоголь + напої | Біля клубів, вечірні точки |
| Побутове | Якщо під ваш RP у районі |

Не обов’язково брати всі три категорії одразу — краще дві, які точно ходять у вашому місці.

## Меню власника

| Вкладка | Для чого |
| --- | --- |
| **Головна** | Загальний огляд, баланс |
| **Товари** | Залишки, ціни, експорт |
| **Банк** | Покласти / зняти гроші |
| **Доставки** | Поставка — самі або [далекобійник](../jobs/trucker.md) |
| **Покращення** | Склад, фургон, знижка постачальника |
| **Найм** | Працівники, завдання для кур'єрів |

## Покращення

| | На старті | 5 рівень |
| --- | --- | --- |
| **Склад** | 1000 од. | **5000** од. |
| **Фургон** | мала машина | **~300** од./рейс (Speedo → Pounder) |
| **Відносини** | без знижки | **~25%** на закупівлю |

## Експорт, якщо мало клієнтів

У тихому районі або коли склад забитий — залишок можна **здати оптом**. У **Товарах** біля кожної позиції є **«Ціна експорту»** — вона нижча за роздріб, зате не треба чекати покупців.

1. **Товари** → обрати позиції → **Експорт**
2. Фургон з гаражу → точка на мапі → **`E`** → назад
3. Гроші на рахунку бізнесу

**Команда:** кожен працівник з доступом може крутити рейси так само, як ви. У **Найм** — до **20** завдань для [далекобійників](../jobs/trucker.md). Один ви — один фургон; п’ять людей на зміні — у п’ять разів більше рейсів за вечір.

**Орієнтовна маржа** (фургон max, **Відносини** max):

| Товар | ~За повний рейс (~300 од.) |
| --- | --- |
| Вода | **~18 000$** |
| Кола | **~14 500$** |
| Бургер | **~5 500$** |

Точну цифру дивіться в **Товарах**: ціна експорту мінус ваша закупівля з урахуванням **Відносин**.

## Для покупця

Каса → **`E`** → товар → оплата. Порожня полиця — власник не поповнив склад. [Детальніше про магазини →](../basics/shops.md)

---

## На що звернути увагу

- Купили магазин і забули про доставку — полиці пусті, заробітку немає.
- Гроші лежать на рахунку бізнесу — це ще не «у кишені», треба **зняти** через **Банк**.
- Ціна = закупівля — працюєте в нуль. Підніміть ціну або качайте **Відносини**.
