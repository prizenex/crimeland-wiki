# Магазин 24/7

![](../.gitbook/assets/blips/52.png) До **3** точок · **10** працівників · **20** завдань [далекобійнику](../jobs/trucker.md).

> [Огляд](overview.md)

---

## Скільки заробляєте

*Max прокачка: **Відносини ~25%**, фургон **~300** од./рейс.*

### На гравцях

| Приклад | Закупівля | Продаж | **Прибуток** |
| --- | --- | --- | --- |
| **Вода**, 1 шт. | ~25$ | ~85$ | **~60$** |
| **Енергетик**, 1 шт. | ~40$ | ~119$ | **~79$** |

Клієнт бере на касі — ви отримуєте різницю автоматично.

### Експорт — max за 1 ходку

| Приклад | К-ть | **Прибуток / рейс** |
| --- | --- | --- |
| **Вода** | 300 шт. (повний фургон) | **~18 000$** |
| **Кола** | 300 шт. | **~14 500$** |

**Склад** → галочки → **Експорт** → фургон → точка → **`E`** → гроші на **Касі**. Далекобійника на експорт **немає**.

---

## Як працює

1. **Імпорт** — завозите товар на **Склад**
2. **Склад** — ставите **ціну продажу**
3. **Гравці** купують на касі **або** ви робите **Експорт**
4. **Каса** — знімаєте прибуток

---

## Меню

| Вкладка | Для чого |
| --- | --- |
| **Склад** | Залишки · ціни · **Експорт** |
| **Купити товари** | **Імпорт** (самі) |
| **Найняти кур'єра** | Імпорт через [далекобійника](../jobs/trucker.md) |
| **Покращення** | Склад · Фургон · Відносини |
| **Працівники** | Найм · доступ до рейсів |
| **Каса** | Покласти / зняти |

---

## Імпорт

| | |
| --- | --- |
| **Самі** | **Купити товари** → **Імпорт** |
| **Далекобійник** | **Найняти кур'єра** → **Створити роботу** |

Гроші за закупівлю — з **Каси** одразу. Поповніть **Касу** перед рейсом.

---

## Покращення

| | Старт | 5 рівень |
| --- | --- | --- |
| **Склад** | 1000 од. | **~5000** од. |
| **Фургон** | мала машина | **~300** од./рейс |
| **Відносини** | 0% | **~25%** знижки на закупівлю |

Вкладка **Покращення** в панелі власника.

---

## Старт

1. **Купити** магазин → **Каса** → гроші
2. **Категорії** — до **3** лінійок
3. **Купити товари** → **Імпорт**
4. **Склад** → ціни
