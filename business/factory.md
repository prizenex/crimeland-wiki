# Фабрика

Фабрика перетворює **сировину** на **готову продукцію** для [магазинів 24/7](twenty-four-seven.md) та [кафе](cafe.md). Бізнес гравця — не цивільна вакансія з центру зайнятості.

## Загальний цикл

```
Сировина → Фабрика (виробництво) → Склад магазину / маркетплейс
```

1. **Власник** купує або керує фабрикою.
2. Закуповується сировина ([ферма](../jobs/farming.md), шахта, опт).
3. На фабриці запускається **виробництво** (таймер за рецептом).
4. Готова продукція йде на склад магазину або на [маркетплейс](../basics/marketplace.md).

## Для працівників

- **Завантажувач** — Привезти сировину, запустити лінію
- **Кур’єр** — Доставити готовий товар у [24/7](twenty-four-seven.md)
- **Охоронець** — RP-супровід вантажів (за домовленістю)

Найм — через **власника бізнесу** (посада в магазині + RP), не через ![](../.gitbook/assets/blips/419.png) центр зайнятості.

## Поради

- Рецепти та ціни залежать від конкретної фабрики — уточнюйте у власника **IC**.
- Для легального заробітку без бізнесу — [цивільні вакансії](../basics/city-hall.md).
