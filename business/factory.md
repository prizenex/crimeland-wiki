# Фабрика

Фабрика перетворює **сировину** на **готову продукцію** для [магазинів](twenty-four-seven.md) та [кафе](cafe.md).

### Загальний цикл

1. **Власник** купує або орендує фабрику.
2. Закуповується сировина (ферма, шахта, опт).
3. На фабриці запускається **виробництво** (таймер / рецепт).
4. Готова продукція йде на склад магазину або на [маркетплейс](../basics/marketplace.md).

### Для працівників

- Найм через власника бізнесу (RP + посада в магазині).
- Завдання: завантаження, контроль лінії, доставка готового товару.

Деталі рецептів залежать від конкретної фабрики — уточнюйте у власника IC.
