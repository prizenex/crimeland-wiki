# Фабрика

Фабрика перетворює сировину на готову продукцію для [магазинів 24/7](twenty-four-seven.md) та [кафе](cafe.md). Це бізнес гравця, який купує й веде фабрику сам — сюди не влаштуєшся через [центр зайнятості](../basics/city-hall.md).

Якщо фабрика ваша, ви закуповуєте сировину — з [ферми](../jobs/farming.md), шахти чи опту — і запускаєте виробництво: лінія працює за таймером, який залежить від рецепту. Готова продукція йде на склад магазину або на [маркетплейс](../basics/marketplace.md).

{% hint style="info" %}
Рецепти та ціни різні для кожної фабрики — уточнюйте деталі в IC у власника.
{% endhint %}

## Ролі на фабриці

**Завантажувач** — привозить сировину і запускає лінію.

**Кур'єр** — доставляє готовий товар у [24/7](twenty-four-seven.md).

**Охоронець** — RP-супровід вантажів, за домовленістю з власником.

Найм на ці посади — через власника бізнесу, як позиція в магазині плюс RP, без черги в мерії.

Якщо власна фабрика не потрібна, легальний заробіток без бізнесу дають [цивільні вакансії](../basics/city-hall.md).
