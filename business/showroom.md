# Шоурум

Приватний автосалон під гравцем — окремо від [державних салонів](../transport/dealerships.md). Замовляєте авто з каталогу, виставляєте, продаєте з **маржею**. Ключі та реєстрація — IC з покупцем.

> [Огляд усіх бізнесів](overview.md)

---

## Найвигідніше

| Що | **~Прибуток** |
| --- | --- |
| Продаж **100k** | **~20 000$** |
| Продаж **500k** | **~100 000$** |
| Продаж **2M** | **~400 000$** |
| Продаж **2M** + торг **+10%** | **~600 000$** |

**Кредит:** перший внесок **10%** · **12** платежів · **+10%** відсоток — додатковий дохід зверху маржі.

---

## Структура

| | |
| --- | --- |
| **Маржа** | **~20%** — закупівля ~80% каталожної, продаж 100% |
| **Замовлення** | Авто з серверного каталогу → на **Склад** |
| **Продаж** | IC угода · прямий продаж · **кредит** |
| **Команда** | Керівник · Старший продавець · Продавець |

---

## Меню

| Вкладка | Що робите |
| --- | --- |
| **Баланс** | Гроші салону — закупівля, виплати |
| **Склад** | Які моделі **є** · **ціна продажу** |
| **Замовлення** | Нова машина з каталогу |
| **Виставковий транспорт** | Демо на парковці · тест-драйв **~5 хв** |
| **Співробітники** | Ролі та доступ |
| **Записи** | Хто в **кредиті** · прострочки |

---

## Ролі

| Роль | Доступ |
| --- | --- |
| **Керівник** | Усе: баланс, ціни, персонал |
| **Старший продавець** | Склад, продажі, історія |
| **Продавець** | Продати, видати ключі, записи |

---

## Як продавати (без імпорту/експорту)

| Крок | Дія |
| --- | --- |
| 1 | **Замовлення** → модель → чекати **Склад** (списання з **Балансу**) |
| 2 | **Склад** → ціна продажу |
| 3 | **Виставковий транспорт** → демо (опційно) |
| 4 | Угода IC → ключі покупцю |

{% hint style="info" %}
[Державні салони](../transport/dealerships.md) — фіксований каталог сервера. **Шоурум** — **ваш** асортимент і **ваші** ціни.
{% endhint %}

---

## Старт

1. **`E`** → **«Керування автосалоном»** → **купити**
2. **Баланс** → капітал
3. **Замовлення** → модель
4. **Співробітники** → продавець на зміну

---

## Для покупця

**«Пташка»**, [маркетплейс](../basics/marketplace.md) → **`E`** → **«Відкрити шоурум»** → модель → тест-драйв → оплата / кредит.
