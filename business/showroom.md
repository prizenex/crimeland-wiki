# Шоурум

Окремо від [державних салонів](../transport/dealerships.md) (PDM, люкс, JDM…) є **приватні автосалони** під гравцем. Ви замовляєте машини з каталогу, виставляєте на парковці, продаєте з маржею. Ключі й реєстрація — IC з покупцем через систему салону.

Це інша історія, ніж [24/7](twenty-four-seven.md) чи [АЗС](gas-station.md): тут не «коробки на полиці», а **склад авто** і великі чеки. Одна вдала угода може перекрити тиждень у магазині — але потрібен стартовий капітал і люди, які не зіб’ють демо-машину на тест-драйві.

> [Огляд бізнесів](overview.md)

---

## Скільки лишається з угоди

| | ~Частка |
| --- | --- |
| Замовили у постачальника | **~80%** від ціни в каталозі |
| Продали клієнту | **100%** (або дорожче після торгу IC) |
| **Маржа** | **~20%** |

Приклад: авто **500 000$** в каталозі → купили **~400 000$** → продали **500 000$** → **~100 000$** прибутку.

Якщо салон дає **кредит** — клієнт платить частинами, ви отримуєте **відсоток** зверху (див. нижче).

---

## Запуск після покупки

1. **`E`** → **«Керування автосалоном»** → **купити**
2. **Баланс** — гроші на рахунок (з нього списуються замовлення)
3. **Замовлення** → модель з каталогу → чекати на **склад**
4. **Склад** → ціна продажу
5. **Виставковий транспорт** → машина на парковку для огляду
6. Найняти продавця — щоб не сидіти на точці цілодобово

---

## Меню

| Розділ | Для чого |
| --- | --- |
| **Баланс** | Гроші салону |
| **Склад** | Що є і за скільки продаєте |
| **Замовлення** | Нова машина з каталогу |
| **Виставковий транспорт** | Огляд, тест-драйв (~5 хв) |
| **Співробітники** | Хто продає, хто лише дивиться |
| **Записи** | Хто в кредиті, прострочки |

---

## Ролі в салоні

| Роль | Доступ |
| --- | --- |
| **Керівник** | Усе |
| **Старший продавець** | Склад, продажі, історія |
| **Продавець** | Продати, видати ключі |

Не давайте всім повний доступ — помилка з ціною суперкара б’є по **вашому** балансу.

---

## Кредит для клієнтів

| | ~Умови |
| --- | --- |
| Перший внесок | **10%** |
| Платежів | **12** |
| Відсоток | **10%** |
| Прострочення | Повернення авто |

Перевіряйте платоспроможність IC — боржник б’є по репутації салону.

---

## Вітрина і тест-драйв

На парковці можна поставити **демо-машину** — для огляду, не обов’язково ту саму, що «в наявності». Клієнт сідає, їде **~5 хв**. Тільки **в зоні** шоуруму.

**Прямий продаж** — угода з гравцем поруч після RP-огляду і торгу («скину 20к, якщо забереш сьогодні»).

---

## Приватний vs державний салон

| | Державний | Ваш шоурум |
| --- | --- | --- |
| Власник | Сервер | Гравець |
| Асортимент | Фіксований каталог | Те, що замовили |
| Ціни | Базові | Ви (в межах системи) |
| RP | Мінімум | Переговори, історія авто |

---

## Для покупця

«Пташка», [маркетплейс](../basics/marketplace.md), таблички біля локації → **`E`** → **«Відкрити шоурум»** → модель → тест-драйв → оплата готівкою / банком / кредит.

---

## На що звернути увагу

- Весь капітал у машинах на парковці — на **балансі** лишайте запас на нові **замовлення**.
- Тест-драйв без правил — депозит IC або супровід продавця.
- Реклама без машин на **складі** — клієнт приїхав даремно.
