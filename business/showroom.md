# Шоурум

**Державні [салони](../transport/dealerships.md)** (PDM, люкс, JDM, мото…) — для **нових** машин з каталогу сервера. **Приватний шоурум** — **ваш автосалон**: ви **закуповуєте** авто, **виставляєте** на локації, **продаєте** гравцям з маржею, наймаєте **менеджерів** і можете дати **розстрочку**.

> Це **інша** система, ніж [24/7](twenty-four-seven.md) / [АЗС](gas-station.md). Тут немає «складу коробок» — є **склад транспорту** і **замовлення з дилерського каталогу**.

---

## Для покупця

1. Дізнайтесь про шоурум: **«Пташка»**, [маркетплейс](../basics/marketplace.md), таблички біля локації.
2. Приїдьте → **`E`** → **«Відкрити шоурум»** / **«Переглянути в шоурумі»**.
3. Оберіть **категорію**, **модель**, **колір** — як у державному салоні.
4. **Тест-драйв** — до **~5 хв** (оцінити модель перед покупкою).
5. Оплата **готівкою / банком** або **фінансування** (якщо салон пропонує).

Угода **player-to-player** через систему салону — ключі та реєстрація проходять **IC** з продавцем.

---

## Для власника: панель «Керування автосалоном**

**`E`** у службовій зоні → **«Керування автосалоном»**.

| Розділ | Навіщо |
| --- | --- |
| **Баланс** | Гроші салону — закупівля авто, виплати |
| **Склад / інвентар** | Які моделі **в наявності** і за скільки продаєте |
| **Замовлення** | **Замовити транспорт** з опту (дилерський прайс) |
| **Виставковий транспорт** | **Демо-машини** на парковці — «вітрина» для клієнтів |
| **Співробітники** | Ролі з правами (див. нижче) |
| **Записи / фінансування** | Хто в боргу, прострочені платежі |

### Закупівля авто

Оптова ціна для власника — орієнтовно **~80%** від роздрібної в каталозі (`DealerPurchasePrice`). Різниця — **ваша маржа**, якщо продасте за повною ціною.

**Замовлення** може приходити:

- **Швидко** (хвилини) — авто з’являється на складі салону.
- Через **логістику** — рейс / доставка (якщо увімкнено на сервері).

## Команда салону

| Роль | Типові права |
| --- | --- |
| **Manager** | Повний доступ, ціни, персонал |
| **Supervisor** | Склад, продажі, доставки, історія |
| **Sales** | Продаж, перегляд записів, видача авто |

Продавець **без прав** не змінить ціну на суперкар у мінус — розділяйте ролі.

---

## Фінансування для клієнтів

Якщо салон дає **кредит** на авто (параметри сервера):

| Параметр | Орієнтовно |
| --- | --- |
| Перший внесок | **10%** |
| Платежів | **12** |
| Відсоток | **10%** |
| Прострочення | Ризик **повернення** авто (репо) |

Перевіряйте платоспроможність **IC** — один дефолт б’є по **репутації** салону.

---

## Виставковий транспорт

**Demo-машини** на території — не обов’язково те саме, що «в stock на продаж»:

- Клієнт **крутить** камеру, сідає всередину, їде в **тест-драйв**.
- Модель ставите **фіксовану** — вітрина бренду («у нас JDM», «у нас донатні»).

Розміщуйте **тільки в зоні** шоуруму — інакше система не дасть поставити.

---

## Прямий продаж

Менеджер може оформити **пряму угоду** з гравцем поруч (direct sale) — зручно для **торгу** після RP-огляду, без «клікнув і пішов».

---

## Як відрізнити від державного салону

| | **Державний салон** | **Приватний шоурум** |
| --- | --- | --- |
| Власник | Сервер / каталог | **Гравець** |
| Асортимент | Фіксований каталог | Те, що **замовили** + виставка |
| Ціни | Базові | Власник / менеджер (в межах системи) |
| RP | Мінімум | **Переговори**, історія авто, trade-in |
| Сусіди | Будь-де | Окрема локація, **не** прив’язана до СТО |

---

## Поради

- Не тримайте **100%** капіталу в машинах на парковці — **баланс салону** для нових **замовлень**.
- **Тест-драйв** без супроводу — ризик «поїхав у захід». RP-правила або депозит IC.
- Донатні / рідкісні моделі — **окрема** вітрина, не змішуйте з «першим авто новачка».
