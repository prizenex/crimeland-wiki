# Шоурум

**Свій автосалон** — це коли гравці приїжджають **до вас**, обирають машину на **вашій** парковці, торгуються IC — а різниця між **вашою закупівлею** і **ціною на табличці** лишається **вам**. Не зарплата продавця. Не «попрацював зміну». **Ваш** бренд, **ваша** вітрина, **ваші** угоди.

Один проданий суперкар може перекрити **тиждень** доходу з магазину. Зате потрібен **стартовий капітал** і **команда**, яка не злиє машину в тест-драйві.

> Це **інший** бізнес, ніж [24/7](twenty-four-seven.md) чи [АЗС](gas-station.md). Тут немає «коробок на полиці» — є **склад машин** і **замовлення з каталогу**.

---

## Чому варто

- **Великий чек** — одна угода = тисячі або сотні тисяч.
- **Ви керуєте ціною** (у межах системи) і **асортиментом** — що замовили, те й продаєте.
- **Кредит для клієнтів** — люди купують **дорожчі** авто, ви заробляєте на **відсотках**.
- **RP-центр** — переговори, тест-драйви, «мій перший Porsche».
- **Статус** — **ваша** назва на мапі, **ваші** машини на парковці.

---

## Скільки можна заробити (приклад)

| | Сума |
| --- | --- |
| Замовили авто у постачальника | **~80%** від ціни в каталозі |
| Продали клієнту | **100%** (або дорожче після торгу IC) |
| **Ваш заробіток** | **~20%** з кожної машини |

**Приклад:** каталог **500 000$** → купили за **~400 000$** → продали за **500 000$** → **~100 000$** прибутку з **однієї** угоди.

Плюс **кредит**: клієнт платить частинами — ви отримуєте **відсоток** зверху (див. нижче).

---

## Перші 30 хвилин після покупки

1. **`E`** у службовій зоні → **«Керування автосалоном»** → **купити** точку (ціна в меню).
2. **Баланс** → покласти гроші на **рахунок салону** (закупівля списується **з нього**).
3. **Замовлення** → обрати модель з каталогу → чекати доставку на **склад**.
4. **Склад** → виставити **ціну продажу**.
5. **Виставковий транспорт** → поставити **демо-машину** на парковку для огляду.
6. Найняти **продавця** — щоб не сидіти на точці 24/7.

## Меню власника — що де шукати

| Розділ | Коли відкривати |
| --- | --- |
| **Баланс** | Скільки грошей на рахунку салону |
| **Склад** | Які моделі **є** і за **скільки** продаєте |
| **Замовлення** | **Замовити** нову машину з каталогу |
| **Виставковий транспорт** | **Вітрина** — машини для огляду та тест-драйву |
| **Співробітники** | Хто може продавати, хто — тільки дивитись |
| **Записи** | Хто в **кредиті**, хто прострочив платіж |

## Для покупця (коротко)

1. Дізнайтесь про салон: **«Пташка»**, [маркетплейс](../basics/marketplace.md), таблички біля локації.
2. Приїдьте → **`E`** → **«Відкрити шоурум»**.
3. Категорія → модель → колір.
4. **Тест-драйв** — до **~5 хв**, щоб «почувати» машину.
5. Оплата **готівкою / банком** або **кредит** (якщо салон дає).

Угода проходить **через систему салону** — ключі та реєстрація **IC** з продавцем.

{% hint style="info" %}
**Державні [салони](../transport/dealerships.md)** (PDM, люкс, JDM…) — для **нових** машин з каталогу сервера. **Приватний шоурум** — **ваш** бізнес з **вашими** цінами та командою.
{% endhint %}

## Команда салону

| Роль | Що може |
| --- | --- |
| **Керівник** | Усе: ціни, персонал, баланс |
| **Старший продавець** | Склад, продажі, доставки, історія |
| **Продавець** | Продати авто, видати ключі, переглянути записи |

**Порада:** не давайте всім **повний** доступ — один «жарт» з ціною суперкара в мінус = **мінус** на вашому рахунку.

## Кредит для клієнтів

Якщо салон пропонує **розстрочку**:

| | Орієнтовно |
| --- | --- |
| Перший внесок | **10%** |
| Платежів | **12** |
| Відсоток | **10%** |
| Прострочення | Ризик **повернення** авто |

Перевіряйте платоспроможність **IC** — один боржник б’є по **репутації** салону.

---

## Вітрина та тест-драйв

**Демо-машини** на парковці — для **огляду**, не обов’язково те саме, що «в наявності на продаж»:

- Клієнт **крутить** камеру, сідає, їде **5 хв**.
- Ставите **фіксовану** модель — «у нас JDM», «у нас спорт».

Розміщуйте **тільки в зоні** шоуруму.

**Прямий продаж** — менеджер оформляє угоду з гравцем **поруч**, після RP-огляду та торгу. Зручно для «скину 20к, якщо забереш сьогодні».

## Шоурум vs державний салон

| | **Державний** | **Ваш шоурум** |
| --- | --- | --- |
| Власник | Сервер | **Ви** |
| Асортимент | Фіксований каталог | Те, що **замовили** |
| Ціни | Базові | **Ви** (в межах системи) |
| RP | Мінімум | **Переговори**, історія, trade-in |
| Прибуток | Немає | **Ваша маржа** |

---

## Три помилки новачка

1. **Весь капітал у машинах на парковці** — на **балансі** має лишатись запас для **нових замовлень**.
2. **Тест-драйв без правил** — «поїхав у захід». Депозит IC або супровід продавця.
3. **Порожній склад** — клієнт приїхав, а **немає** моделі. Замовляйте **до** реклами.
