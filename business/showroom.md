# Шоурум

Приватний автосалон під гравцем — окремо від [державних салонів](../transport/dealerships.md). Замовляєте авто з каталогу, виставляєте, продаєте з **маржею**. Ключі та реєстрація — IC з покупцем.

> [Огляд усіх бізнесів](overview.md)

---

## Коротко про бізнес

| | |
| --- | --- |
| **Що продаєте** | Авто з серверного каталогу |
| **Маржа** | **~20%** (купівля ~80% → продаж 100%) |
| **Кредит клієнтам** | **10%** перший внесок · **12** платежів · **10%** відсоток |
| **Команда** | Керівник · Старший продавець · Продавець |
| **Тест-драйв** | **~5 хв** |

---

## Заробіток — канали

| Канал | Як працює |
| --- | --- |
| **Продаж авто** | Різниця між закупівлею (~80%) і ціною на **Складі** |
| **Торг IC** | Продаж **вище** каталожної — додаткова маржа |
| **Кредит** | Клієнт платить частинами + **10%** відсоток зверху |
| **Прямий продаж** | Угода з гравцем поруч після RP-огляду |

---

## Маржа — приклади

### Продаж (без кредиту)

| Ціна в каталозі | ~Закупівля (80%) | ~Продаж | **~Прибуток** |
| --- | --- | --- | --- |
| **100 000$** | 80 000$ | 100 000$ | **~20 000$** |
| **500 000$** | 400 000$ | 500 000$ | **~100 000$** |
| **2 000 000$** | 1 600 000$ | 2 000 000$ | **~400 000$** |
| **2 000 000$** + торг +10% | 1 600 000$ | 2 200 000$ | **~600 000$** |

### Кредит (орієнтовно)

На авто **500 000$**: клієнт вносить **10%** (**50 000$**), далі **12** платежів з **10%** відсотком — додатковий дохід зверху маржі продажу.

| | ~Сума |
| --- | --- |
| Перший внесок | **10%** |
| Платежів | **12** |
| Відсоток | **10%** |
| Прострочення | Повернення авто |

---

## Функціонал — вкладки меню

| Розділ | Що робите |
| --- | --- |
| **Баланс** | Гроші салону — закупівля авто, виплати |
| **Склад** | Які моделі **є** · **ціна продажу** |
| **Замовлення** | Нова машина з каталогу → на склад |
| **Виставковий транспорт** | Демо на парковці · тест-драйв |
| **Співробітники** | Ролі: хто продає, хто керує цінами |
| **Записи** | Хто в **кредиті** · прострочки |

---

## Ролі

| Роль | Доступ |
| --- | --- |
| **Керівник** | Усе: баланс, ціни, персонал |
| **Старший продавець** | Склад, продажі, історія |
| **Продавець** | Продати, видати ключі, перегляд записів |

---

## Запуск

1. **`E`** → **«Керування автосалоном»** → **купити**
2. **Баланс** — капітал на рахунку (з нього — **Замовлення**)
3. **Замовлення** → модель → чекати **Склад**
4. **Склад** → ціна
5. **Виставковий транспорт** → демо на парковку
6. **Співробітники** → продавець на зміну

{% hint style="info" %}
[Державні салони](../transport/dealerships.md) — фіксований каталог сервера. **Шоурум** — **ваш** асортимент і **ваші** ціни.
{% endhint %}

---

## Вітрина

- Демо-машина — для огляду, не обов’язково та сама, що в продажу
- Тільки **в зоні** шоуруму
- Тест-драйв **~5 хв** — правила IC (депозит / супровід)

---

## Для покупця

**«Пташка»**, [маркетплейс](../basics/marketplace.md) → **`E`** → **«Відкрити шоурум»** → модель → тест-драйв → оплата / кредит.
