# Шоурум

Окрім державних [салонів](../transport/dealerships.md), гравці можуть володіти **приватним шоурумом** — продавати авто з власного складу.

### Для покупця

- Шукайте оголошення в **«Пташці»**, [маркетплейсі](../basics/marketplace.md) або на табличках біля шоуруму.
- Приїдьте на огляд, домовтесь про ціну.
- Угода через [ринок транспорту](../transport/market.md) або прямий обмін з власником.

### Для власника

- Купівля авто у гравців / на аукціоні → виставлення з націнкою.
- Потрібен простір для демонстрації та RP-оформлення угод.
- Співпраця з [механіками](auto-repair-shop.md) для передпродажного ТО.

Державний PDM і приватний шоурум — різні економічні ніші.
