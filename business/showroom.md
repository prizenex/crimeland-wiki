# Шоурум

Окрім державних [салонів](../transport/dealerships.md) ![](../.gitbook/assets/blips/50.png), гравці можуть володіти **приватним шоурумом** — продавати авто з власного складу.

## Для покупця

1. Шукайте оголошення в **«Пташці»**, на [маркетплейсі](../basics/marketplace.md) ![](../.gitbook/assets/blips/52.png) або на табличках біля шоуруму.
2. Приїдьте на огляд, домовтесь про ціну IC.
3. Перевірте стан авто, пробіг, тюнінг.
4. Угода — через [ринок транспорту](../transport/market.md) або прямий обмін з власником.

## Для власника

| Крок | Дія |
| --- | --- |
| Закупівля | Авто у гравців, аукціоні або з [салону](../transport/dealerships.md) |
| Виставлення | Парковка на території шоуруму + оголошення |
| Сервіс | [Механік](auto-repair-shop.md) для передпродажного ТО |
| Продаж | RP-оформлення угоди + передача ключів |

## Поради

- Державний PDM і приватний шоурум — **різні ніші**: ексклюзив, тюнінг, RP-історія авто.
- Не купуйте без огляду — перевірте документи та [страховку](../transport/driving-school.md).
