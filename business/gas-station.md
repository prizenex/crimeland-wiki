# АЗС

![](../.gitbook/assets/blips/361.png) **АЗС** — це **пасивний магніт** для кожного водія: заправка, преміум, дизель, іноді **електрозарядка**. Частина колонок належить **гравцю** — ви купуєте точку, тримаєте **склад палива**, ставите **ціни за літр** і заробляєте на кожному повному баку.

> Спільна логіка бізнесів — [Огляд](overview.md). Доставка **цистернами** — [Далекобійник](../jobs/trucker.md).

## Для водія

1. Під’їдьте до **колонки** АЗС (група бліпів **«АЗС»** на мапі).
2. **`E`** / **`лівий Alt`** → меню заправки.
3. Оберіть тип палива (**звичайне**, **плюс**, **преміум**, **дизель**, **електро** — якщо є на цій точці).
4. Вкажіть **літри** або **суму** → оплата **готівкою** / **карткою**.

| Порада | Деталі |
| --- | --- |
| Каністра | Купуйте в [магазинах](../basics/shops.md) для заправки в полі |
| Електро | Окремі зарядки — власник має **відкрити** їх за гроші бізнесу |

{% hint style="warning" %}
**Немає палива на складі** — колонки **не працюють**, навіть якщо ціни встановлені. Власнику потрібна **цистерна** вчасно.
{% endhint %}

## Для власника

| Параметр | Значення |
| --- | --- |
| Макс. АЗС у власності | **1** |
| Макс. робота на чужих АЗС | **2** |
| Працівників | До **5** |
| Контрактів доставки в черзі | До **20** |

### Старт

1. **`E`** у службовій зоні → панель власника → **купити** (ціна в меню; орієнтовно **від ~400 000$** за невеликі точки).
2. **Поповніть** рахунок бізнесу.
3. Замовте **першу поставку палива** (цистерна).
4. Встановіть **роздрібні ціни** у межах лімітів (див. нижче).

## Типи палива та ціни

На кожному типі палива — **свій склад** (літри). Власник задає **ціну за літр** у діапазоні системи:

| Паливо | Орієнтовний max ціна (за літр) |
| --- | --- |
| Звичайне | до **~190$** |
| Плюс | до **~230$** |
| Преміум | до **~250$** |
| Дизель | до **~230$** |
| Електро | до **~240$** (за одиницю заряду) |

**Оптова закупівля** (імпорт цистерною) дешевша за те, що платить клієнт — ваша **маржа**.

### Поставки палива

У панелі — **кілька форматів** поставки (мала / середня / велика): різний **обсяг літрів**, **відстань** і **рівень фургона**, який потрібен для рейсу. Великі партії — вигідніші за літр, але потребують **прокачаної доставки**.

## Електрозарядки

Окремо від бензину власник може **відкрити**:

| Тип | Орієнтовна вартість відкриття |
| --- | --- |
| **Звичайні** зарядки | **~300 000$** |
| **Швидкі** зарядки | **~900 000$** |

На мапі все більше **EV** — точка з швидкою зарядкою біля магістралі може окупити інвестицію швидше, ніж «ще одна колонка Regular».

## Апгрейди АЗС

Ті самі **три гілки × 5 рівнів**, що в [24/7](twenty-four-seven.md):

| Гілка | Макс. ефект (орієнтовно) | Сенс для АЗС |
| --- | --- | --- |
| **Склад** | **~5000 л** на тип палива | Витримати вечірній наплив без «мертвих» колонок |
| **Цистерна (доставка)** | **~50 л** за рейс на max (менше ніж у 24/7 — паливо важче логістично) | Частіші, але менші рейси — або найм далекобійника на великі контракти |
| **Відносини** | **~10%** знижки на опт | Стабільна маржа при конкуренції «хто дешевше за сусідом» |

**Тягач + цистерна** — типовий транспорт рейсу (не фургон з коробками).

## RP і конкуренція

| Ситуація | Що робить сильний власник |
| --- | --- |
| Поруч інша АЗС | **Преміум** + сервіс (RP-«кава», охорона) замість демпінгу до мінімуму |
| Банда на маршруті | Угода з **логістом** на регулярні рейси в «безпечні» години |
| Поліцейські патрулі | Легальний бізнес — привід для **легального** заробітку в RP |
