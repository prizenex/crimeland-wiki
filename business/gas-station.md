# АЗС

![](../.gitbook/assets/blips/361.png) Заправка під гравцем: паливо на складі, **ціна на табло**, водії заправляються самі. Маржа — різниця між закупкою і ціною на колонці. **1** АЗС у власності, **5** працівників, глибока прокачка.

> [Огляд усіх бізнесів](overview.md)

## Заробіток — три канали

| Канал | Як працює | Коли |
| --- | --- | --- |
| **Колонки** | Водій заправився — **~60$**/л маржі при 150$ на табло | Трафік, магістраль |
| **Експорт** | **Поповнення** → **Експорт** → цистерна → оптовик | Паливо є, клієнтів мало |
| **Електрозарядки** | Окрема покупка з рахунку АЗС | EV-трафік у районі |

## Функціонал — вкладки меню

| Вкладка | Що робите |
| --- | --- |
| **Ваша заправка** | Статистика, літри продано, відвідування |
| **Паливо** | Залишок літрів · **ціна за літр** для клієнтів |
| **Поповнення** | **Імпорт** / **Експорт** — рейс **самостійно** |
| **Найняти водія** | **Створити завдання** — імпорт [далекобійником](../jobs/trucker.md) |
| **Покращення** | Склад, цистерна, знижка |
| **Працівники** | Найм, доступ до рейсів |
| **Каса** | Покласти / **зняти** |

## Імпорт і експорт

| | Імпорт | Експорт |
| --- | --- | --- |
| **Де** | **Поповнення** → **Імпорт** | **Поповнення** → **Експорт** |
| **Самі** | Цистерна → точка → **`E`** → гараж | Те саме |
| **Далекобійник** | **Найняти водія** → завдання | **Немає** — тільки свій рейс |
| **Партії** | 500 / 1000 / **2000** л | 500 / 1000 / **2000** л |

{% hint style="info" %}
Гроші за поставку списують **одразу**. На **Касі** має бути запас **до** старту рейсу.
{% endhint %}

## Запуск

1. **`E`** → **Панель власника** → **купити**
2. **Каса** → гроші на рахунок
3. **Поповнення** → **Імпорт** (самі або **Найняти водія**)
4. **Паливо** → ціни за літр
5. Колонки працюють

---

## Для водія

**`E`** / **`лівий Alt`** → паливо → оплата. Колонка мертва — у власника **немає** палива на складі.
