# АЗС

![](../.gitbook/assets/blips/361.png) **Своя заправка** — це коли **кожна машина**, що під’їхала до колонки, залишає вам **різницю між закупкою та ціною на табло**. Водії на сервері заправляються **постійно**. Вам не треба їх ловити — вони **самі** приїжджать, якщо у вас **є паливо** і **нормальна ціна**.

> Загальна логіка меню власника — [Огляд бізнесів](overview.md).

---

## Чому варто

- **Постійний попит** — без палива ніхто далеко не поїде.
- **Ви ставите ціну** за літр (у межах ліміту сервера).
- **Покращуєте точку** — дешевша закупівля, більший склад, великі цистерни.
- **Один заклад** — можна **глибоко** прокачати, не розпиляючись.
- **Легальний RP** — зрозумілий бізнес для цивільного шляху.

---

## Скільки можна заробити (приклад)

| | Сума |
| --- | --- |
| Купили паливо (поставка) | **~90$** за літр |
| Продали на колонці | **150$** за літр |
| **Ваш заробіток** | **~60$** з кожного литра |

Повний бак **50 л** ≈ **~3000$** прибутку з **одного** клієнта. На жвавій АЗС за вечір проходять **десятки** машин — рахуйте самі.

Чим вище **Відносини** (покращення) — тим **дешевше** купуєте паливо → **більше** лишається з тієї самої ціни на колонці.

---

## Перші 30 хвилин після покупки

1. **`E`** у службовій зоні → **«Відкрити панель власника»** → **купити** АЗС (ціна в меню).
2. **Банк** → покласти гроші на **рахунок бізнесу** (з закупівлі спишуть **з нього**).
3. **Доставки** → замовити **поставку палива** (цистерна).
4. **Товари** → виставити **ціну за літр** (кожен тип окремо: звичайне, плюс, преміум, дизель).
5. Готово — колонки **працюють**, гроші **капать** на рахунок.

**Ліміти:** **1** АЗС у власності · до **5** працівників.

---

## Меню власника — що де шукати

| Вкладка | Коли відкривати |
| --- | --- |
| **Головна** | Швидко глянути, як ідуть справи |
| **Товари** | Скільки **літрів** лишилось + **ціна** для клієнтів |
| **Банк** | Покласти / **зняти зароблене** |
| **Покращення** | Прокачати склад, цистерну, знижку у постачальника |
| **Найм** | Дати другу доступ «касир» або «заступник» |
| **Доставки** | Замовити паливо — самі або [далекобійник](../jobs/trucker.md) |

---

## Паливо на колонках

| Тип | Хто заправляється |
| --- | --- |
| **Звичайне** | Більшість легкових |
| **Плюс** / **Преміум** | Хто хоче «краще» паливо |
| **Дизель** | Вантажівки, дизельні авто |
| **Електро** | Якщо **встановили** зарядку (див. нижче) |

**Максимальна ціна** для клієнта (орієнтовно): звичайне **~190$**/л · преміум **~250$**/л. Не обов’язково ставити максимум — головне **не нижче**, ніж ви купили.

---

## Поставки — як привезти паливо

У **Доставках** обираєте розмір партії. **Більша** партія — **дешевший** літр, але потрібен **вищий** рівень «Місткість вантажівки»:

| Поставка | Літрів | Коли доступна |
| --- | --- | --- |
| Невелика | **500** | з першого дня |
| Середня | **1000** | після прокачки доставки |
| Велика | **2000** | на max рівні доставки |

Везе **тягач із цистерною** — контракт може взяти [далекобійник](../jobs/trucker.md).

{% hint style="info" %}
Гроші за поставку часто **списують одразу**, коли запускаєте рейс. На **Банку** має бути запас **до** натискання «замовити».
{% endhint %}

## Покращення — що зміниться для вас

| | Без прокачки | На max (рівень 5) |
| --- | --- | --- |
| **Склад** | **1000** л на тип палива | **5000** л — рідше замовляєте |
| **Доставка** | тільки **500** л за рейс | до **2000** л — вигідніші партії |
| **Відносини** | закупівля за повною ціною | **~10%** дешевше — більший заробіток |

## Електрозарядки (додатковий заробіток)

Окремо від бензину, з **рахунку АЗС**:

| | Вартість (орієнтовно) |
| --- | --- |
| Звичайна зарядка | **~300 000$** |
| Швидка зарядка | **~900 000$** |

Поки не купили — **електро** тут не заправиться. Хто їздить на EV — поїде **до вас**, якщо ви перші поставили швидку колонку в районі.

---

## Для водія (якщо ви не власник)

Під’їхали до колонки → **`E`** / **`лівий Alt`** → обрали паливо → літри або суму → оплата. Якщо колонка **не працює** — у власника **закінчилось** паливо на складі, не «поламалась гра».

---

## Три помилки новачка

1. **Купили АЗС і не привезли паливо** — колонки мертві, заробітку нуль.
2. **Забули поповнити Банк** перед поставкою — рейс не стартує.
3. **Ціна на колонці нижча за закупівлю** — працюєте **в мінус**. Перевіряйте **Товари**.
