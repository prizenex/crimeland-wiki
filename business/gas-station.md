# АЗС

![](../.gitbook/assets/blips/361.png) Заправка під гравцем: паливо на складі, **ціна на табло**, водії заправляються самі. **1** точка · **5** працівників · **20** завдань [далекобійнику](../jobs/trucker.md).

> [Огляд усіх бізнесів](overview.md)

---

## Найвигідніше (max прокачка)

**Відносини ~10%** · цистерна **2000** л

| Що | **~Прибуток** |
| --- | --- |
| **1 заправка** 50 л (150$/л) | **~3 450$** |
| **1 заправка** 50 л преміум (200$/л) | **~5 900$** |
| **2000 л** через колонку (150$/л) | **~138 000$** |
| **1 рейс** експорту 2000 л (~100$/л) | **~38 000$** |
| **3 рейси** експорту / вечір | **~114 000$** |

Колонка в **~3,6×** вигідніша за експорт того ж обсягу — але потрібні **реальні** водії.

---

## Структура

| | |
| --- | --- |
| **Заробіток** | **Колонки** (основне) · **Експорт** залишків · електрозарядки |
| **Склад** | Літри по типах палива — без них колонки мертві |
| **Ціни** | **Паливо** → ціна за літр на табло |
| **Прокачка** | **Склад** · **Цистерна** · **Відносини** (до **5** рівня) |

---

## Меню

| Вкладка | Що робите |
| --- | --- |
| **Ваша заправка** | Статистика, літри продано |
| **Паливо** | Залишок · **ціна за літр** |
| **Поповнення** | **Імпорт** / **Експорт** — рейс **самостійно** |
| **Найняти водія** | **Створити завдання** — [далекобійник](../jobs/trucker.md) |
| **Покращення** | Склад, цистерна, знижка |
| **Працівники** | Найм, доступ до рейсів |
| **Каса** | Покласти / **зняти** |

---

## Імпорт

| | |
| --- | --- |
| **Де** | **Поповнення** → **Імпорт** |
| **Самі** | Цистерна → точка → **`E`** → гараж |
| **Далекобійник** | **Найняти водія** → завдання |
| **Партії** | **500** / **1000** / **2000** л |

Гроші за поставку списують **одразу**. На **Касі** має бути запас **до** старту рейсу.

---

## Експорт

| | |
| --- | --- |
| **Де** | **Поповнення** → **Експорт** |
| **Хто** | Тільки **ви** або **працівник** — далекобійника **немає** |
| **Партії** | **500** / **1000** / **2000** л |

Коли паливо лежить, а трафіку мало — вигідніше відвантажити, ніж тримати мертвий склад.

| Плюс / Преміум | **~230–250$**/л |

---

## Покращення

| | Старт | 5 рівень |
| --- | --- | --- |
| **Склад** | **1000** л / тип | **5000** л |
| **Цистерна** | **500** л/рейс | **2000** л/рейс |
| **Відносини** | 0% | **~10%** знижки |

---

## Старт

1. **`E`** → **Панель власника** → **купити**
2. **Каса** → гроші
3. **Поповнення** → **Імпорт**
4. **Паливо** → ціни

---

## Для водія

**`E`** / **`лівий Alt`** → паливо → оплата. Немає палива на складі — колонка не працює.
