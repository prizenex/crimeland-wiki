# АЗС

Заправки дозволяють **заправити транспорт**. Частина АЗС — **бізнеси гравців** з власним складом палива та цінами.

## Для водія

1. Під’їдьте до **колонки** АЗС — на мапі група бліпів ![](../.gitbook/assets/blips/361.png) **«АЗС»**.
2. **`E`** або **`лівий Alt`** → меню заправки.
3. Оберіть тип палива (**звичайне**, **преміум**, **дизель**, **електро** — залежить від АЗС).
4. Вкажіть суму або літри → сплатіть **готівкою** або **карткою**.

| Порада | Деталі |
| --- | --- |
| Каністра | Купуйте в [магазинах](../basics/shops.md) для екстреної заправки в полі |
| Електро | Окремі колонки на деяких АЗС — для електромобілів |

## Для власника бізнесу

| Параметр | Типове значення |
| --- | --- |
| Макс. АЗС на гравця | **1** |
| Макс. робота на чужих АЗС | **2** |
| Замовлень доставки | До **20** у панелі власника |

1. Купіть АЗС через меню власника (ціна залежить від локації — від **~600 000$**).
2. Слідкуйте за **залишками палива** на складі.
3. Замовляйте **доставку бензину** — контракти з’являються у [далекобійників](../jobs/trucker.md) (категорія пального).
4. Встановлюйте **ціни** в межах лімітів панелі.

Логістика палива пов’язана зі скриптом доставок — [далекобійник](../jobs/trucker.md) може привезти цистерну на вашу АЗС.

{% hint style="info" %}
Якщо на АЗС **немає палива на складі** — колонки не працюють. Власнику потрібно вчасно замовляти поставку.
{% endhint %}
