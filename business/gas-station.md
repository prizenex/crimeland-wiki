# АЗС

![](../.gitbook/assets/blips/361.png) Заправка під гравцем працює так: ви привозите паливо, ставите **ціну за літр** на табло, водії заправляються самі. Ваш заробіток — різниця між закупкою і ціною на колонці. Ловити клієнтів не треба — без палива далеко не поїдеш, трафік на магістралях є майже завжди.

Свою АЗС можна мати **одну**, зате прокачати глибоко: склад, цистерни, знижка у постачальника. Працівників — до **5**.

> Спільна логіка — [Огляд бізнесів](overview.md).

---

## Цифри на прикладі

| | ~Сума |
| --- | --- |
| Закупівля (велика партія) | **~90$**/л |
| Продаж на колонці | **150$**/л |
| **Маржа** | **~60$**/л |

Повний бак **50 л** — це **~3000$** з одного клієнта. На жвавій точці за вечір проїжджають десятки машин.

**Відносини** знижують закупівлю — при тій самій ціні на колонці лишається більше.

---

## Купівля і запуск

1. **`E`** → **«Панель власника»** → **купити**
2. **Банк** — гроші на рахунок бізнесу
3. **Поповнення** → **Імпорт** → поставка палива (цистерна)
4. **Товари** (запаси палива) → ціна за літр: звичайне, плюс, преміум, дизель
5. Колонки працюють — гроші на рахунок

{% hint style="info" %}
Гроші за поставку часто списують **одразу** при старті рейсу. На **Банку** має бути запас **до** «замовити».
{% endhint %}

| **Головна** | Статистика |

| **Покращення** | Склад, цистерна, знижка |

## Паливо на колонках

| Тип | Хто заправляється |
| --- | --- |
| Звичайне | Більшість легкових |
| Плюс / Преміум | Хто обирає «краще» паливо |
| Дизель | Вантажівки, дизельні авто |
| Електро | Після встановлення зарядки |

Максимум для клієнта (орієнтовно): звичайне **~190$**/л, преміум **~250$**/л. Не обов’язково ставити максимум — головне **не нижче** закупівлі.

---

## Імпорт і експорт

У **Поповненні** біля кожного типу — **Імпорт** (привезти) і **Експорт** (здати залишок).

**Імпорт:**

| Партія | Літрів | ~Закупівля |
| --- | --- | --- |
| Невелика | **500** | **~92$**/л |
| Середня | **1000** | **~91$**/л |
| Велика | **2000** | **~90$**/л |

Більша партія — дешевший літр, потрібен вищий рівень **Місткість вантажівки**.

**Експорт** — коли мало заправок біля колонок, але паливо на складі лежить:

1. **Поповнення** → тип → **Експорт** → обсяг (500 / 1000 / 2000 л)
2. Цистерна → точка на мапі → **`E`** → повернення
3. Гроші на рахунку

| | Колонка | Експорт |
| --- | --- | --- |
| ~Ціна | **150$**/л | **~100$**/л |
| Коли має сенс | Є трафік | Тиха точка, повний склад |

На max прокачці (**2000 л**, **Відносини ~10%**): закупівля **~81$**/л, експорт **~100$**/л → **~38 000$** за рейс. На колонці те саме паливо теоретично дало б **~138 000$**, але тільки якщо хтось реально заправився.

Працівники з доступом крутять рейси так само; у **Найм** — до **20** завдань для [далекобійників](../jobs/trucker.md).

## Електрозарядки

Окремо з рахунку АЗС: звичайна **~300 000$**, швидка **~900 000$**. Поки не купили — електро тут не зарядиться.

---

## Для водія

Під’їхали → **`E`** / **`лівий Alt`** → паливо → літри або сума → оплата. Колонка «не працює» — у власника **закінчилось** паливо на складі.

---

## На що звернути увагу

- Купили АЗС, не привезли паливо — колонки мертві.
- Пустий **Банк** перед поставкою — рейс не стартує.
- Ціна на колонці **нижча** закупівлі — працюєте в мінус.
