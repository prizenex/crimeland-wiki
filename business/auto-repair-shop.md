# Автомайстерня

Два пов’язані бізнеси: **майстерня** (ремонт, тюнінг, [планшет](../jobs/mechanic.md)) і **склад запчастин** (меню як у [24/7](twenty-four-seven.md)). Без деталі на складі механік не поставить Stage — навіть якщо клієнт оплатив.

> [Огляд усіх бізнесів](overview.md)

---

## Коротко про бізнес

| | |
| --- | --- |
| **Шар 1** | Майстерня — рахунки, підйомники, **~25%** комісія механіку |
| **Шар 2** | Склад запчастин (Benny's…) — опт, **маржа** на деталях |
| **Працівники складу** | **10** · завдань [далекобійнику](../jobs/trucker.md): **20** |
| **Покращення складу** | Склад · Фургон · Відносини (до **5** рівня) |

---

## Заробіток — два потоки

| Потік | Звідки | Хто отримує |
| --- | --- | --- |
| **Робота** | Рахунок у планшеті | Майстерня + **~25%** механіку |
| **Запчастини** | Опт на **Складі** vs ціна в рахунку | Власник **складу** |
| **Експорт** | **Склад** → **Експорт** залишків | Власник **складу** |

---

## Маржа — орієнтири

Точні суми залежать від робіт у [планшеті](../jobs/mechanic.md) і цін на **Складі**. Типові чеки:

| Послуга | ~Чек клієнта | Ваш дохід (орієнтовно) |
| --- | --- | --- |
| **ТО** (масло, фільтри) | **5 000–15 000$** | робота + маржа на розходниках |
| **Stage 1–2** | **20 000–50 000$** | робота + деталь зі складу |
| **Swap двигуна** | **50 000–150 000$**+ | висока маржа на деталі |
| **Нітро** | **10 000–30 000$** | робота + балони зі складу |
| **Повний ремонт після ДТП** | **15 000–40 000$** | робота + запчастини |

### Склад — експорт (max фургон **~300 од.**)

Як у [24/7](twenty-four-seven.md): залишкові деталі → **Склад** → **Експорт**. Маржа залежить від **«Ціна експорту»** конкретної позиції.

## Функціонал — майстерня

| | |
| --- | --- |
| **Ремонт** | Кузов, двигун, знос |
| **Тюнінг** | Stage, swap, турбо, stance, дрифт |
| **ТО** | Знос від пробігу |
| **Нітро** | Балони, заправка |
| **Динамометр** | Замір потужності |
| **Планшет** | **`Tab`** → **«Планшет механіка»** → **ПКМ** → **«Використати»** |

Підйомники — тільки **механіки** на зміні.

---

## Функціонал — склад запчастин

| Вкладка | Що робите |
| --- | --- |
| **Склад** | Залишки · ціни · **Експорт** |
| **Купити товари** | **Імпорт** — **самостійно** |
| **Найняти кур'єра** | **Створити роботу** — [далекобійник](../jobs/trucker.md) |
| **Покращення** | Склад **~5000** · фургон **~300** · **~25%** опт |
| **Працівники** | Доступ до рейсів |
| **Каса** | Покласти / зняти |

| Розділ товарів | Що там |
| --- | --- |
| **Замовлення** | Деталі під роботи в планшеті |
| **Сервіс** | Розходники ТО |
| **Кастом** | Кузов, колір, диски |
| **Встановлювані** | Stage, swap — знімається зі складу |

---

## Імпорт / експорт складу

| | Імпорт | Експорт |
| --- | --- | --- |
| **Самі** | **Купити товари** → **Імпорт** | **Склад** → **Експорт** |
| **Далекобійник** | **Найняти кур'єра** → завдання | — (тільки свій рейс) |
| **Команда** | Працівники + до **20** завдань | Кілька рейсів / вечір |

---

## Запуск

1. Керування майстернею + **складом** запчастин
2. **Каса** складу → гроші
3. **Купити товари** → **Імпорт** (ходовий набір: stage, гальма, масло)
4. **Найм** механіків на зміну
5. Клієнт → планшет → рахунок → оплата

Без механіків клієнти йдуть у **Customs** — [самообслуговування](../transport/tuning.md) (не ваш прибуток).
