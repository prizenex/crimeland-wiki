# Автомайстерня

Два пов’язані бізнеси: **майстерня** (ремонт, тюнінг, [планшет](../jobs/mechanic.md)) і **склад запчастин** (окрема точка). Без деталі на складі механік не поставить Stage — навіть якщо клієнт оплатив.

> [Огляд усіх бізнесів](overview.md)

---

## Найвигідніше

Рахунок механік виставляє **сам** (деталь + робота). **~25%** — комісія механіку. Цифри — якщо ви ведете **і** склад, **і** майстерню, **Відносини** 5.

| Що | Чек клієнту | **~Ваш прибуток** |
| --- | --- | --- |
| **Stage 1** (імпорт ~75k, рахунок 120k+20k) | **140 000$** | **~30 000$** |
| **Stage 2** (імпорт ~750k, рахунок 1,1M+50k) | **1 150 000$** | **~110 000$** |
| **V6 swap** (імпорт ~375k, рахунок 550k+50k) | **600 000$** | **~75 000$** |
| **Турбо** (імпорт ~75k, рахунок 120k+30k) | **150 000$** | **~40 000$** |
| **ТО** (масло + фільтри + робота) | **~15 000$** | **~5 000$** |

На дорогих деталях **закупка = ціна продажу** за замовчуванням — маржа на позиції **0**, заробіток через **рахунок**. Експорт залишків — слабий канал (Stage 1 ≈ **250$**/шт).

{% hint style="warning" %}
Рахунок **не підтягує** **Ціну продажу** зі складу. Якщо в чеку лише «робота» без деталі — ви в **мінусі** на всю закупку.
{% endhint %}

## Структура

| Шар | Що це | Гроші |
| --- | --- | --- |
| **Майстерня** | Підйомники, [планшет](../jobs/mechanic.md), рахунки | **Управління** → баланс СТО |
| **Склад** | Запчастини для встановлення | **Каса** складу, імпорт/експорт |

| | |
| --- | --- |
| **Працівники складу** | **10** · завдань [далекобійнику](../jobs/trucker.md): **20** |
| **Прокачка складу** | **Склад** · **Фургон** · **Відносини** (до **5**) |
| **Комісія механіку** | **~25%** з оплаченого рахунку |

---

## Меню — склад запчастин

| Вкладка | Що робите |
| --- | --- |
| **Склад** | Залишки · **ціна продажу** · **ціна експорту** · **Експорт** |
| **Купити товари** | **Імпорт** — **самостійно** |
| **Найняти кур'єра** | **Створити роботу** — [далекобійник](../jobs/trucker.md) |
| **Покращення** | Склад **~5000** · фургон **~300** · **~25%** опт |
| **Працівники** | Доступ до рейсів |
| **Каса** | Покласти / **зняти** |

| Розділ товарів | Що там |
| --- | --- |
| **Замовлення** | Деталі під роботи в планшеті |
| **Сервіс** | Розходники ТО |
| **Кастом** | Кузов, колір, диски |
| **Встановлювані** | Stage, swap — знімається при установці |

---

## Меню — майстерня (планшет)

| Розділ | Для чого |
| --- | --- |
| **Тюнінг** | Stage, swap, турбо, дрифт |
| **Обслуговування** | ТО за пробігом |
| **Рахунки** | Чек клієнту — **сума вручну** |
| **Управління** | Баланс майстерні |

Планшет: **`Tab`** → **«Планшет механіка»** → **ПКМ** → **«Використати»**.

---

## Імпорт (склад)

| Спосіб | Де | Хто |
| --- | --- | --- |
| **Самостійно** | **Купити товари** → **Імпорт** | Ви на фургоні |
| **Далекобійник** | **Найняти кур'єра** → завдання | [Далекобійник](../jobs/trucker.md) |

**Вартість** партії — на екрані імпорту (мінус **Відносини**). Після рейсу деталі на **Складі**.

---

## Експорт (склад)

| | |
| --- | --- |
| **Де** | **Склад** → галочки → **Експорт** |
| **Хто** | Ви або працівник — далекобійника **немає** |
| **Макс.** | **~300** од. за рейс (max фургон) |

Маржа — від **«Ціна експорту»** кожної позиції. На Stage/swap це запасний варіант, не основний заробіток.

---

## Старт

1. Керування майстернею + **складом** запчастин
2. **Каса** складу → гроші
3. **Купити товари** → **Імпорт** (stage, масло, гальма)
4. **Найм** механіків на зміну
5. Клієнт → планшет → рахунок (деталь + робота) → оплата

Без механіків клієнти йдуть у **Customs** — [самообслуговування](../transport/tuning.md).
