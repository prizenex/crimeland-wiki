# Автомайстерня

Два пов’язані бізнеси: **майстерня** (ремонт, тюнінг, [планшет](../jobs/mechanic.md)) і **склад запчастин** (окрема точка — **Склад**, **Купити товари**, **Каса**). Без деталі на складі механік не поставить Stage — навіть якщо клієнт оплатив.

> [Огляд усіх бізнесів](overview.md)

---

## Коротко про бізнес

| | |
| --- | --- |
| **Шар 1** | Майстерня — рахунки, підйомники, **~25%** комісія механіку |
| **Шар 2** | Склад запчастин (Benny's…) — опт, **маржа** на деталях |
| **Працівники складу** | **10** · завдань [далекобійнику](../jobs/trucker.md): **20** |
| **Покращення складу** | Склад · Фургон · Відносини (до **5** рівня) |

---

## Заробіток — два потоки

| Потік | Звідки | Хто отримує |
| --- | --- | --- |
| **Робота** | Рахунок у планшеті | Майстерня + **~25%** механіку |
| **Запчастини** | Опт на **Складі** vs ціна в рахунку | Власник **складу** |
| **Експорт** | **Склад** → **Експорт** залишків | Власник **складу** |

---

## Де ви бачите гроші

Окремого рядка **«прибуток з цього Stage»** у грі **немає**. Два бізнеси — два меню; суму треба збирати самому або домовлятися з механіками про прайс.

| Де | Що показує | Для чого |
| --- | --- | --- |
| **Склад** → **Склад** | **Ціна продажу**, **Ціна експорту**, залишок | Скільки можна взяти за деталь / скільки дасть експорт |
| **Купити товари** → **Імпорт** | **Вартість** партії (з урахуванням **Відносин**) | Скільки ви **заплатите** за завоз |
| **Планшет** → **Рахунки** | Позиції й **сума**, яку механік виставив клієнту | Чек **до/після** оплати |
| **Планшет** → **Управління** | **Баланс рахунку** майстерні | Скільки лягло на рахунок СТО після оплат |

**Важливо:** ціна в рахунку **не підтягується** автоматично з **Ціни продажу** на складі. Механік **сам** додає деталь, роботу та суму. Якщо в рахунок не закладена вартість Stage чи swap — прибуток лишається лише на папері складу (ви вже заплатили за імпорт).

На дорогих деталях **ціна закупки = ціна продажу** за замовчуванням — маржа на самій позиції **0**. Заробіток на встановленні — через **рахунок майстерні** (мінус **~25%** комісії механіку).

## Маржа — орієнтири

### ТО та дрібниці

| Послуга | ~Чек клієнта | Звідки дохід |
| --- | --- | --- |
| **ТО** (масло, фільтри, колодки) | **5 000–20 000$** | Рахунок майстерні; деталі з розділу **Сервіс** на складі |
| **Кузов / ремонт** | **15 000–40 000$**+ | Рахунок + % від вартості авто в планшеті |

### Дорогий тюнінг — цифри зі складу

Закупка — вкладка **Купити товари** (**Вартість**). **Ціна продажу** на **Складі** — орієнтир, скільки закласти в рахунок за деталь. **Експорт** — якщо деталь так і лежить на полиці.

| Деталь | Закупка (імпорт) | Ціна продажу | Експорт / од. | Приклад роботи в рахунку* |
| --- | --- | --- | --- | --- |
| **Stage 1** | **100 000$** | **100 000$** | **75 250$** | **20 000$** |
| **Stage 2** | **1 000 000$** | **1 000 000$** | **750 250$** | **30 000$** |
| **Турбо** | **100 000$** | **100 000$** | **75 500$** | **30 000$** |
| **V6 swap** | **500 000$** | **500 000$** | **377 000$** | **30 000$** |
| **2JZ swap** | — | — | — | **100 000$** (лише робота; деталь окремо, якщо є на складі) |
| **Нітро (комплект)** | **500 000$** | **500 000$** | **376 000$** | окремо в планшеті |
| **Дрифт-комплект** | **300 000$** | **300 000$** | **226 000$** | **50 000$** |

\*Рядок «робота» — орієнтир для позиції в рахунку; **не** додається до ціни деталі автоматично.

**Приклад Stage 1:** імпорт **100 000$** → у рахунку клієнту, наприклад, **120 000$** (деталь) + **20 000$** (робота) = **140 000$**. На рахунок майстерні після **25%** механіку ≈ **105 000$**. Мінус закупка деталі ≈ **5 000$** чистими на всю операцію — якщо власник веде **і** склад, **і** майстерню. Більший чек = ваша ціна в **Рахунках**, не кнопка «показати прибуток».

З **Відносинами** рів. **5** (**~25%** знижка) закупка Stage 1 ≈ **75 000$** — той самий приклад дає ≈ **30 000$**+, якщо в рахунку лишаєте **100 000$** за деталь.

### Склад — експорт (max фургон **~300 од.**)

Залишкові деталі → **Склад** → **Експорт**. Маржа залежить від **«Ціна експорту»** конкретної позиції.

## Функціонал — майстерня

| | |
| --- | --- |
| **Ремонт** | Кузов, двигун, знос |
| **Тюнінг** | Stage, swap, турбо, stance, дрифт |
| **ТО** | Знос від пробігу |
| **Нітро** | Балони, заправка |
| **Динамометр** | Замір потужності |
| **Планшет** | **`Tab`** → **«Планшет механіка»** → **ПКМ** → **«Використати»** |

Підйомники — тільки **механіки** на зміні.

## Функціонал — склад запчастин

| Вкладка | Що робите |
| --- | --- |
| **Склад** | Залишки · ціни · **Експорт** |
| **Купити товари** | **Імпорт** — **самостійно** |
| **Найняти кур'єра** | **Створити роботу** — [далекобійник](../jobs/trucker.md) |
| **Покращення** | Склад **~5000** · фургон **~300** · **~25%** опт |
| **Працівники** | Доступ до рейсів |
| **Каса** | Покласти / зняти |

| Розділ товарів | Що там |
| --- | --- |
| **Замовлення** | Деталі під роботи в планшеті |
| **Сервіс** | Розходники ТО |
| **Кастом** | Кузов, колір, диски |
| **Встановлювані** | Stage, swap — знімається зі складу |

## Імпорт / експорт складу

| | Імпорт | Експорт |
| --- | --- | --- |
| **Самі** | **Купити товари** → **Імпорт** | **Склад** → **Експорт** |
| **Далекобійник** | **Найняти кур'єра** → завдання | — (тільки свій рейс) |
| **Команда** | Працівники + до **20** завдань | Кілька рейсів / вечір |

---

## Запуск

1. Керування майстернею + **складом** запчастин
2. **Каса** складу → гроші
3. **Купити товари** → **Імпорт** (ходовий набір: stage, гальма, масло)
4. **Найм** механіків на зміну
5. Клієнт → планшет → рахунок → оплата

Без механіків клієнти йдуть у **Customs** — [самообслуговування](../transport/tuning.md) (не ваш прибуток).
