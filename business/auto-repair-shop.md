# Автомайстерня

Тут **два шари**, які працюють разом:

1. **Майстерня** — ремонт, тюнінг, ТО, рахунки, підйомники, **планшет механіка**.
2. **Магазин запчастин** (наприклад **Benny's**) — **склад деталей**, опт, доставки, **ті самі апгрейди**, що в [24/7](twenty-four-seven.md).

Клієнт заїхав на **Stage** → механік бере деталь **зі складу магазину** → ставить через планшет → оплата йде в **касу майстерні**. Без складу — немає swap'ів і stage'ів «з коробки».

> Огляд апгрейдів і логістики — [Огляд бізнесів](overview.md). Робота механіка — [Механік](../jobs/mechanic.md).

---

## Для клієнта

1. Заїдьте в **зону майстерні** (підйомник / бай).
2. Зверніться до **механіка** IC або через **«Послуги»** в [телефоні](../basics/phone.md).
3. Дочекайтесь робіт → оплатіть **рахунок** (готівка / картка на рахунок СТО).

**Без механіка на зміні** — [самообслуговування](../transport/tuning.md) у зонах **Customs** (доки, Sandy, марина тощо): базовий тюнінг без RP-обслуговування.

---

## Шар 1 — Майстерня (сервіс)

### Що вміє точка

| Послуга | Деталі |
| --- | --- |
| **Ремонт** | Кузов, двигун, знос після ДТП |
| **Тюнінг** | Stage, swap, привід, дрифт, турбо, вихлоп, stance |
| **ТО** | Знос від **пробігу** — фільтри, масло, гальма (див. [Механік](../jobs/mechanic.md)) |
| **Нітро** | Балони, заправка |
| **Динамометр** | Замір потужності після збірки |
| **Рахунки** | Клієнт платить за позиціями в планшеті |

### Планшет механіка

| Крок | Дія |
| --- | --- |
| Відкрити | **`Tab`** → предмет **«Планшет механіка»** → **ПКМ** → **«Використати»** |
| Замовлення | Клієнт у зоні → оформити роботи в планшеті |
| Оплата | Рахунок → кошти на **рахунок майстерні** (частина — **комісія** механіку, орієнтовно **~25%**) |

**Підйомники** — лише для **співробітників** на зміні (не самообслуговування).

### Власник / керівник СТО

- Найм через **job** майстерні (Benny's, LS Customs, Beeker, SGC тощо).
- Керування **балансом** організації, цінами послуг у конфігурації точки.
- **Команда на зміні** = гроші; порожня майстерня = клієнти їдуть у **Customs**.

## Шар 2 — Магазин запчастин (Benny's та аналоги)

Окремий **бізнес з панеллю власника** (як у [24/7](twenty-four-seven.md)) у зоні майстерні:

| Розділ | Що там |
| --- | --- |
| **Замовлення (orders)** | Деталі під **конкретні** роботи в планшеті |
| **Сервіс** | Розхідники ТО, ремонт |
| **Кастом** | Кузов, колір, диски |
| **Usable** | Предмети, що **встановлюються** з інвентаря (swap, stage kits) |

### Чому це важливо

Багато робіт у планшеті потребують **фізичної деталі** на складі — без предмета механік **не встановить** мод, навіть якщо клієнт уже оплатив рахунок.

**Цикл:**

```
Панель магазину → імпорт деталей → склад Benny's
       ↓
Механік: планшет → списання зі складу → встановлення
       ↓
Оплата клієнта → рахунок майстерні → прибуток
```

### Апгрейди магазину запчастин

**Ті самі три гілки**, що в [24/7](twenty-four-seven.md): **склад ~5000**, **рейс ~300 од.**, **~25%** на опт. Категорій може бути **до 5** (усі лінійки тюнінгу).

Доставки — знову через [далекобійників](../jobs/trucker.md) (фургон з коробками).

| Орієнтир | Де |
| --- | --- |

Деталі — [Тюнінг](../transport/tuning.md). Це **не** ваш бізнес-прибуток — але звідси клієнти **приїжджать** до Benny's за «нормальним» Stage.

## Бізнес-модель (як заробляти)

| Джерело | Хто заробляє |
| --- | --- |
| Маржа на **запчастинах** | Власник **магазину** (опт vs ціна в рахунку) |
| **Робота** в планшеті | Майстерня + **комісія** механіка |
| **Нітро / дрифт-пакети** | Високий чек, потрібен **сток** на складі |
| **ТО за пробігом** | Постійні клієнти з [механіків](../jobs/mechanic.md) на зміні |

### Типова помилка

Купили тільки **job майстерні**, забули **вести склад Benny's** → механіки стоять, клієнти лаються, «СТО не працює». Склад — **обов’язкова** половина бізнесу.

---

## Поради

- Тримайте **TOP-20** ходових деталей (stage, гальма, oil) — не весь каталог одразу.
- Один **логіст** на вечірні рейси дешевший за простій підйомника.
