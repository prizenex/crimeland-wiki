# Автомайстерня

**Своя СТО** — це коли клієнти приїжджають на **Stage**, **swap** або **ТО**, механік відкриває **планшет**, бере деталь **зі складу** — а гроші йдуть на **ваш рахунок**. На сервері **завжди** хтось ламає машину, **завжди** хтось хоче «швидше» або «нижче». Ви заробляєте **на роботі** і **на запчастинах**.

Тут **два шари**, які працюють разом:

1. **Майстерня** — ремонт, тюнінг, підйомники, **планшет механіка**.
2. **Магазин запчастин** (наприклад **Benny's**) — **склад деталей**, доставки, **ті самі покращення**, що в [24/7](twenty-four-seven.md).

Без **складу** механіки **не зможуть** поставити Stage — навіть якщо клієнт уже оплатив. Склад — **обов’язкова** половина бізнесу.

> Загальна логіка меню складу — [Огляд бізнесів](overview.md). Робота механіка — [Механік](../jobs/mechanic.md).

---

## Чому варто

- **Постійний попит** — ДТП, знос, «хочу турбо».
- **Великі чеки** — Stage + swap + нітро = **десятки тисяч** за візит.
- **Два джерела доходу** — **маржа на деталях** + **комісія** з робіт.
- **RP-центр** — тусовка механіків, «своя» точка в місті.
- **Масштаб** — наймаєте зміну, заробляєте **навіть офлайн** (якщо склад повний).

---

## Як ви заробляєте

```
Клієнт заїхав → механік оформив у планшеті → деталь зі складу
       ↓
Клієнт оплатив рахунок → гроші на рахунок майстерні
       ↓
Частина — комісія механіку (~25%) · решта — вам + маржа на деталях
```

| Джерело | Хто заробляє |
| --- | --- |
| **Запчастини** (опт vs ціна в рахунку) | Власник **магазину** |
| **Робота** в планшеті | Майстерня + **комісія** механіка |
| **Нітро / дрифт-пакети** | Високий чек, потрібен **сток** |
| **ТО за пробігом** | Постійні клієнти |

---

## Перші 30 хвилин

1. Отримати **керування** майстернею (найм / покупка — залежить від точки на сервері).
2. **Панель магазину запчастин** → **Банк** → покласти гроші.
3. **Доставки** → перша **поставка** ходових деталей (stage, гальма, масло).
4. Найняти **механіка** на зміну — без нього клієнти йдуть у **Customs** (самообслуговування).
5. Клієнт заїхав → механік **`Tab`** → **«Планшет механіка»** → оформити роботи.

---

## Для клієнта (коротко)

1. Заїдьте в **зону майстерні** (підйомник / бай).
2. Зверніться до **механіка** IC або через **«Послуги»** в [телефоні](../basics/phone.md).
3. Дочекайтесь робіт → оплатіть **рахунок**.

**Без механіка на зміні** — [самообслуговування](../transport/tuning.md) у зонах **Customs** (доки, Sandy, марина): базовий тюнінг **без** RP-обслуговування.

---

## Планшет механіка

| Крок | Дія |
| --- | --- |
| Відкрити | **`Tab`** → **«Планшет механіка»** → **ПКМ** → **«Використати»** |
| Замовлення | Клієнт у зоні → оформити роботи |
| Оплата | Рахунок → кошти на **рахунок майстерні** |

**Підйомники** — лише для **співробітників** на зміні.

---

## Що вміє майстерня

| Послуга | Для кого |
| --- | --- |
| **Ремонт** | Після ДТП, знос |
| **Тюнінг** | Stage, swap, привід, дрифт, турбо, stance |
| **ТО** | Знос від **пробігу** — фільтри, масло, гальма |
| **Нітро** | Балони, заправка |
| **Динамометр** | Замір потужності після збірки |

## Магазин запчастин — меню власника

Та сама логіка, що в [24/7](twenty-four-seven.md):

| Розділ | Що там |
| --- | --- |
| **Замовлення** | Деталі під **конкретні** роботи |
| **Сервіс** | Розхідники ТО, ремонт |
| **Кастом** | Кузов, колір, диски |
| **Встановлювані** | Stage-кits, swap — те, що **знімається зі складу** |

### Покращення (як у 24/7)

| | Старт | Max |
| --- | --- | --- |
| **Склад** | 1000 од. | **~5000** |
| **Фургон** | мала машина | **~300** од./рейс |
| **Відносини** | 0% | **~25%** знижки на опт |

Доставки — [далекобійник](../jobs/trucker.md).

## Зони самообслуговування (Customs)

| Де | Що |
| --- | --- |
| Доки LS | Південь міста |
| Sandy Shores | Пустеля |
| Марина | Захід LS |

Це **не** ваш прибуток — але звідси клієнти **приїжджать** до Benny's за «нормальним» Stage. Деталі — [Тюнінг](../transport/tuning.md).

---

## Три помилки новачка

1. **Купили майстерню, забили склад** — механіки стоять, «СТО не працює».
2. **Немає механіків на зміні** — клієнти їдуть у **Customs**.
3. **Замовили весь каталог** — тримайте **топ-20** ходових деталей (stage, гальма, oil).
