# Автомайстерня

**Майстерня** ([планшет](../jobs/mechanic.md)) + **склад запчастин** (окрема точка). Без деталі на складі Stage не поставлять.

> [Огляд](overview.md)

---

## Скільки заробляєте

*Max прокачка: **Відносини ~25%** на складі. **~25%** рахунку — комісія механіку. Цифри — якщо ви ведете **обидва** бізнеси.*

### На гравцях

| Приклад | Чек клієнту | **Ваш прибуток** |
| --- | --- | --- |
| **Stage 2** (деталь + робота) | **1 150 000$** | **~110 000$** |
| **Stage 1** (деталь + робота) | **140 000$** | **~30 000$** |
| **ТО** (масло, фільтри, робота) | **~15 000$** | **~5 000$** |

Механік виставляє **Рахунок** у планшеті: деталь + робота. Ціна **не** підтягується зі складу автоматично.

### Експорт — max за 1 ходку

| Приклад | К-ть | **Прибуток / рейс** |
| --- | --- | --- |
| **Косметичні деталі** | 300 шт. (max фургон) | **~75 000$** |

**Склад** → **Експорт**. На Stage/swap експорт **слабкий** — основний заробіток через **рахунки**, не вивоз.

{% hint style="warning" %}
Якщо в рахунку лише «робота» без ціни деталі — ви в **мінусі** на всю закупку.
{% endhint %}

---

## Як працює

**Склад:** імпорт → деталі на полиці → механік знімає при установці → **експорт** залишків.

**Майстерня:** клієнт → планшет → установка → **Рахунок** → оплата на баланс СТО.

| Вкладка | Для чого |
| --- | --- |
| **Склад** | Залишки · ціни · **Експорт** |
| **Купити товари** | **Імпорт** (самі) |
| **Найняти кур'єра** | Імпорт через [далекобійника](../jobs/trucker.md) |
| **Покращення** | Склад · Фургон · Відносини |
| **Каса** | Покласти / зняти |

| Розділ товарів | Що там |
| --- | --- |
| **Сервіс** | Масло, фільтри, колодки |
| **Встановлювані** | Stage, swap, турбо |

---

## Меню — майстерня

| Розділ | Для чого |
| --- | --- |
| **Рахунки** | Чек клієнту |
| **Управління** | Баланс СТО |
| **Тюнінг** | Stage, swap, турбо |

Планшет: **`Tab`** → **«Планшет механіка»** → **ПКМ** → **Використати**.

## Покращення (склад)

| | Старт | 5 рівень |

| **Склад** | 1000 од. | **~5000** од. |
| **Фургон** | мала машина | **~300** од./рейс |

## Старт

1. **Каса** складу → гроші
2. **Купити товари** → **Імпорт**
3. Механіки на зміні → **Рахунок** (деталь + робота)
