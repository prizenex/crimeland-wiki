# Кафе

![](../.gitbook/assets/blips/827.png) Кафе — **бізнеси гравців** з їжею та напоями (наприклад, **Bean Machine**, **UwU Cat Cafe**). Популярне місце для RP-зустрічей і відновлення [статусів](../character/statuses.md).

На мапі (`P`) — бліп ![](../.gitbook/assets/blips/827.png) **«Кафе»**.

## Для відвідувача

1. Знайдіть кафе на мапі — бліп ![](../.gitbook/assets/blips/827.png) **«Кафе»** або назва в ![](../.gitbook/assets/blips/419.png) [каталозі бізнесів](../basics/city-hall.md).
2. Підійдіть до каси → **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)) → меню.
3. Купіть **каву, випічку, снеки** — оплата готівкою або карткою.
4. Використайте їжу з [інвентаря](../character/inventory.md) для голоду / спраги.

## Для власника

1. **Купівля** — Знайдіть вільне кафе → **`E`** / **`лівий Alt`** → панель власника (**Склад**, **Каса**, **Працівники**)
2. **Асортимент** — Кава, випічка, снеки — закупівля та ціни
3. **Персонал** — Найм бариста (до **10** працівників)
4. **Постачання** — [Фабрика](factory.md), [ферма](../jobs/farming.md) або доставка

## Поради

- Кафе — зручна точка для ділових зустрічей і найму через [телефон](../basics/phone.md).
- Власник може **перейменувати** заклад — орієнтуйтесь на бліп ![](../.gitbook/assets/blips/827.png) **«Кафе»** або каталог у мерії.
