# Кафе

Кафе — магазини їжі та напоїв під керуванням гравців (наприклад, **Bean Machine**). Популярне місце для RP-зустрічей.

### Для відвідувача

1. Знайдіть бліп кафе на мапі.
2. `E` у зоні каси → меню.
3. Купіть їжу та напої для відновлення [статусів](../character/statuses.md).

### Для власника

- Панель власника — як у [24/7](twenty-four-seven.md).
- Асортимент: кава, випічка, снеки.
- Найм бариста, встановлення цін, постачання з [фабрики](factory.md) або ферми.

Кафе — зручна точка для ділових зустрічей і найму через [телефон](../basics/phone.md).
