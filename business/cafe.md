# Кафе

Кафе — **бізнеси гравців** з їжею та напоями (наприклад, **Bean Machine**). Популярне місце для RP-зустрічей і відновлення [статусів](../character/statuses.md).

## Для відвідувача

1. Знайдіть кафе на мапі — зазвичай бліп ![](../.gitbook/assets/blips/52.png) **«Магазин»** або назва в ![](../.gitbook/assets/blips/419.png) [каталозі бізнесів](../basics/city-hall.md).
2. Підійдіть до каси → **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)) → меню.
3. Купіть **каву, випічку, снеки** — оплата готівкою або карткою.
4. Використайте їжу з [інвентаря](../character/inventory.md) для голоду / спраги.

## Для власника

| Крок | Дія |
| --- | --- |
| Купівля | Знайдіть вільне кафе → панель власника (як у [24/7](twenty-four-seven.md)) |
| Асортимент | Кава, випічка, снеки — закупівля та ціни |
| Персонал | Найм бариста (до **10** працівників) |
| Постачання | [Фабрика](factory.md), [ферма](../jobs/farming.md) або доставка |

## Поради

- Кафе — зручна точка для ділових зустрічей і найму через [телефон](../basics/phone.md).
- Власник може **перейменувати** заклад — орієнтуйтесь на бліп або каталог у мерії.
