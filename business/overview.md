# Бізнеси гравців

На сервері є бізнеси, де **власник — гравець**: магазин, заправка, склад запчастин, автосалон. Ви купуєте точку, поповнюєте склад, ставите ціни — гроші з продажів йдуть на **рахунок бізнесу**. Це не зарплата з NPC і не «відпрацював зміну на роботі».

Багато хто тримає такі точки роками: стабільний дохід, своя назва на мапі, зручна база для RP у районі.

## Типовий день (24/7 або АЗС)

1. **`E`** у службовій зоні → **«Панель власника»**
2. **Банк** — скільки на рахунку
3. Склад пустий → **Доставки** (ви або [далекобійник](../jobs/trucker.md))
4. **Товари** — перевірити ціни
5. Клієнти купують самі, поки склад повний (навіть якщо ви офлайн)
6. Зняли прибуток або вклали в **Покращення**

{% hint style="warning" %}
**Порожній склад = нуль продажів.** На АЗС колонки не працюють без палива в цистернах.
{% endhint %}

## Експорт, коли мало клієнтів

Якщо район тихий або склад переповнений — залишок можна **продати оптом** рейсом. У **Товарах** (магазин, склад) або **Поповненні** (АЗС) є кнопка **Експорт**. Ціна нижча за роздріб, зате не треба чекати покупців.

| Бізнес | Де в меню |
| --- | --- |
| 24/7 · склад запчастин | **Товари** → **Експорт** |
| АЗС | **Поповнення** → **Експорт** |

**Команда:** працівники з доступом запускають рейси так само, як власник. У **Найм** — до **20** завдань для [далекобійників](../jobs/trucker.md). Більше людей — більше рейсів за вечір.

**Маржа за один рейс** (max прокачка, орієнтовно):

| | Приклад | ~Прибуток |
| --- | --- | --- |
| 24/7 | Вода, фургон 300 шт. | **~18 000$** |
| 24/7 | Кола, 300 шт. | **~14 500$** |
| АЗС | 2000 л звичайного | **~38 000$** |

На колонці маржа вища (~60$/л), але потрібні клієнти. Деталі — у [24/7](twenty-four-seven.md) та [АЗС](gas-station.md).

## Покращення

У **Покращення** три лінії, кожна до **5 рівня**:

| | Що дає |
| --- | --- |
| **Склад** | Більше товару / палива без нової доставки (~**5000** на max) |
| **Вантажівка** | Більше за один рейс (~**300** од. / **2000** л) |
| **Відносини** | Дешевша закупівля (~**25%** у магазині, ~**10%** на АЗС) |

## З чого почати

**Новачку** — [24/7](twenty-four-seven.md) у жвавому місці: їжа + напої, одна доставка, ціни трохи вище сусідів. Просте меню, передбачуваний дохід.

**Хочете одну точку на повну** — [АЗС](gas-station.md) на проїзній дорозі: кожна заправка = гроші.

**Є капітал і команда** — [шоурум](showroom.md): одна угода може перекрити тиждень у магазині.
