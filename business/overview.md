# Бізнеси гравців

На CrimeLand **магазин, заправка, майстерня чи автосалон** — це не декорація на мапі, а **жива економіка**: ви купуєте точку, ведете склад, наймаєте людей, крутите логістику і поступово **прокачуєте** бізнес, щоб заробляти більше сусідів, які просто «підбігли до полиці».

Цей розділ — про **приватні бізнеси**. Державні [салони](../transport/dealerships.md) і зони **Customs** (самообслуговування) — окрема історія; тут — те, що **належить гравцю**.

## Карта бізнесів

| Бізнес | Суть | Гайд |
| --- | --- | --- |
| **Магазин 24/7** | Їжа, напої, алкоголь, побутове — продаж мешканцям | [24/7](twenty-four-seven.md) |
| **АЗС** | Паливо + зарядки, ціни задає власник | [АЗС](gas-station.md) |
| **Автомайстерня** | Ремонт, тюнінг, ТО + **магазин запчастин** | [Автомайстерня](auto-repair-shop.md) |
| **Шоурум** | Приватний автосалон: склад авто, продажі, фінансування | [Шоурум](showroom.md) |

{% hint style="info" %}
**24/7**, **АЗС** і **магазин запчастин** у майстерні працюють на **одній логіці**: панель власника, склад, доставки, три гілки апгрейдів.

**Автомайстерня** (ремонт, планшет, запчастини) і **шоурум дилера** (продаж авто) — **різні бізнеси**, різні локації та механіки. Не плутайте їх між собою і з [державними салонами](../transport/dealerships.md).
{% endhint %}

## Життєвий цикл (магазин / АЗС / запчастини)

```mermaid
flowchart LR
  A[Купити бізнес] --> B[Поповнити рахунок]
  B --> C[Закупівля / імпорт]
  C --> D[Склад]
  D --> E[Продаж клієнтам]
  E --> F[Прибуток]
  F --> G[Апгрейди + зарплати]
  G --> C
```

1. **Купівля** — у службовій зоні бізнесу (`E` → панель власника). Ціна залежить від локації.
2. **Рахунок бізнесу** — окремий баланс; з нього йдуть закупівлі, апгрейди, частина доставок.
3. **Склад** — поки товару / палива **немає**, клієнти нічого не купують (порожні полиці або «мертві» колонки).
4. **Продаж** — гравці платять **готівкою** або **карткою**; гроші лягають на рахунок бізнесу.
5. **Реінвест** — апгрейди, нові категорії товару, найм [далекобійників](../jobs/trucker.md) на постійні рейси.

**Порожній бізнес без власника** у 24/7 часто має **базовий асортимент** (щоб місто жило); після покупки асортимент і ціни — **ваша відповідальність**.

## Три гілки розвитку (24/7, АЗС, магазин запчастин)

У панелі власника — вкладка **«Покращення»**. Кожна гілка: **5 рівнів**, кожен рівень коштує грошей з рахунку бізнесу.

| Гілка | Що дає на практиці | Орієнтовний максимум (рівень 5) |
| --- | --- | --- |
| **Склад** | Скільки одиниць товару / літрів палива **тримає** заклад | **~5000** одиниць (база ~1000 + прокачка) |
| **Доставка (фургон)** | Скільки **за один рейс** привозить імпорт / експорт | **~300** одиниць (24/7) · **~50** (АЗС, цистерна) |
| **Відносини з постачальником** | **Знижка на оптову закупівлю** — менша собівартість | **~25%** (магазини) · **~10%** (АЗС) |

### Як росте «Доставка»

Разом із рівнем змінюється **фургон / тягач** для ваших рейсів — від маленького **Speedo** до **Pounder**. Більший рейс = менше «біганини» по місту за кожною партією.

### Навіщо качати все три

| Стратегія | Сенс |
| --- | --- |
| Тільки **склад** | Довго не замовляєте доставку, але один раз завезли — продаєте довго |
| Тільки **доставка** | Часті рейси, але склад швидко «зabивається» — треба часто вивозити / продавати |
| **Відносини** | Маржа на кожній одиниці товару — must-have для великих обертів |
| **Все разом** | Стабільний магазин біля жвавого району або АЗС на магістралі |

{% hint style="warning" %}
Гроші за **імпорт** часто **списуються одразу** при старті рейсу (не після розвантаження). Тримайте на рахунку бізнесу **подушку**, інакше доставка не стартує.
{% endhint %}

## Команда та ролі

| Рівень доступу | Хто це | Типові права |
| --- | --- | --- |
| **Базовий** | Касир, помічник | Склад, товари, старт простих доставок, поповнення рахунку |
| **Розширений** | Заступник | Найм, звільнення, апгрейди, створення робіт для [далекобійників](../jobs/trucker.md) |
| **Повний** | Довірена особа | Ціни, зняття грошей, категорії товару, комісії |
| **Власник** | Тільки ви | Продаж бізнесу, найважливіші рішення |

**Ліміти найму:** до **10** працівників у магазинах · до **5** на АЗС.

**Особисті ліміти власника:**

| Бізнес | Макс. у власності | Макс. робота «у чужого» |
| --- | --- | --- |
| 24/7 / запчастини | **3** | **2** |
| АЗС | **1** | **2** |

До **20** активних **замовлень доставки** одночасно в черзі одного закладу.

## Логістика: далекобійники

Власник у панелі створює **контракт доставки** → він з’являється у [далекобійників](../jobs/trucker.md) (швидкі рейси на орендованому транспорті).

| Тип бізнесу | Що везуть |
| --- | --- |
| 24/7 | Фургон з **коробками** товару |
| АЗС | **Цистерна** з паливом (звичайне, плюс, преміум, дизель) |
| Запчастини Benny's | Деталі для **тюнінгу** та ремонту |

Можна **самому** виконати рейс (якщо система дозволяє) або **оплатити** працю іншому гравцю.

## Два «швидких» шляхи підприємця

### Шлях 1 — «Кіоск біля дому»

Купити **24/7** у спальному районі → базові **їжа + напої** → перші апгрейди **склад + відносини** → один постійний далекобійник на вечірні рейси. Низький ризик, стабільний дрібний cashflow.

### Шлях 2 — «Заправка на магістралі»

Одна **АЗС** у проїзному місці → стабільний потік водіїв → прокачка **складу** та **відносин** → маржа з кожного литра. Окремий бізнес, не потребує СТО чи автосалону поруч.

### Шлях 3 — «Дилер»

**Приватний шоурум** — закупівля авто, вітрина, команда продажів, опційно **фінансування**. Капіталомістко; логістика **транспорту**, не запчастин з Benny's.
