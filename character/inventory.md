# Інвентар

Інвентар зберігає все, що носить персонаж: їжу, одяг, інструменти, документи, зброю та цінності. Від нього залежить виживання, заробіток і безпека речей під час пограбувань.

## Основні параметри

| Параметр | Значення |
| --- | --- |
| Слотів | **60** (частина зарезервована під одяг) |
| Переносна вага | **25 кг** без рюкзака (з рюкзаком — [35–50 кг](#слоти-одягу-та-рюкзаки)) |
| Відкрити інвентар | `Tab` |
| Другий інвентар (багажник, сховище) | `F2` |
| Швидка панель (hotbar) | `Z` |

Якщо вага перевищена — нові предмети не додадуться, поки не звільните місце або не зменшите навантаження (наприклад, знімете рюкзак із важкими речами).

## Як відкрити та користуватись

1. Натисніть **`Tab`** — відкриється вікно інвентаря з вашим персонажем.
2. **Лівий клік** ![](../.gitbook/assets/inputs/mouse-lmb.svg) — взяти / покласти предмет, перетягнути між слотами.
3. **ПКМ** ![](../.gitbook/assets/inputs/mouse-rmb.svg) на предметі — контекстне меню з діями.
4. Перетягніть предмет на **hotbar** (`Z`) — швидкий доступ без відкриття повного інвентаря.

### Дії з предметом (ПКМ ![](../.gitbook/assets/inputs/mouse-rmb.svg))

| Дія | Коли використовувати |
| --- | --- |
| **Використати** | Їжа, напої, телефон, гаманець, медикаменти |
| **Дати** | Передати іншому гравцю поруч (з’явиться список людей поблизу) |
| **Показати** | Документи через гаманець (не плутати з «Дати») |
| **Викинути** | Залишити предмет на землі |

{% hint style="warning" %}
**«Показати»** і **«Передати»** — різні дії. Для документів використовуйте **показ** через [гаманець](../basics/documents.md), а не передачу картки в руки.
{% endhint %}

## Дорожня сумка

На старті ви отримуєте **дорожню сумку** разом із базовим набором (телефон, документи, їжа, вода, гроші — див. [Перші кроки](../getting-started/first-steps.md)).

| Що класти в сумку | Чому |
| --- | --- |
| Готівка, документи, телефон | **Грабіжники** не заберуть з сумки — лише з **кишен** |
| Нелегал, цінності | Приховані від **грабіжників**; **поліція** сумку обшукує |

При [грабежі](../crime/robbery-interaction.md) злочинці **не можуть забрати** речі з **сумки** (рюкзака) — лише з **кишен** основного інвентаря. **Поліцейський** при законному обшуку може переглянути **сумку** та **вилучити нелегальні** предмети (наркотики, незареєстрована зброя тощо).

## Слоти одягу та рюкзаки

Частина слотів зарезервована під **одяг** (верх, низ, взуття, аксесуари). Одяг можна знімати та надягати через інвентар — змінюється вигляд персонажа.

**Рюкзаки** збільшують **максимальну переносну вагу** персонажа. Без рюкзака ліміт **25 кг**; коли рюкзак **надіто** — **35–50 кг** залежно від моделі:

| Тип рюкзака | Макс. переносна вага (орієнтовно) |
| --- | --- |
| Базовий рюкзак | ~35 кг |
| Покращені моделі | до 50 кг |

Рюкзак — окремий предмет: надійте його як одяг або покладіть у відповідний слот, залежно від меню.

## Зброя та патрони

- Зброя — **окремий предмет** в інвентарі.
- Екіпірування — через **«Використати»** на предметі зброї.
- Патрони заряджаються з інвентаря, якщо є відповідний калібр.
- Не носіть зброю на виду без RP-приводу — це привертає увагу поліції.

## Документи та гаманець

У слотах інвентаря — лише предмет <img src="../.gitbook/assets/wallet.png" alt="Гаманець" width="24"> **«Гаманець»**. ID-картка, права, ліцензії та інші документи **всередині гаманця** — окремих карток у інвентарі **немає**.

Відкрити: **`Tab`** → ПКМ на **«Гаманець»** → **«Використати»** → обрати потрібну картку. Детальніше — [Документи](../basics/documents.md).

Якщо гаманець втрачено — купіть новий на прилавку в [мерії](../basics/city-hall.md) (там же, де підручники з законами).

## Сховища та багажники

| Місце | Як відкрити |
| --- | --- |
| **Будинок** | Сховище в [житлі](../housing/house-management.md) |
| **Авто** | Підійдіть до машини → **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)) або `F2` |
| **Смітники** | Іноді можна знайти випадкові речі (не розраховуйте на це як на заробіток) |

При відкритті багажника або сховища з’являться **два вікна** поруч: ваш інвентар і сховище. Перетягуйте предмети між ними.

## Викинути та підібрати

1. Перетягніть предмет **за межі** інвентаря або оберіть **«Викинути»** в меню.
2. На землі з’явиться сумка-проп.
3. Інші гравці можуть **підібрати**, якщо стоять поруч.

### Друге вікно (`Tab`)

Інвентар часто відкривається **в двох панелях**: зліва — ваші речі, справа — **другий контейнер**. Назва праворуч **змінюється** — це не завжди **«Викинути»** / Drop.

| Ситуація | Друге вікно | Що це |
| --- | --- | --- |
| Стоїте на вулиці, поруч викинуті речі | **«Викинути»** (Drop) | Предмети **на землі** біля вас |
| Сидите **в авто**, `Tab` | **Бардачок** | Сховище в салоні (не багажник — [Керування](../basics/controls.md)) |
| Відкрили **дорожню сумку** («Використати») | **Слоти сумки** | Вкладений інвентар всередині сумки |
| Біля **багажника** або **сховища** | Окремий контейнер | Зазвичай **`F2`**, не `Tab` — [вище](#сховища-та-багажники) |

**«Викинути»:** перетягніть **з себе в цю панель** — викинете на землю; **з панелі до себе** — підберете. У **авто** замість неї буде **Бардачок**; у **відкритій сумці** — **слоти сумки**. Якщо нічого з цього не підходить і поруч на землі нічого немає — другого вікна може не бути.

Не залишайте цінності на вулиці без нагляду.

## Пограбування інвентаря

Якщо вас обшукують у RP:

- **Грабіжники:** лише **кишені** — вміст сумки недоступний.
- **Поліція:** може обшукати **сумку** і **вилучити нелегал** (за RP-підставою).
- **Гаманець** — для документів; показуйте через нього, не передавайте картки без потреби.
- Детальніше — у гайді [Взаємодія під час пограбування](../crime/robbery-interaction.md).

{% hint style="info" %}
Тримайте в інвентарі мінімум їжі та води на одну поїздку, бандаж або аптечку — і перевіряйте [статуси](statuses.md) персонажа, щоб не впасти в непритомність від голоду.
{% endhint %}
