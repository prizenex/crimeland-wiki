# Тату-салон

Тату — **постійний** елемент зовнішності персонажа (доки не видалите). Студії розкидані по всьому штату; адреси також є в [мерії](../basics/city-hall.md) → **«Бізнеси»** → Tattoo.

> Косметика для RP. На механіки бою не впливає.

## Де знайти студії

| Район | Орієнтир |
| --- | --- |
| **Vespucci / Del Perro** | Західне узбережжя, біля пляжу |
| **Downtown Vinewood** | Центр, біля магазинів |
| **Sandy Shores** | Північ, татусалон біля шосе |
| **Paleto Bay** | Північний берег |
| **Grapeseed** | Схід села |
| **Chumash** | Узбережжя на заході |

На мапі шукайте **іконку тату-студії** (голка / малюнок).

---

## Як зробити тату

1. Приїдьте в **зону салону** (всередині будівлі або біля крісла майстра).
2. Підійдіть до **майстра** або точки взаємодії — **`лівий Alt`** → оберіть дію.
3. Відкриється **каталог тату**:
   - Оберіть **зону тіла** (рука, груди, спина, ноги тощо).
   - Перегляньте **категорії** малюнків.
   - Поверніть камеру, щоб побачити, як виглядає на моделі.
4. Підтвердіть — з вас спишеться **вартість** тату.
5. Тату **зберігається** на персонажі назавжди (до видалення).

### Оплата

| Параметр | Деталі |
| --- | --- |
| Базова ціна | За **одне** тату (налаштовується на сервері) |
| Дорогі малюнки | Можуть мати **окрему ціну** в каталозі |
| Спосіб оплати | Готівка / картка залежно від салону |

---

## Видалення тату

1. Приїдьте в **той самий** (або будь-який) тату-салон.
2. Відкрийте меню → режим **видалення** / лазер.
3. Оберіть тату на тілі.
4. Сплатіть — зазвичай **дорожче**, ніж нанесення.

{% hint style="warning" %}
Перед видаленням **подумайте RP** — шрам після «лазера» можна відіграти, але гроші не повернуть.
{% endhint %}

---

## Поради

1. **Не закривайте одягом** — зніміть куртку через `F1` → Одяг, щоб побачити тату на торсі.
2. Для **фракційного RP** (банда, військові) — узгодьте малюнки з лідером, щоб не порушити дрес-код.
3. Поєднуйте з [салоном нігтів](nail-salon.md) та [зміною зовнішності](appearance.md) для повного образу.
