# Тату-салон

Тату лишається на персонажі, поки самі не видалите. На CrimeLand працює студія в **Downtown Vinewood** — на мапі (`P`) бліп ![](../.gitbook/assets/blips/75.png) **«Тату-салон»**. Інші адреси з [мерії](../basics/city-hall.md) можуть бути закриті; орієнтуйтесь на бліп.

## Як зробити тату

1. Зайдіть у зону салону.
2. Маркер → **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)).
3. У каталозі: зона тіла → малюнок → поверніть камеру, подивіться на моделі.
4. Підтвердіть — спишеться ціна з каталогу.
5. Тату зберігається до видалення.

### Оплата

- Платите **за кожне** тату окремо — суму бачите у каталозі **до** підтвердження.
- За **прозорість** (насиченість) може бути доплата, якщо слайдер доступний.
- Рідкісні малюнки інколи коштують дорожче — ціна теж у каталозі.
- Готівка або картка.

## Видалення

1. Та сама студія ![](../.gitbook/assets/blips/75.png).
2. Меню → режим видалення / лазер.
3. Оберіть тату → сплатіть (зазвичай **дорожче**, ніж нанесення).

{% hint style="warning" %}
Гроші за видалення не повертаються. Якщо RP-шрам після «лазера» — ок, але подумайте заздалегідь.
{% endhint %}

## Поради

- Зніміть куртку (`F1` → Одяг), щоб бачити торс і спину.
- Для банди / фракції — узгодьте малюнок з лідером.
- Образ: [нігті](nail-salon.md), [зовнішність](appearance.md), [одяг](clothing.md).
