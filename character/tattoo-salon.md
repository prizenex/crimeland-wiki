# Тату-салон

Тату — **постійний** елемент зовнішності персонажа (доки не видалите). На CrimeLand працює студія в **Downtown Vinewood**; адреси також є в [мерії](../basics/city-hall.md) → **«Бізнеси»**.

> Косметика для RP. На механіки бою не впливає.

## Де знайти студію

| Параметр | Значення |
| --- | --- |
| Район | **Downtown Vinewood** |
| Бліп на мапі | ![](../.gitbook/assets/blips/75.png) **Тату-салон** |
| Орієнтир | Північний LS, район Vinewood (біля магазинів одягу) |

{% hint style="info" %}
На сервері активна **одна** публічна студія з бліпом. Інші адреси з мапи штату можуть бути закриті — орієнтуйтесь на бліп ![](../.gitbook/assets/blips/75.png).
{% endhint %}

---

## Як зробити тату

1. Приїдьте в **зону салону** (всередині будівлі).
2. Підійдіть до маркера — **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)).
3. Відкриється **каталог тату**:
   - Оберіть **зону тіла** (рука, груди, спина, ноги тощо).
   - Перегляньте **категорії** малюнків (у т.ч. кастомні набори CrimeLand).
   - Поверніть камеру, щоб побачити, як виглядає на моделі.
4. Підтвердіть — з вас спишеться **вартість** тату.
5. Тату **зберігається** на персонажі (до видалення).

### Оплата

| Параметр | Деталі |
| --- | --- |
| Базова ціна | За **одне** тату (видно в каталозі до підтвердження) |
| Прозорість | Додаткова оплата за рівень насиченості (якщо доступно) |
| Дорогі малюнки | Можуть мати **окрему ціну** в каталозі |
| Спосіб оплати | Готівка / картка |

---

## Видалення тату

1. Приїдьте в **ту саму** студію (бліп ![](../.gitbook/assets/blips/75.png)).
2. Відкрийте меню → режим **видалення** / лазер.
3. Оберіть тату на тілі.
4. Сплатіть — зазвичай **дорожче**, ніж нанесення.

{% hint style="warning" %}
Перед видаленням **подумайте RP** — шрам після «лазера» можна відіграти, але гроші не повернуть.
{% endhint %}

---

## Поради

1. **Не закривайте одягом** — зніміть куртку через `F1` → Одяг, щоб побачити тату на торсі.
2. Для **фракційного RP** (банда, військові) — узгодьте малюнки з лідером, щоб не порушити дрес-код.
3. Поєднуйте з [салоном нігтів](nail-salon.md) та [зміною зовнішності](appearance.md) для повного образу.
