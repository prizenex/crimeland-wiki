# Love-menu

Love-menu — **романтичні сцени для подружжя** в системі весілля: поцілунки, сюрпризи, анімації з ефектами. Доповнює [шлюб](marriage.md) та [емоути](animations.md).

## Хто може користуватись

| Умова | Деталі |
| --- | --- |
| Шлюб | Потрібен **зареєстрований** шлюб на сервері |
| Партнер | Поруч або онлайн (залежить від обраної сцени) |
| Кільце | Рекомендовано мати **обручку** для GPS та меню пари |

Без шлюбу love-menu **недоступне** — спочатку пройдіть [церемонію](marriage.md).

## Як відкрити

1. Переконайтесь, що ви **одружені**.
2. Відкрийте меню весільної пари (через **кільце** або меню шлюбу — підказка в інтерфейсі після весілля).
3. Оберіть розділ **«Моє вічне кохання»** / love-сцени.
4. Введіть коротке повідомлення (до **50 символів**) за бажанням.
5. Оберіть сцену (поцілунок, сюрприз тощо) → підтвердіть.

Деякі сцени **платні** — перед відправкою з’явиться підтвердження оплати.

## Що доступно

| Тип | Приклад |
| --- | --- |
| Сцени з анімацією | Поцілунок, романтичні пози |
| Сюрпризи | Повідомлення + ефект для партнера |
| Love emoji-місії | Спільні завдання для пари (емодзі над головою) |

Партнер отримує **сповіщення** з вашим текстом і може прийняти сцену.

## Правила RP

- **Згода обох** обов’язкова — відхилення запиту поважайте.
- У публічних місцях дотримуйтесь [правил сервера](../basics/rules.md) та рейтингу (18+ сцени — приватні локації).
- Love-menu не замінює звичайні **спільні емоути** (`U` → категорія shared) для друзів — лише для **подружжя**.

## Якщо не працює

1. Перевірте, що шлюб активний (ви не проходили [розлучення](marriage.md)).
2. Партнер у радіусі взаємодії.
3. Спробуйте перезайти в меню кільця.
4. `F4` → вкажіть, яка сцена не запускається.
