# Анімації

Меню **емоутів** — жести, пози, танці, пропи, стилі ходи та **спільні** анімації для RP-сцен.

## Як відкрити меню

| Спосіб | Дія |
| --- | --- |
| **`U`** | Основна клавіша меню емоутів |
| **Радіальне меню** (`F1`) | Пункт, що відкриває меню емоутів |

Якщо `U` не спрацьовує — **Esc → Settings → Key Bindings → FiveM → Open Emotes Menu** (можна переназначити).

## Як використати

1. Натисніть **`U`**.
2. Оберіть категорію: емоути, танці, пропи, спільні, стилі ходи, міміка.
3. Запустіть анімацію кнопкою миші (див. таблицю нижче).
4. **`X`** — скасувати поточний емоут.

### Кнопки миші в меню

У каталозі емоутів активна кнопка підсвічується **акцентним кольором** (як у підказках HUD):

| Кнопка | Іконка | Дія |
| --- | --- | --- |
| **Ліва (ЛКМ)** | ![](../.gitbook/assets/inputs/mouse-lmb.svg) | Запустити емоут на собі |
| **Права (ПКМ)** | ![](../.gitbook/assets/inputs/mouse-rmb.svg) | **Спільна** анімація — націлитись на гравця в меню та натиснути |
| **Колесо (СКМ)** | ![](../.gitbook/assets/inputs/mouse-mmb.svg) | **Обрати місце** — режим позиціонування перед стартом |

У меню можна увімкнути **ходьбу під час перегляду** каталогу та перегляд GIF-прев’ю анімацій.

## Спільні емоути

1. Підійдіть близько до іншого гравця (~3 м).
2. Відкрийте меню (`U`) → категорія **«Спільні»**.
3. Наведіть курсор на **потрібного гравця** в списку/на екрані та натисніть **ПКМ** ![](../.gitbook/assets/inputs/mouse-rmb.svg) на обраній анімації.
4. Другий гравець отримає запрошення: прийняти — **`Y`**, відхилити — **`M`** (підказка на екрані).

### Групові емоути

У меню є **групові емоути**: можна створити групу, запросити гравців поруч (~10 м) і синхронізувати одну анімацію на всіх.

Без згоди не використовуйте нав’язливі анімації — це порушення [правил](../basics/rules.md).

## Позиціонування (AnimPos)

Для частини емоутів доступне **точне позиціонування** персонажа в сцені:

| Клавіша | Дія |
| --- | --- |
| Стрілки | Зсув вперед / назад / вліво / вправо |
| Колесо миші | Вгору / вниз |
| **Q** / **E** | Поворот |
| **G** | Фіксація курсора |
| **Enter** | Підтвердити позицію |

## Додаткові рухи

| Дія | Клавіша |
| --- | --- |
| Скасувати емоут | **`X`** |
| Повзти | **`Правий Ctrl`** (`RCONTROL`) |

## Поради для RP

- Сидіння, куріння, телефон — доповнюють сцену без голосового чату.
- На зупинках ([таксист](../jobs/taxi-driver.md), [охорона](../police/getting-started.md)) емоути роблять очікування живим.
- Скасовуйте емоут (`X`) перед бігом, боєм або посадкою в авто — під час наручників і knockout анімація знімається автоматично.
