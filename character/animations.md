# Анімації

Хочете оживити RP-сцену без єдиного слова в голосовому чаті? Меню емоутів дає жести, пози, танці, пропи, стилі ходи та спільні анімації з іншими гравцями — усе відкривається однією клавішею.

## Як відкрити та використати

Натисніть **`U`** (або оберіть пункт меню емоутів у радіальному меню — **`F1`**). Якщо `U` не спрацьовує, перепризначте клавішу: **Esc → Settings → Key Bindings → FiveM → Open Emotes Menu**.

У меню оберіть категорію — емоути, танці, пропи, спільні, стилі ходи, міміка. **ЛКМ** <img src="../.gitbook/assets/inputs/mouse-lmb.svg" alt="ЛКМ" data-size="line"> запускає емоут на собі, **ПКМ** <img src="../.gitbook/assets/inputs/mouse-rmb.svg" alt="ПКМ" data-size="line"> — спільну анімацію (наведіть на гравця в меню), **СКМ** <img src="../.gitbook/assets/inputs/mouse-mmb.svg" alt="СКМ" data-size="line"> відкриває позиціонування перед стартом. Активна кнопка в каталозі підсвічується акцентним кольором.

Під час перегляду каталогу можна увімкнути ходьбу та переглянути GIF-прев’ю анімацій. Щоб зупинити поточний емоут — **`X`**.

## Спільні та групові емоути

Підійдіть близько до іншого гравця (~3 м), відкрийте меню (`U`) → категорія **«Спільні»**, наведіть курсор на потрібного гравця та натисніть **ПКМ** <img src="../.gitbook/assets/inputs/mouse-rmb.svg" alt="ПКМ" data-size="line"> на обраній анімації. Другий гравець отримає запрошення: прийняти — **`Y`**, відхилити — **`M`**.

Для більшої компанії в меню є **групові емоути**: створюєте групу, запрошуєте гравців поруч (~10 м) і синхронізуєте одну анімацію на всіх.

{% hint style="warning" %}
Без згоди партнера не нав’язуйте анімації — це порушення [правил сервера](../basics/rules.md).
{% endhint %}

## Позиціонування (AnimPos)

Для частини емоутів доступне точне позиціонування персонажа в сцені:

- **Стрілки** — зсув вперед / назад / вліво / вправо
- **Колесо миші** — вгору / вниз
- **Q / E** — поворот
- **G** — фіксація курсора
- **Enter** — підтвердити позицію

## Додатково

**Повзти** — **`Правий Ctrl`**.

{% hint style="info" %}
Скасовуйте емоут (`X`) перед бігом, боєм або посадкою в авто — під час наручників і нокдауну анімація знімається автоматично.
{% endhint %}

Сидіння, куріння, телефон — гарний спосіб доповнити сцену без голосового чату. На зупинках ([таксист](../jobs/taxi-driver.md), [охорона](../police/getting-started.md)) емоути роблять очікування живим.
