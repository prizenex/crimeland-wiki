# Салон нігтів

На CrimeLand манікюр — окрема **косметична** механіка: колір, форма та дизайн нігтів на руках персонажа. На бій, роботи чи заробіток **не впливає** — лише на зовнішній вигляд у RP.

## Як зробити манікюр

### Варіант 1. Самообслуговування

1. Приїдьте до салону.
2. Підійдіть до **столу майстра** (маркер біля крісла).
3. Станьте на позицію **клієнта** (навпроти майстра).
4. Відкриється **меню нігтів** — оберіть руку, палець, колір, текстуру, довжину.
5. Підтвердіть — з вас спишеться оплата.
6. Зміни **зберігаються** на персонажі.

### Варіант 2. Через майстра (RP)

Салон може працювати як **робоче місце** — інший гравець-майстер сідає за стіл, ви — у крісло клієнта. Це зручно для RP-візиту «на манікюр» з чайком і розмовою.

## Ціна

| Послуга               | Орієнтовна ціна               |
| --------------------- | ----------------------------- |
| Будь-яка зміна нігтів | **$500** за сесію редагування |

Оплата знімається **після підтвердження** в меню. Переконайтесь, що маєте готівку або кошти на картці.

***

## Що можна налаштувати

| Категорія | Приклади                                          |
| --------- | ------------------------------------------------- |
| Колір     | Однотон, глянець, мат                             |
| Дизайн    | Візерунки, градієнт (залежить від DLC на сервері) |
| Форма     | Довжина та форма нігтів                           |
| Руки      | Ліва / права окремо                               |

{% hint style="info" %}
Частина дизайнів — з **сезонних наборів** (святкові, візерунки). Якщо не бачите потрібний — можливо, він у розширеному пакеті салону.
{% endhint %}

## Поради

1. Зробіть манікюр **перед фотосесією** або весіллям — дешевий спосіб виділитись у RP.
2. Якщо меню не відкривається — станьте **точно на маркер** клієнта, обличчям до столу.
3. Для повної зміни образу поєднайте з [тату](tattoo-salon.md), [одягом](clothing.md) та [зовнішністю](appearance.md).
