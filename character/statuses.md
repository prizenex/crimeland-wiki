# Статуси

Статуси показують фізичний і психологічний стан персонажа. Ігнорування призводить до дебафів, втрати свідомості або гіршої реакції в бою.

## Де дивитись

- **HUD** — іконки біля міні-карти (ті самі символи, що в таблиці нижче; малює `ZSX_UIV2`)
- **[Радіальне меню](../controls/radial.md)** — детальніший перегляд стану
- **`F1` → Про мене → Фізуха → Стати** — статистика спортзалу; див. [Спорт](sport.md)

## Основні статуси

Іконки в HUD збігаються з `ZSX_UIV2/shared/ui_cfg/config_hud.lua`.

| | Статус | Що відбувається | Як відновити |
| --- | --- | --- | --- |
| <i class="fa-hamburger">:hamburger:</i> | **Голод** | Падає без їжі | Їжа з [інвентаря](inventory.md) або [магазину](../basics/shops.md) |
| <i class="fa-whiskey-glass">:whiskey-glass:</i> | **Спрага** | Падає без пиття | Вода, напої, кава; у довгих рейсах тримайте запас у машині |
| <i class="fa-brain">:brain:</i> | **Стрес** | Росте від швидкої їзди (особливо без ременя), стрільби, погонь; на високому рівні — тремтіння екрана | Цукерки Twerks / Snikkel у [24/7](../basics/shops.md), куріння (запальничка), відпочинок, [спорт](sport.md) |
| <i class="fa-person-running">:person-running:</i> | **Стаміна** | Виснажується при бігу та навантаженні | Короткий відпочинок, сон (RP), душ у спортзалі |
| <i class="fa-lungs">:lungs:</i> | **Кисень** | З’являється під водою — скільки ще вистачить повітря | Випливи на поверхню; довше тримає [об’єм легень](#статистика-спортзалу) зі спортзалу |

Окремо від шкали HUD:

- **Травми** — після бою, ДТП, падіння. [EMS](../ems/getting-started.md), бандаж, лікарня; самолікування не завжди знімає всі ефекти.

На старті в дорожній сумці є їжа та вода — використайте їх у першій поїздці.

## Статистика спортзалу

Окремо від голоду/спраги в [спортзалі](sport.md) прокачуються три показники — див. **`F1` → Про мене → Фізуха → Стати**.

| | Стат | Ефект |
| --- | --- | --- |
| <i class="fa-dumbbell">:dumbbell:</i> | **Сила** | Сильніший рукопашний бій |
| <i class="fa-person-running">:person-running:</i> | **Витривалість** | Довший спринт без зупинки |
| <i class="fa-lungs">:lungs:</i> | **Об’єм легень** | Довше під водою без акваланга |

Без тренувань показники повільно падають (приблизно раз на годину). Регулярні заняття тримають форму.

{% hint style="warning" %}
Не виходьте з гри в пустелі без запасу води — статуси продовжують діяти, поки персонаж у світі.
{% endhint %}
