# Зміна зовнішності

Зовнішність редагується в **салонах** на мапі та при створенні персонажа. Одяг змінюється окремо — розділ [Одяг](clothing.md).

## Де змінити

- **Барбершоп** ![](../.gitbook/assets/blips/71.png) — зачіска, борода, брови, макіяж; ціна за категорією (див. таблицю нижче)
- **Магазин одягу** ![](../.gitbook/assets/blips/73.png) — куртки, штани, аксесуари; [окремий розділ](clothing.md)
- **Тату-салон** — малюнки на тілі; [Тату-салон](tattoo-salon.md)
- **Пластичний хірург** (лікарня Pillbox) ![](../.gitbook/assets/blips/71.png) — обличчя, пропорції, риси; **безкоштовно**

Увійдіть у зону → **`E`** / **`лівий Alt`** ([Керування](../basics/controls.md)) → меню зовнішності.

### Барбершоп — орієнтовні ціни

| Категорія | Ціна |
| --- | --- |
| Зачіска | **7 500$** |
| Борода | **3 500$** |
| Брови | **2 000$** |
| Волосся на грудях | **2 500$** |
| Макіяж / рум’яна / помада | **2 000$** – **3 000$** |

## Як користуватись

1. Підійдіть до NPC / маркера салону.
2. Відкрийте меню (підказка на екрані).
3. Налаштуйте параметри: обличчя, волосся, макіяж, пропорції.
4. Підтвердіть і сплатіть.

Зміни **зберігаються** на персонажа назавжди (поки знову не зміните).

## Пластичний хірург (лікарня)

Якщо хочете **кардинально** змінити обличчя або пропорції тіла — не барбер і не магазин [одягу](clothing.md), а **пластичний хірург у лікарні**.

- **Де** — **Pillbox**, центральна лікарня (бліп EMS на мапі)
- **Як** — підійдіть до точки хірурга → **`E`** / **`лівий Alt`** → меню кастомізації
- **Що можна** — майже повна переробка, як при [створенні персонажа](../getting-started/character.md)
- **Ціна** — **безкоштовно**

Використовуйте для обґрунтованого RP: операція після травми, зміна імені/образу, реконструктивна хірургія.

{% hint style="info" %}
**Барбершоп** — лише волосся, борода, макіяж. **Хірург** — риси обличчя та тіло. **Магазин одягу** — куртки та штани.
{% endhint %}

## Стартові апартаменти

Після першого входу в [стартові апартаменти](../getting-started/first-steps.md) доступний базовий гардероб і дзеркало — зручно виправити дрібні деталі перед виходом у місто.

## Поради

- Зробіть скріншот «до/після» для RP-історії.
- Татуювання знімаються лише в [тату-салоні](tattoo-salon.md) (лазер), не в барбершопі.
- Після зміни обличчя оновіть фото в [гаманці](../basics/documents.md), якщо ID підтримує актуальне зображення.
