# Шлюб

Весілля на CRIMELAND — повноцінна **RP-подія** з підготовкою, оплатою та церемонією. Обряд проводить гравець із посадою **священник** (не NPC).

## Етапи до весілля

### 1. Обручки

| Параметр | Значення |
| --- | --- |
| Ціна кільця | **1 000 000$** за кільце |
| Скільки потрібно | **По одному** кожному з наречених |

### 2. Підготовка

| Стаття | Вартість |
| --- | --- |
| Оплата весілля | **150 000$** |
| Весільний одяг (опція) | **1 000 000$** |
| Церемонія | **1 000 000$** |
| Оренда весільного авто (stretch) | **500 000$** + депозит **200 000$** |

Час підготовки після бронювання — **60 хвилин** (домовтесь про гостей, локацію, фото).

### 3. Церемонія

Локація церемонії — **церква Rockford Hills** (подіум і координати пари задає система весілля).

1. Домовтесь про дату зі **священником** через [телефон](../basics/phone.md).
2. Обидва наречені з обручками на місці.
3. Священник запускає обряд (**`/marriage`**).
4. Після церемонії — RP-святкування за бажанням.

## Після шлюбу

| Бонус | Опис |
| --- | --- |
| ❤️ над головою | Емодзі партнера (якщо увімкнено) |
| Кільце | GPS-мітка партнера на мапі при використанні |
| Нагороди за стаж | Бонуси за 1 / 3 / 6 / 12 місяців шлюбу |
| [Love-menu](love-menu.md) | Романтичні сцени для пари |

Оголошення про весілля може з’явитись на **3 години** для всього сервера — плануйте як публічну подію.

## Розлучення

Команда **`/divorce`**.

| Параметр | Значення |
| --- | --- |
| Згода партнера | **Потрібна** — партнер онлайн і поруч |
| Мультишлюб | **Вимкнено** — лише один шлюб на персонажа |

## Поради

- Запросіть друзів, фотографа, ведучого — це головна соціальна подія персонажа.
- Перевірте баланс **до** дня Х: сума з обручками та церемонією легко перевищує **3 000 000$**.
- Після шлюбу спробуйте [love-menu](love-menu.md) для парних RP-сцен.

{% hint style="info" %}
Шлюб технічно прив’язаний до системи весіль — без священника (гравця з посадою) обряд не провести.
{% endhint %}
